# SVGストーリームービーの挿入計画（第1～5章）

[資料の入口](../README.md) / [冒頭ショートムービー](opening-movie.md) / [プロローグ試作](../../../Storybook_Character_Studio/story-movies/prologue/README.md)

2026-11-08作成の制作計画です。実装済みの第1～5章で、プロローグと同じ方式のSVGムービーを入れる場所と内容を整理します。**ゲームにはまだ1本も組み込んでいません**（Studioで試作済みなのはプロローグだけ）。字幕案は実装済みの台詞・結末文から取り、新しい設定は加えません。作るかどうか、順番はユーザーが決めます。

## 方針

- **入れる場所**: 物語の節目に限ります。編の始まりと終わり、職の復活、強敵の出現です。会話で進む日常や建築の手順は、これまでどおりゲーム画面で見せます。
- **長さは3段階**:
  - 大（25～35秒）: 編の始まり・終わり
  - 中（10～20秒）: 章の山場
  - 小（5～8秒）: 差し込み
- **今ある演出との関係**: 第1・3・5章の結末は、今は文字が流れる演出（`ui.playEnding()`）です。書の復活は、ゲージが伸びる小窓（`ui.showBookRevival()`）です。ムービーはこれらに置き換えるか、前後に足します。今ある演出は、ムービーを再生できないときの代わりとして残すことを勧めます。
- **重なりの調整**: ムービーで語った内容を、直後の会話で繰り返さないよう調整します（例: プロローグと第1章の導入の冒頭3行）。
- **操作**: 送り・スキップができ、タイトル画面からもう一度見られるようにします。セーブを読み込んだときには再生しません。「見た」という記録は既存のセーブと別のキーに保存し、セーブ形式を変えません。
- **作り方**: プロローグと同じです（PythonのSVG生成、再生エンジン `StoryPlayer`、ゲームと同じ書体）。人物はStudioの作画コードから頭・胴を取り出して使います。

## 各ムービーの内容

### M1 第1章の結び「小さな社」（中・15秒）

- **目的**: 最初の章を締めくくり、シオンが「職をつぐ者」と呼ばれる場面を印象づける。
- **場面**:
  1. 夜の北の山の社。祭壇に職業の書と、よみがえった農民の書が並び、灯りがともる。
  2. 社を見上げる島の人々（ミナ・ピノ・ゴンタ・ジンベエ）。
  3. 朝の村の全景。小屋・畑・旗。
  4. 「職をつぐ旅は、ここから続いていく」
- **字幕案**: 祭壇の会話と、今の章末の文から取る（「人々が働き始めた時、白紙の職業の書に文字が戻った」など）。
- **注意**: 今の章末の文（`playEnding()` の既定の文）は、勇者・魔物・神殿の崩壊をもう一度語っており、プロローグと重なります。ムービーにする際は、第1章の出来事だけに絞ります。

### M2 書の復活（共通の型・小・6～8秒×5）

- **目的**: 職が戻る瞬間を、毎回同じ型で気持ちよく見せる。
- **場面**:
  1. 白紙の書が開く。
  2. ページに光の文字が戻る。
  3. その職の道具が光の中に浮かぶ（鍬・鍋・舵・槌・薬草など）。
  4. 書の名前を表示する。
- **作り方**: 型は1つにして、書の色・紋章・道具の絵だけを差し替える。
- **準備が必要なもの**: 農民の書など5冊の見た目（表紙の色・紋章）は未定です。職業の書（深緑・金の開いた本）と区別できる意匠を、先にStudioで決めます。

### M3 強敵の出現（小・6～8秒）

- **クラーケン（第3章）**: 港の静かな海面が盛り上がり、触手が桟橋と停泊中の船に迫る。船を見下ろす巨大な影。
- **瘴泉竜グロム（第5章）**: 濁った泉の上を低く漂う、双頭・翼のある竜。実装の姿（`GROM_CONFIG`）に合わせる。
- **作らないもの**: 書喰いのスライム・泥田の主・炉喰らいの大鬼火は、防衛戦の始まりとして今の会話で十分なので作らない。
- **注意**: 戦闘の準備（会話と選択）を終えた後、戦闘が始まる直前に再生する。戦闘中には差し込まない。

### M4 旅立ち「ジパング復興編・完」（大・30～35秒）

- **目的**: 第1～3章の総まとめと、島からの船出。第4～5章（M5）へつなぐ。
- **場面**:
  1. 復興した島（田・食堂・灯台・社）を朝の光で見渡す。
  2. 島に残るピノ・イナホ・ジンベエ。
  3. 船に乗るシオン・ミナ・ゴンタ・ワタリ。桟橋で見送る人々。
  4. 灯台の光の先、水平線へ進む帆。
  5. タイトル「ジパング復興編・完」。
- **字幕案**: 今の結末文（`chapter3.js` の `ending`）から。例:「漂着した者は、船をつくる者になった。」「職をつぐ旅は、海の向こうへ続いていく。」
- **注意**: 「漂着した見習い神官」から始まる今の文の流れを、絵の順番に合わせる。クリア後に `CH3_DONE` でワタリと話すと、もう一度見られる（今の再演の仕組みをそのまま使う）。

### M5 火山島編の始まり「海を越えて」（大・25～30秒）

- **目的**: 第4～5章は別のゲームとして単独で始まり、プロローグがありません。初めて遊ぶ人にもシオンたちのことが分かるようにし、火山島への到着を見せる。
- **場面**:
  1. これまでの旅を短く（ダーマ神殿から脱出した少年、ジパングの復興）。プロローグとM4の絵を小さく使う。
  2. 長い航海。物資が尽きていく船上の四人。
  3. 灰の匂いの風と、煙を上げる黒い島影。
  4. 焼けた船着き場。
- **字幕案**: 今の導入会話（`chapter4.js` の `intro`）の地の文と、第4章の開始状態の説明から。例:「……潮風が、変わった。灰の匂いをふくんだ風。」
- **注意**: ムービーを見た後は、導入会話の振り返り（「思い出すのう…」の2行）を短くする。最後の「だれか、いるの……？」とカヤとの出会いは会話に残す。

### M6 黒い爪痕（小・5～6秒）

- **目的**: 第6～7章への伏線を短く印象づける。
- **場面**: よみがえった炉の火が歪み、炎の奥に黒い爪痕のような影が浮かんで消える。
- **注意**: 敵の名前（ヴァルガ）や姿は出さない。第4章で確定していない設定を描かない（[第4章の記録](../implemented/chapter4.md)）。

### M7 帰るべき場所へ「火山島編・完」（大・30～35秒）

- **目的**: 第4～5章を締めくくり、旧ダーマ神殿へ戻る決意を見せる。
- **場面**:
  1. 澄んだ水が戻る清めの泉。
  2. 町の人々（鍛冶屋のベルク、僧侶のナギ、薬草のヨモギ、ロク、カヤ、スミ、テル）。
  3. 船出する四人。
  4. 夜の海の向こうに、プロローグ第3場面と同じ形の、崩れた神殿の影が見える。
  5. タイトル「火山島編・完」。
- **字幕案**: 今の結末文（`chapter5.js` の `ending`）から。例:「そして 職をつぐ者は、船に乗る。」「すべてが失われた、始まりの場所へ。」
- **注意**: 第6～7章は未実装です。ヴァルガの姿や再建後の神殿は描かず、「戻る」ところで止める。

### M8 章の幕開け（小・4～5秒）

- **目的**: 章が変わったことを、1枚絵と章名ではっきり伝える。
- **内容**:
  - 第2章「荒れた田の村」: 南へ架かる壊れた橋
  - 第3章「旅立ちの港」: 浜に漂着したワタリ
  - 第5章「眠る竹林の社」: 竹林の門
- **注意**: 第1章と第4章は、それぞれM0・M5の終わりに章名を出して兼ねる。

## 作る順番の提案

1. **M4とM5**: ジパング復興編の終わりと火山島編の始まりを、対で作る。2つのゲームをつなぎ、効果が最も大きい。
2. **M7**: 火山島編の終わり。プロローグの神殿と呼応させる。
3. **M2**: 書の復活の型。1つ作れば5回使える。先に5冊の意匠を決める。
4. **M1**: 第1章の結び。章末の文とプロローグの重なりも解消する。
5. **M3・M6・M8**: 余裕があれば。

## 共通の準備（Studio）

- **人物の部品**: プロローグのシオンと同じく、Studioの各 `character.mjs` から頭・胴を取り出す仕組み（`shion_parts.mjs`）を全員に広げる。手足と姿勢は `shion.py` を共通化する。
  - 人物の作画は全員Studioにある: シオン、ミナ、ピノ、イナホ、ゴンタ、ジンベエ、ワタリ、ベルク、ロク、カヤ、ナギ、ヨモギ、スミ、テル。
  - 竜グロムの作画もStudioにある（`prototypes/grom-8dir/`）。
- **新しく描く必要があるもの**: 船、クラーケン、5冊の職業の書の意匠、各章の背景（島・港・火山島・竹林・泉）。
- **再生エンジンと共通部品**: `story-movies/shared/` にまとめ、各ムービーは `story-movies/<名前>/` に置く。
- **確認**: 各ムービーにプロローグと同じテスト（静止画・通し再生・スマートフォン・モーション軽減）を付ける。

## ゲームへ組み込むときの注意

- **再生エンジンの置き場所**: `StoryPlayer` は両編で共用するので `game-shared/` に置く。
- **読み込み**: ムービーは1本あたり0.3～0.6MBの見込み。必要になったときに読み込み、ゲームの起動を重くしない。
- **再生する時機**: 会話の終わりやステージが変わる区切りで再生し、防衛戦の最中や建築の操作中には再生しない。再生中は世界を止める（既存の一時停止の仕組みを使う）。
- **テスト**: 既存の章の通しテスト（`story.test.mjs`・`chapter3.test.mjs`・`chapter5.test.mjs` など）が、ムービーをスキップして進められるようにする。
- **台詞の調整**: ムービーで語った内容と重なる台詞は、移植のときに調整する。その際は[不整合一覧](../inconsistencies.md)に記録する。
