# SVGストーリームービーの挿入計画（第1～5章）

[資料の入口](../README.md) / [冒頭ショートムービー](opening-movie.md) / [プロローグ試作](../../../Storybook_Character_Studio/story-movies/prologue/README.md) / [第6～7章のムービー計画](chapter6-7-movies.md)

2026-11-08作成の制作計画です。実装済みの第1～5章で、プロローグと同じ方式のSVGムービーを入れる場所と内容を整理します。字幕案は実装済みの台詞・結末文から取り、新しい設定は加えません。

同日、ユーザーが**作る7本を決めました**（[採用した7本](#adopted)）。当初の候補のうち3本は見送りとし、検討の記録を[見送ったもの](#declined)に残します。採用した7本は、すべてStudioで試作しました（プロローグ M0 のほか、M4・M5・M7・M2・M1・M9 は2026-11-08）。同日、**7本すべてを両編のゲームへ組み込みました**（[ゲームへの組み込み](#integration)）。

## 方針

- **入れる場所**: 物語の節目に限ります。編の始まりと終わり、章の結び、職の復活です。会話で進む日常や建築の手順は、これまでどおりゲーム画面で見せます。
- **長さは3段階**:
  - 大（25～35秒）: 編の始まり・終わり
  - 中（10～20秒）: 章の結び
  - 小（5～8秒）: 差し込み
- **今ある演出との関係**: 第1・3・5章の結末は、計画の時点では文字が流れる演出（`ui.playEnding()`）でした（組み込みの後、2026-11-08に削除）。書の復活は、ゲージが伸びる小窓（`ui.showBookRevival()`）です。ムービーはこれらに置き換えるか、前後に足します。今ある演出は、ムービーを再生できないときの代わりとして残すことを勧めます。
- **重なりの調整**: ムービーで語った内容を、直後の会話で繰り返さないよう調整します（例: プロローグと第1章の導入の冒頭3行）。
- **操作**: 送り・スキップができ、タイトル画面からもう一度見られるようにします。セーブを読み込んだときには再生しません。「見た」という記録は既存のセーブと別のキーに保存し、セーブ形式を変えません。（2026-11-08の組み込みでは、送り・スキップと、セーブを読み込んだときに再生しないところまで。タイトル画面からもう一度見る機能と「見た」記録は未実装）
- **作り方**: プロローグと同じです（PythonのSVG生成、再生エンジン `StoryPlayer`、ゲームと同じ書体）。人物はStudioの作画コードから頭・胴を取り出して使います。

## 各ムービーの内容

### M1 第1章の結び「小さな社」（中・15秒）

- **目的**: 最初の章を締めくくり、シオンが「職をつぐ者」と呼ばれる場面を印象づける。
- **場面**:
  1. 夜の北の山の社。祭壇に職業の書と、よみがえった農民の書が並び、灯りがともる。
  2. 社を見上げる島の人々（ミナ・ピノ・ゴンタ・ジンベエ）。
  3. 朝の村の全景。小屋・畑・旗。
  4. 「職をつぐ旅は、ここから続いていく」
- **字幕案**: 祭壇の会話と、今の章末の文から取る（「人々が働き始めた時、白紙の職業の書に文字が戻った」など）。
- **注意**: 今の章末の文（`playEnding()` の既定の文）は、勇者・魔物・神殿の崩壊をもう一度語っており、プロローグと重なります。ムービーにする際は、第1章の出来事だけに絞ります。
- **試作（2026-11-08）**: Studioの [`story-movies/ch1-shrine/`](../../../Storybook_Character_Studio/story-movies/ch1-shrine/README.md)。約15秒・3場面（祭壇の二冊／社を見上げる人々／朝の村）。字幕は今の章末の文のうち第1章の行（「その書に導かれ…槌を取った」から「…文字が戻った」まで）と最後の行だけを使い、プロローグと重なる前半は使わない。最後にタイトル「第1章・完／漂着の浜」。祭壇の会話は字幕にせず、会話に残す。

### M9 第2章の結び「収穫祭の夜」（中・約18秒）

- **目的**: 第2章を「食卓が戻る」場面で締めくくり、第3章の海と船へつなぐ。今の第2章には章末の演出がないので、新しく足す。
- **場面**:
  1. 守った田（3秒）: 月夜。泥の跡が残る田で、実った稲が揺れる。
  2. 収穫祭（5秒）: 食堂の前でかまどの火が燃え、シオン・ミナ・イナホ・ゴンタ・ジンベエ・ピノが膳を囲む。イナホが料理を運ぶ。
  3. 二冊の書（3秒）: 宴の灯りの中で、シオンが背負う職業の書がほのかに光り、農民と料理人の紋が浮かぶ。
  4. 荒れる沖（5秒）: カメラが宴から海へ動く。沖に黒い雲と稲光。波にもまれる小さな船の影。稲光の一瞬だけ、海の中に巨大な影が見える。
  5. 結び（2秒）: 嵐が遠くで続く暗い海。「職をつぐ旅は、まだ続く。」
- **字幕案**: 勝利会話（`chapter2.js` の `paddyDefenseWin`）から取る。「田がよみがえり、食が戻った」（ジンベエ）、「今夜は 収穫祭だね！」（イナホ）、「農民、料理人……二冊の書が よみがえった」「今夜は 荒れるやもしれん」（職業の書）。
- **第3章とのつながり**: 第3章の導入で、ワタリは「嵐と、海の化け物にやられての」と語ります。④の嵐と船の影がその夜の出来事に当たり、翌朝ピノが浜で船を見つける場面につながります。M4では、この荒れた海へ自分たちの船で漕ぎ出す形になります。
- **見せないもの**: ワタリの顔・名前と、浜に打ち上がる場面（発見の驚きは第3章の導入に残す）。クラーケンの全身（影だけにし、第3章の戦闘まで取っておく）。嵐の原因や魔物の正体など、新しい設定。
- **注意**:
  - ゲームの島には嵐の表現がありません。嵐は沖だけにし、島は静かなままにして、翌朝の画面と食い違わないようにします。
  - 字幕の一部は、勝利会話の後半（ジンベエと書の台詞）と重なります。会話を短くするか字幕を減らすかは、移植のときに決めます。
  - スキップしても進行（`CH2_DONE` への移行と、翌日の第3章の開始）は変わらないようにします。
  - ③の書は、M2で書の意匠が決まっていれば二冊を並べて見せます。決まっていなければ、光る紋だけで作ります。
  - 結びの言葉はM1（「職をつぐ旅は、ここから続いていく」）と近いので、続けて見たときに同じに聞こえないよう言い回しを分けます。
- **試作（2026-11-08）**: Studioの [`story-movies/ch2-harvest/`](../../../Storybook_Character_Studio/story-movies/ch2-harvest/README.md)。約20秒・5場面（守った田／収穫祭／二冊の書／荒れる沖／結び）。字幕は勝利会話の台詞から語の順を変えずに抜き出し、結びは「職をつぐ旅は、まだ続く。」にした。③はM2で決めた農民・料理人の書を浮かべる。④の海の中の影は稲光の一瞬だけ、船は影だけ、嵐は沖だけ。最後にタイトル「第2章・完／荒れた田の村」。

### M2 書の復活（共通の型・小・6～8秒×5）

- **目的**: 職が戻る瞬間を、毎回同じ型で気持ちよく見せる。
- **場面**:
  1. 白紙の書が開く。
  2. ページに光の文字が戻る。
  3. その職の道具が光の中に浮かぶ（鍬・鍋・舵・槌・薬草など）。
  4. 書の名前を表示する。
- **作り方**: 型は1つにして、書の色・紋章・道具の絵だけを差し替える。
- **準備が必要なもの**: 農民の書など5冊の見た目（表紙の色・紋章）。職業の書（深緑・金の開いた本）と区別できる意匠を、Studioで決める。M9の③でも使う。2026-11-08にM2の試作で作り、ユーザーが承認した：農民＝土色に金の稲穂、料理人＝朱赤に金の鍋、船乗り＝紺に金の舵輪、鍛冶屋＝鉄色に銅の金床と槌、僧侶＝生成りに朱のしずくと葉。定義は Studioの `story-movies/shared/books.py`。
- **試作（2026-11-08）**: Studioの [`story-movies/book-revival/`](../../../Storybook_Character_Studio/story-movies/book-revival/README.md)。約7秒・1場面（白紙の書が開く→光の文字→紋章→道具が浮かぶ→閃光→書の名前）。5冊分のページを同じ型で書き出す。字幕はゲームの今の復活の小窓の文と、各書の `revivedDesc`。

### M4 旅立ち「ジパング復興編・完」（大・30～35秒）

- **目的**: 第1～3章の総まとめと、島からの船出。第4～5章（M5）へつなぐ。
- **場面**:
  1. 復興した島（田・食堂・灯台・社）を朝の光で見渡す。
  2. 島に残るピノ・イナホ・ジンベエ。
  3. 船に乗るシオン・ミナ・ゴンタ・ワタリ。桟橋で見送る人々。
  4. 灯台の光の先、水平線へ進む帆。
  5. タイトル「ジパング復興編・完」。
- **字幕案**: 今の結末文（`chapter3.js` の `ending`）から。例:「漂着した者は、船をつくる者になった。」「職をつぐ旅は、海の向こうへ続いていく。」
- **注意**: 「漂着した見習い神官」から始まる今の文の流れを、絵の順番に合わせる。クリア後に `CH3_DONE` でワタリと話すと、もう一度見られる（今の再演の仕組みをそのまま使う）。M9の荒れた夜の海と対になるよう、晴れた朝の海にする。
- **試作（2026-11-08）**: Studioの [`story-movies/ch3-departure/`](../../../Storybook_Character_Studio/story-movies/ch3-departure/README.md)。約35秒・5場面（復興した島／島に残る三人／船出／灯台の先へ／海の向こうへ）。字幕は結末文の行を順番どおりそのまま使い、最後の「ジパング復興編・完」はタイトルで表す。結末文の「白紙の書に文字が戻るたび…」の2行は、三人の場面の前半に置いた。

### M5 火山島編の始まり「海を越えて」（大・25～30秒）

- **目的**: 第4～5章は別のゲームとして単独で始まり、プロローグがありません。初めて遊ぶ人にもシオンたちのことが分かるようにし、火山島への到着を見せる。
- **場面**:
  1. これまでの旅を短く（ダーマ神殿から脱出した少年、ジパングの復興）。プロローグとM4の絵を小さく使う。
  2. 長い航海。物資が尽きていく船上の四人。
  3. 灰の匂いの風と、煙を上げる黒い島影。
  4. 焼けた船着き場。
- **字幕案**: 今の導入会話（`chapter4.js` の `intro`）の地の文と、第4章の開始状態の説明から。例:「……潮風が、変わった。灰の匂いをふくんだ風。」
- **注意**: ムービーを見た後は、導入会話の振り返り（「思い出すのう…」の2行）を短くする。最後の「だれか、いるの……？」とカヤとの出会いは会話に残す。
- **試作（2026-11-08）**: Studioの [`story-movies/ch4-arrival/`](../../../Storybook_Character_Studio/story-movies/ch4-arrival/README.md)。約29秒・5場面（神殿からの見習い／ジパングの復興／長い航海／灰の風／焼けた船着き場）。場面①・②はプロローグとM4の絵を思い出の額にそのまま入れた。字幕はすでにある文だけ：プロローグの字幕、職業の書の振り返り2行、第3章の結末文の最後の行、導入会話の地の文、火山島編のタイトル画面の一文。最後にタイトル「職をつぐ者／火山島編／第4章　鬼火の山」。移植するときは、導入会話の地の文と振り返り2行を外すか短くする。

## ゲームへの組み込み（2026-11-08）

7本すべてを両編へ組み込みました。入る場所は上の表のとおりです。

- **ファイル**: Studioで生成したムービー（`story-movies/<名前>/index.html`）を、Studioの `npm.cmd run sync:movies` で各編の `assets/movies/` へ写します（書き出し先は Studioの `story-movies/game-targets.mjs`）。第1～3章はM0・M1・M9・M4と書の復活3冊（農民・料理人・船乗り）、第4～5章はM5・M7と書の復活2冊（鍛冶屋・僧侶）。ムービーを作り直したら、生成の後にもう一度写します。Studioのテストが、ゲームの写しが生成物と同じであることを確かめます。
- **再生**: 両編共通の `game-shared/story-movies.mjs`。ムービーは自己完結HTMLのまま、ゲームの上に全画面の iframe で重ねます（`?autoplay=1` で開くので、単体で開いたときの開始パネルは出ません）。読み込むのは再生するときだけで、ビルドではファイルがそのまま `dist/assets/` に出ます。各編の名前とファイルの対応は `src/content/movies.js`。
- **一時停止**: 再生中は `ui.modalOpen` に含めて、入力と世界の時間を止めます。3Dの描画も止めます。
- **操作**: ムービーの操作（クリック・Space・Enter で次の場面、Esc・「スキップ」で終わり）はそのまま。終わるとゲームへ戻ります。
- **流せないとき**: 読み込めない・15秒以内に開かないときは、流さずに進みます。導入会話は全文、書の復活は今までの小窓を出します。章末は文字を出さずに次へ進みます（全画面で文字が流れる章末は、2026-11-08にユーザーの判断で削除。全文は[削除した文字の章末](../reference/removed-text-endings.md)に記録）。進行は変わりません。
- **会話との重なり**: ムービーを最後まで見たときだけ、字幕と同じ内容の会話の行を省きます（M0・M5の導入、M9の書の最後の台詞）。台詞の文言は変えていません。詳細は[不整合一覧のSTORY-008](../inconsistencies.md#story-008)。
- **テスト**: 各編の通しテストは、`tests/helpers.mjs` の `openGame` の既定でムービーを止め（`window.__SHOKU_SKIP_MOVIES__`）、ムービーなしで進めます。ムービー自体は各編の `tests/e2e/movies.test.mjs`（高速テストにも含む）が、再生中の一時停止、最後まで見たとき・スキップしたときの会話、書の復活、全ムービーの読み込み、読み込めないときの扱いを確かめます。章末のムービー中にセーブできないこと（第4～5章の `raid-save.test.mjs`）と入力が止まること（`quality-input.test.mjs`）も確かめます。ブラウザーで止めたいときは、localStorage の `shoku_movies` を `off` にします。
- **未対応**: タイトル画面からもう一度見る機能と「見た」記録。ムービーの音（BGMは通常の曲が流れ続ける）。スマートフォン実機での確認。
