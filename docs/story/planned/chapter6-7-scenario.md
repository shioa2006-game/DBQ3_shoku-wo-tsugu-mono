# ダーマ再興編・第6～7章シナリオと共通設計

[資料の入口](../README.md) / [第6章](chapter6.md) / [第7章](chapter7.md)

2026-11-03、会話で検討した内容を集約した未実装の制作計画。両章に共通する人物・世界設定・演出方針と未決事項の参照先とする。章ごとの出来事と建築・戦闘の進行は各章資料に記す。

## 物語の流れ

第1～3章でジパングの暮らしを復興し、ピノ・イナホ・ジンベエへ島を託したシオンたちは、第4～5章で火山島の鍛冶と癒やしを取り戻した。旅を続けるシオン・ミナ・ゴンタ・ワタリは、シオンが逃れた旧ダーマ神殿のある島へ戻る。

第6章では、ダーマの住民と暮らしの拠点を作り、山の採石洞で大岩ガニを倒して祭壇の要石を切り出す。ワタリが迎えたピノと大屋根を架け、旧神殿を元の場所に再建する。工事を通して大工の道を選んだ若者への授職で章を結ぶ。

第7章では、職と技術が再び広まることを阻もうと魔物が襲来する。地上の波状攻撃を退けた後、三頭竜に神殿を壊されながらも反撃で退かせる。神殿本体を補修し、初戦から学んだ対策を施して、同じ三頭竜との最終決戦に勝つ。

## 合意した制作方針

| 対象 | 方針 |
|---|---|
| 舞台 | ジパング・火山島とは別の島。一方が海に接し、奥へずっと山が続く。旧ダーマ神殿を同じ場所へ再建する |
| 人物 | 旅の4人にダーマの新キャラクター3人以上を加える。旧友は必要な技術に応じてワタリが迎える。第6章ではピノを呼ぶ |
| 第6章のボス | 採石洞に棲む大岩ガニ。討伐後に職人と祭壇の要石を切り出す |
| 第7章の敵の目的 | 職と技術が神殿から再び人々へ広がることを阻止する |
| 最終ボス | 三頭竜。初襲来で神殿を攻撃し、一度退いた後、最終決戦で再登場する |
| 初襲来の退却理由 | こちらの反撃で退かせる。ゴンタが低空へ降りた竜の翼をボウガンで射る場面を現行演出案とする |
| 防衛 | 通常戦闘・とげ罠・据え付け式ボウガンを組み合わせる。各波の間に修理と補給を行い、プレイヤーの合図で次へ進む |
| 神殿の損傷 | 壁・屋根も壊れ、神殿本体を補修する。神殿中枢の耐久が尽きると敗北する |
| シオン | 神官見習いとして再建後の最初の授職を務める。第3章でジンベエへ役割を託した経験を引き継ぐ |
| ビルダーの書 | 話す相棒として両章に登場する。結末案では原本をシオンが携え、設計図と仕事の記録の写しをダーマへ残す |
| 船の演出 | ワタリと船の出航・帰港は、海岸が見えない場所でのイベントに合わせて反映する |

当初選んだ「第6章はボスなし」は、洞窟探索の追加時に「大岩ガニとの一戦あり」へ更新した。第6章の山場は神殿完成と最初の授職とする。

## ダーマの人物

新キャラクターの名前・外見・年齢・性格は今後決める。以下の呼び方は役割を示す仮称。

| 人物 | 第6章の役割 | 第7章へのつながり |
|---|---|---|
| 水運びをしていた住民 | 神殿へ通う古い坂道を案内。石段を登れなかった人の記憶を語り、横の入口・水場・休める部屋を作るきっかけになる | 神殿と集落を結ぶ道を知る。避難や水の確保での具体的な出番は今後設計する |
| 大工に憧れる若者 | 足場作りを手伝い、ピノから梁の組み方を学ぶ。章末に大工の道を選び、最初の授職を受ける | 初襲来で傷ついた屋根を自分から直そうとする。第6章の選択を行動で示す |
| 山の石切り職人 | 採石洞と石目を知り、要石の切り出しを助ける。崩壊後は斜面の落石を取り除いて暮らしていた人物という案 | 石材確保や補修への協力が候補。担当する作業の詳細は今後設計する |

地元住民は襲撃時に神殿周辺で暮らしていた人々。シオンが「神殿にいた人々の中では唯一の生存者」という設定と両立する。石切りや運搬の知識を持つ人も、大規模神殿の建築と授職を自力で再開できずにいた。大工に憧れる若者が工事を通して学ぶ過程を描く。

## 旅の一行と旧友

| 人物 | ダーマでの役割 |
|---|---|
| シオン | 帰還、探索、神殿の建築と補修、授職、最終決戦を担う |
| ミナ | 食と暮らしを支え、地元住民と復興拠点を整える。食料・畑の必須工程は今後決める |
| ゴンタ | 山道と工事中の安全、防衛を担う。三頭竜への反撃で次戦の勝機を作る |
| ワタリ | 航路と輸送を担い、必要な技術を持つ旧友を船で迎える |
| ピノ | 第6章途中で合流。大屋根の棟梁となり、地元の若者に技術を伝える |

イナホ・ジンベエや火山島の仲間の追加招聘は、必要な役割がシナリオで生じた時に検討する。ピノの留守中にジパングの建物を誰が手入れするかは、短い帰還報告などで補う必要がある。

## シオンとビルダーの書

シオンは神官見習いの立場で最初の授職を取り仕切る。本人が職を選び、シオンがその意思を聞いて授け、住民が立ち会う構成にする。正式な神官への昇格儀式は今回のシナリオに設定していない。見習いと授職の関係は第3章の経験を踏まえ、最終台詞の作成時に確認する。

| 場面 | 書の役割・演出案 |
|---|---|
| 神殿跡への帰還 | 祭壇を急いで直そうとするシオンに、ジパングで最初に建てた小屋を思い出させる。共同小屋の建築につなぐ |
| 最初の授職 | 書を開いたシオンに、若者本人の顔を見て話を聞くよう促す。シオン自身の言葉で授職を行う |
| 戦後の旅立ち | 設計図と仕事の記録の写しを残し、書の原本は相棒としてシオンと旅を続ける |

台詞の例文は演出の方向性として扱い、逐語の脚本は今後作る。第5章までの復活済みの六種（ビルダー・農民・料理人・船乗り・鍛冶屋・僧侶）を前提とする。大工・神官の役割と書の種類を区別する。

## 地形とゲームの境界

海岸・桟橋から、麓の集落、山道、神殿、採石洞へ進む。第6章の神殿と周辺設備を第7章でも使用する。海岸から神殿跡の柱を見上げ、章末には同じ方向に完成した大屋根を見る演出を目指す。

左右を崖や深い谷、奥を露出した岩壁にする配置は提案段階。採石洞は山の横腹に設け、船の出入りを隠せる尾根裏の場所を用意する。カメラ回転、足場建築、掘削でも境界を越えない方法、洞窟内の視認性は実装前に設計する。海側の方角、寸法、標高差は未決定。

制作単位は親内の `dqb3-tsugumono-ch6-7/`。第5章までを踏まえた固定初期状態と専用セーブ領域を使う従来方針を引き継ぐ。具体的なセーブキー・初期装備・資材数は未決定。
