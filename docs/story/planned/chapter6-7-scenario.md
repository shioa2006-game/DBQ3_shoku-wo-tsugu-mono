## 物語の流れ

ジパングの暮らしを復興して島を仲間に託し、火山島の鍛冶と癒やしを取り戻したシオン・ミナ・ゴンタ・ワタリは、旧ダーマ神殿のある島へ戻る。

第6章ではスズハ・アサギ・ガンゾウと暮らしの拠点を作る。ワタリがピノを迎える間に採石洞へ入り、大岩ガニを倒して祭壇の要石を切り出す。住民と石を運び、大屋根を架けて神殿を再建する。アサギが大工の道を選び、神官見習いのシオンが最初の授職を務める。

第7章では、職と技術の広がりを阻もうと魔物が襲来する。地上の3波を退けた後、旧神殿を破壊した張本人、三頭魔竜ヴァルガの初襲来を受ける。反撃で退かせ、ワタリがベルクを迎える間に神殿を修理する。ピノとベルクの大型対空ボウガンを完成させ、最終決戦でヴァルガを地上へ降ろし、三つの頭を倒す。

戦後は祭壇・入口などを修復し、シオンがスズハへ神官の務めを託す。ピノはアサギへ仕事を託して帰郷する。各地の暮らしを映した後、旅の4人とビルダーの書は、世界中に残る職業の書を探す旅へ船出する。

## 決定した制作方針

| 対象 | 方針 |
|---|---|
| 舞台 | ジパング・火山島とは別の島。一方が海に接し、奥へずっと山が続く。旧神殿を同じ場所へ再建する |
| 神殿 | 石造りの本堂に木組みの大屋根を架ける。横の入口、水場、休める部屋、共同台所、書庫を備える |
| 仲間 | 旅の4人と新キャラ3人。第6章でピノ、第7章の初襲来後にベルクを招聘する |
| 通常敵 | 新規3種（岩角ヤギ・糸吐きグモ・岩砕きの石兵）＋流用2種（山ねずみ・洞窟こうもり）。ボスは別枠の2種 |
| 採石洞 | 足場・橋の補修と明かりで道を開く。ボスは大岩ガニ。爪の振り下ろしをかわし、横腹を狙う |
| 要石 | 職業の書と祭壇をつなぐ働きがある。切り出し後に搬出路を補強し、住民と運んで祭壇へ据える |
| 選択の柱 | 祭壇と別の記念の柱。第6章にアサギの大工の印を刻み、第7章の修復中に皆の仕事の印を加え、最終決戦前に完成させる |
| 最終敵 | 三頭魔竜ヴァルガ。旧神殿を破壊した張本人で、グロムは配下。職と技術が再び人々へ広まることを阻止する |
| 敵の言葉 | ヴァルガは人の言葉を話す。登場・退却・最終決戦の節目に短い言葉で意思を示す |
| 第6章末 | 完成と授職を十分に祝った後、遠い咆哮と三つ首の影を見せる。名前と本人の言葉は第7章で明かす |
| 地上防衛 | 小型の群れ、壁を壊す大型敵、混成部隊の3波。修理と補給後のプレイヤーの合図で次へ進む |
| 初襲来 | シオンが低く降りた首を攻撃して隙を作り、ゴンタが翼を射抜いて退かせる |
| ボウガン | 通常型は設置した向きへ自動射撃。ベルクと作る大型対空型はプレイヤーが射台で狙って撃つ |
| 最終決戦 | 大型対空ボウガンで地上へ降ろして直接戦闘。頭ごとに耐久があり、倒した頭の火炎が止まる。三つの頭を倒すと勝利 |
| 防衛対象 | 要石を据えた祭壇を神殿中枢とする。耐久が尽きると授職の灯りが消え、防衛失敗となる |
| 修理 | 壁・屋根も壊れる。足りないブロックを半透明の修復ガイドに沿って補う |
| 敗北時 | その戦いの開始直前の準備状態へ戻す。建物・資材・装備を復元し、突破済みの波はクリア済みとする |
| 勝利時 | 損傷を修理段階へ引き継ぐ。初襲来の後も、守れた建物と損傷が残る |
| 授職 | 主要人物の選択と仕事を物語イベントで描く。第6章末にアサギ、戦後にスズハが役割を引き継ぐ |
| 結末 | 神殿再開、スズハへの継承、ピノの帰郷、各地の暮らしを経て、世界中の職業の書を探す出航で締める |

初期の「第6章はボスなし」は採石洞の大岩ガニ戦の採用で更新済み。旧案との差分は末尾と[整理記録](../inconsistencies.md)を参照する。

## 敵キャラクター

通常敵は新規の基本造形3種と、既存造形を生かす流用2種の計5種。色替えは流用として数える。第6章の大岩ガニと第7章の三頭魔竜ヴァルガを別枠に置き、登場する敵は計7種とする。

| 敵 | 制作方針・外見 | 主な出番 | 行動と役割 |
|---|---|---|---|
| 岩角ヤギ | 新規。灰褐色の毛と岩のような太い角 | 第6章の山道、第7章の群れ | 足を踏み鳴らしてから短く突進。かわした後に隙ができる |
| 糸吐きグモ | 新規。濃紺の脚と白い腹を持つ大グモ | 第6章の採石洞、第7章の混成部隊 | 岩陰から糸を吐き、短時間こちらの移動を鈍らせる。接近されると弱い |
| 岩砕きの石兵 | 新規。ずんぐりした石の体と、槌のような大きな両腕 | 第7章の大型敵 | 動きは遅いが門や壁を狙って壊す。振りかぶる間に止めたい相手 |
| 山ねずみ | おおねずみの造形を流用・色替え | 第6章の山道、第7章の群れ | 素早く群れる。罠やボウガンの射線へ誘導する相手 |
| 洞窟こうもり | おおこうもりの造形を流用・色替え | 第6章の採石洞 | 坑道で接近し、探索・採掘を妨げる |
| 大岩ガニ | 第6章ボス。岩に紛れる大きな甲羅と二本の爪を新規制作 | 採石洞奥の採石場 | 爪の振り下ろしをかわし、横腹を狙う |
| 三頭魔竜ヴァルガ | 第7章ボス。三つの頭と大きな翼。グロムのドラゴン構造を生かす構想 | 初襲来、修理と対策後の最終決戦 | 火炎で神殿を広く攻撃。最終戦は対空射撃で地上へ降ろし、頭ごとの耐久を削る |

第7章は第1波に山ねずみと岩角ヤギ、第2波に岩砕きの石兵を中心とする大型敵、第3波に糸吐きグモを加えた地上4種の混成を配置する。洞窟こうもりは採石洞を主な出番とする。具体的な出現数・配置は実装設計で決める。

当初の岩トカゲ・石甲サソリを含む「新規1種＋流用4種」案から更新した。新規通常敵の外見と役割を山道・洞窟・防衛戦に分ける。石兵の成り立ち、ヴァルガの配色、各敵の数値・ドロップ・詳細な動作は実装担当が具体化する。

## ダーマの人物

名前はスズハ・アサギ・ガンゾウに決定。人物像の基本案は以下。正確な年齢、外見、衣装、台詞の細部は今後制作する。

| 人物 | 基本の人物像 | 第6章 | 第7章・結末 |
|---|---|---|---|
| スズハ | かつて神殿へ水を運んでいた、世話好きな中年女性。山道と暮らしを知る | 坂道を案内し、横の入口・水場・休める部屋を作るきっかけになる。最初の授職に立ち会う | シオンに学び、人々を迎える。戦後に自分から神殿を引き受けたいと申し出て、神官の務めを継ぐ |
| アサギ | 大工に憧れるせっかちな若者。まず手を動かすが、大建築の経験は浅い | 足場を手伝い、ピノに梁の組み方を学ぶ。自分で屋根を直せる大工を志して授職を受ける | 初襲来後に自分から補修へ取りかかる。戦後、ピノに直した屋根を確かめてもらい、仕事を託される |
| ガンゾウ | 寡黙な年配の石切り職人。石目と山の危険を知り、崩壊後は落石を取り除いてきた | 採石洞を案内。くさびの位置を示し、シオンと要石を切り出して搬出する | 補修用の石材を支える。再び建物を作り、保つための仕事に取り組む |

地元の3人は神殿周辺で暮らしていた人々。シオンが「襲撃時に神殿にいた人々の中では唯一の生存者」という設定と両立する。石切りや運搬の知恵を生かし、建築と授職の技術を旅の仲間から学ぶ。

## 旅の一行と招聘する旧友

| 人物 | ダーマでの役割 |
|---|---|
| シオン | 帰還、探索、神殿の建築と補修、授職、ヴァルガとの決着を担う |
| ミナ | 共同台所と工事の食事を担当。地元食材を使い、第7章では防衛の食料補給を支える |
| ゴンタ | 山道と工事中の安全を守り、防衛に加わる。初襲来で竜の翼を射抜く |
| ワタリ | 航路・輸送を担う。第6章はピノ、第7章の初襲来後はベルクを船で迎える |
| ピノ | 大屋根の棟梁となりアサギを教える。最終決戦後まで残り、仕事を託してジパングへ帰る |
| ベルク | 大型対空ボウガンの金属機構を作り、ピノの射台と組み合わせる。火山島で取り戻した鍛冶が神殿を守る |

ピノはジパングで受け継いだ建築の記録や書の写し、ベルクは火山島の鍛冶・癒やしの記録や書の写しを持参する。各地の書の知恵が集まる場にする。ピノの留守中のジパングの手入れ、ベルク帰郷の細かな時期・航路は実装前に補う。

## シオン・スズハとビルダーの書

シオンは神官見習いとして、本人の意思を聞いて授職を取り仕切る。第3章でジンベエへ役割を託した経験を引き継ぐ。第6章でスズハが授職に立ち会い、第7章はシオンから学びつつ人々を迎える。最終決戦後、神殿を再開できる状態へ修復してから、スズハへ神官の務めを託す。

| 場面 | ビルダーの書の役割 |
|---|---|
| 旧神殿への帰還 | 祭壇を急いで直そうとするシオンに、ジパングで最初に建てた小屋を思い出させる |
| 最初の授職 | 書を開いたシオンへ、アサギ本人の顔を見て話を聞くよう促す |
| 継承の準備 | シオンが写しを作り、各地の書の写し・仕事の記録とともに書庫へ残す。スズハと住民が学び続ける支えになる |
| 最後の出航 | 相棒として原本がシオンと旅を続ける。世界にはまだ出会っていない職業の書があると、新しい旅へつなぐ |

第1～5章で復活済みの六種は、ビルダー・農民・料理人・船乗り・鍛冶屋・僧侶。これは今回の旅で扱った範囲であり、世界にはさらに職業の書が残る。大工・神官の役割は独立した書の種類と区別する。神殿では写しと仕事の記録を学び、要石を据えた祭壇で授職を続ける。写しを介する力の細かな設定と、主要イベント以外の授職の描写は今後詰める。

## 地形・船・ゲームの境界

海岸・桟橋から、麓の集落、山道、神殿、採石洞へ進む。海岸から神殿跡の柱を見上げ、章末には完成した大屋根を望む。左右の崖・谷と奥の岩壁は地形案。方角・寸法・標高差、足場や掘削でも境界を越えない方法、洞窟内の視認性は要設計。

2回の招聘とも、海岸と対象NPCが見えない場面で船・人物の出入りを反映する。航海中の海岸には船がいない。第6章は採石洞探索・搬出準備、第7章は修理・対空射台の準備で航海中の時間を描く。帰港条件の詳細とセーブ・ロードの整合は章資料と実装設計で詰める。

制作単位は `dqb3-tsugumono-ch6-7/`。第5章までを踏まえた固定初期状態と専用セーブ領域を使用する。具体的なセーブキー・初期装備・所持資材は未決定。

## 実装担当へ委ねる設計

素材・採集場所・ドロップ・クラフトレシピ・装備・料理・回復アイテム・資材量・戦闘数値・設計図の寸法・操作・細かな演出は、ここに記したシナリオ、人物と敵の役割、章進行と勝敗条件に合わせて実装担当が自律的に設計する。

設計したアイテムと仕様は制作資料へ記録し、通し進行に加え、資材不足からの復帰、戦闘敗北後の再挑戦、途中セーブ・ロードを確認する。第4～5章を土台にする際は、進行中のキャラクター移植が完了したコミットを基準にすることを推奨する。
