2026-11-14作成の制作計画です。第6～7章（ダーマ再興編）はゲームが未実装で、ムービーもまだ作っていません。同日、ユーザーが**作る5本を決めました**（[採用した5本](#adopted)）。

同日追記: ヴァルガは海の向こうからガーゴイル軍を率いて来ると決めたので、M11とM12の向きを海へ直しました。M14には、ピノとベルクをそれぞれの島へ送り届ける航海と、最後の表示を加えました。

作り方・長さの3段階・操作・今ある演出との関係は、[第1～5章の計画の「方針」](story-movies.md)を引き継ぎます。

## 制作の順序

第6～7章は、次の順に作ります。

1. **キャラクター**: Studioで登場人物と敵の作画を仕上げる（スズハ・アサギ・ガンゾウ、敵の各種、ヴァルガなど）。
2. **ストーリー資料**: シナリオ・章資料・このムービー計画を仕上げる。
3. **ショートムービー**: Studioで5本を作る。
4. **ゲーム**: 第6～7章のゲームを作り、ムービーを組み込む。

ムービーがゲームより先にできるので、ムービーで決めた絵（ダーマの島、崩れた神殿跡、再建した神殿の形）がゲームの地形・設計図の手本になります。逆に、ゲームの都合で形を変えるときは、ムービーも作り直します。

## 第1～5章との違い

- **字幕を新しく書く**: 第1～5章では、実装済みの台詞・結末文から字幕を取りました。第6～7章はゲームより先に作るので、字幕を新しく書きます。書いた字幕は、ゲームの会話を書くときの基準になります。
- **会話との重なり**: 字幕と同じ文を、前後の会話で続けて流さないようにします。ムービーを飛ばしたとき・流せないときにも話が通じるよう、要点（ヴァルガの名乗りなど）は会話にも用意し、最後まで見たときだけ省きます（[STORY-008](../inconsistencies.md#story-008)と同じ方式）。
- **書の復活（M2）はない**: 第6～7章では新しい書が復活しません。アサギとスズハの授職・継承は、ゲームの会話と場面で描きます。
- **音はない**: 第1～5章と同じく、ムービーに音はありません。第6章末の「遠い咆哮」は、灯の揺れ・山の震え・飛び立つ鳥・文字の効果などで見せます。
- **Studioの一覧への登録**: Studioの一覧（`story-movies/catalog.mjs`）とテストは、[第1～5章の計画](story-movies.md)の「採用した7本」の表を照合しています。第6～7章の5本は、Studioで作り始めるときに一覧・テストと合わせて登録します。それまではこのページで管理します。

## 各ムービーの内容

### M10 ダーマ再興編の始まり「始まりの場所」（大・25～30秒）

- **目的**: 第6～7章は別のゲームとして単独で始まります。初めて遊ぶ人にもこれまでの旅が分かるようにし、旧ダーマ神殿の島への到着を見せます。火山島編のM5と同じ役割です。
- **場面**:
  1. これまでの旅: 神殿からの脱出（プロローグ）、ジパングの復興（M4）、清めの泉（M7）の絵を、M5と同じ思い出の額に小さく入れる。
  2. 夜明けの海: 船に乗るシオン・ミナ・ゴンタ・ワタリ。シオンは背中のホルダーに職業の書を入れている。
  3. 海から山へ続く島: 一方が海に接し、奥へずっと山が続く島影。
  4. 神殿跡: 山腹に、屋根を失った二本の柱。プロローグ第3場面・M7の神殿の影と同じ形の、崩れた姿。
  5. 着岸: 桟橋に船が着く。タイトル「職をつぐ者／ダーマ再興編／第6章　よみがえるダーマ神殿」。
- **字幕の方針**: ①はプロローグとM7の字幕（「そして 職をつぐ者は、船に乗る。」「すべてが失われた、始まりの場所へ。」など）を使える。新しく書く字幕は、帰ってきたシオンの気持ちと、神殿跡を見上げる場面に絞る。
- **見せないもの**: スズハとの出会い（導入会話に残す）、再建した神殿の姿、ヴァルガ。
- **注意**: M7は夜の海で終わるので、M10は夜明けの海で始めて続きに見えるようにする。

### M11 第6章の結び「大屋根の灯」（中・15～20秒）

- **目的**: 第6章を神殿の完成と最初の授職の喜びで締めくくり、最後に第7章の脅威を短く見せて、章と章の間をつなぎます。
- **場面**:
  1. 灯のともる祭壇: 要石を据えた祭壇に授職の灯がともる。そばの選択の柱に、アサギの大工の印。
  2. 祝いの夜: 共同台所の前で、ミナの料理を囲む人々（シオン・ミナ・ゴンタ・ワタリ・ピノ・スズハ・アサギ・ガンゾウ）。
  3. 海岸から望む神殿: 灯のともった大屋根が山腹に浮かぶ。
  4. 遠い咆哮: 海の向こうから咆哮が届き、灯が揺れ、鳥が飛び立つ。月の光る沖を、ガーゴイルの群れを従えた三つ首の影が横切る。
  5. タイトル「第6章・完／よみがえるダーマ神殿」。
- **字幕の方針**: 祝いの言葉と、職業の書の短い言葉。④は字幕を置かないか、ごく短くする。
- **見せないもの**: ヴァルガの名前・全身・色、ガーゴイルの姿（どちらも影の輪郭だけ）。授職の場面そのもの（シオンがアサギの話を聞くところはゲームの会話で描く）。
- **ねらい**: ④でヴァルガが軍勢を率いて海の向こうから来ることを示し、第7章でガーゴイル軍が先に攻めてくることの予告にする。
- **注意**: スキップしても進行は変わらない。①の祭壇と柱、③の大屋根は、ゲームの神殿の設計図と同じ形にする。

### M12 三頭魔竜の襲来「三つ首の影」（小・6～8秒）

- **目的**: 先兵のガーゴイル軍の3波を退けた後、軍勢を率いる竜が自ら海を越えて現れる瞬間を印象づけ、ここで名前を明かします。旧神殿を壊した竜が、初めて姿を見せる場面です。
- **場面**:
  1. 海の向こうの空が暗くなり、水平線から三つ首の竜が飛んでくる。
  2. 三つの頭が大屋根を見下ろし、火を噴く構えをとる。
  3. 名乗り: 竜が自ら名を告げる字幕。
- **字幕の方針**: ヴァルガの言葉は短くする。記録から削られた名を自ら告げ、職を受け継ぐ人々への恐れと、職と技術が再び広まるのを許さない意思がにじむ一言にする（例:「我が名は ヴァルガ。」）。最終的な台詞は制作時に決める。
- **見せないもの**: 戦いの結果（シオンの反撃とゴンタの一撃による退却はゲームで描く）。ガーゴイル（ボス戦にガーゴイルが加わるかはゲームの設計に任せるため、M12にはヴァルガだけを描く）。ゾーマや大穴との関係（物語では語らない）。
- **注意**: シオンが「神殿を壊した竜だ」と気づくのは直後の会話。名乗りは直後の会話にも用意し、最後まで見たときだけ省く。第1～5章で見送ったM3（強敵の出現）と同じ型だが、第7章では名を明かす場面なので採用した。

### M13 最終決戦の決着「灯は消えず」（中・10～20秒）

- **目的**: 三つの頭を倒した決着を見せ、祭壇の灯が守られたことを伝えます。
- **場面**:
  1. 三つ目の頭が倒れ、竜の巨体が崩れ落ちる。
  2. 煙が晴れる。傷ついた屋根と壁の奥で、祭壇の灯がともり続けている。
  3. 朝の光: 大型対空ボウガンの射台、選択の柱、集まってくる仲間と住民。
- **字幕の方針**: ヴァルガの最後の短い言葉と、職業の書かシオンの言葉。
- **見せないもの**: 戦後の修復と、スズハ・アサギへの継承（ゲームで描き、M14へつなぐ）。
- **注意**: 戦いでできた損傷は、ムービーの後も修理段階へ引き継ぐ。ムービーで直った神殿を見せない。崩れ方を第5章のグロム（黒い霧へ崩れ、爪痕の印の黒鱗が残る）と呼応させるかは、制作時に決める。

### M14 ダーマ再興編・完「まだ見ぬ書へ」（大・30～35秒）

- **目的**: ダーマ再興編とこれまでの旅を締めくくり、世界中の職業の書を探す新しい旅へつなぎます。最後の航海で、ピノとベルクをそれぞれの島へ送り届けます。
- **場面**:
  1. 再開した神殿: スズハが訪れた人を迎える。アサギが屋根に上り、ガンゾウが石を運ぶ。桟橋から、旅の4人とピノ・ベルクを乗せた船が出る。
  2. ジパング: 船が寄り、ピノが降りる。イナホ・ジンベエが迎える。田・食堂・社。
  3. 火山島: 船が寄り、ベルクが降りる。ナギ・ロク・カヤ・ヨモギ。炉と社。
  4. 船出: シオン・ミナ・ゴンタ・ワタリと話す職業の書（原本）だけを乗せた船が、その先の海へ進む。
  5. 水平線: タイトル「ダーマ再興編・完」の後、作品名「職をつぐ者」と「完」を出す。
- **字幕の方針**: [第7章](chapter7.md)の台詞の方向性（「世界は広いぞ。まだ出会っておらぬ職業の書が、おぬしらを待っておる。」「探しに行こう。世界中の、まだ知らない職を。」「――職業の書を探す旅は、これからも続いていく。」）をもとに作る。
- **見せないもの**: 次に探す書の種類・数、次の行き先の土地。
- **注意**: 船はM4・M5・M7と同じものを使い、晴れた朝の海にする。②③は、それぞれの島に寄る航海として描く（ピノとベルクは、ダーマから同じ船で帰る）。⑤では、ダーマ再興編の完と、全7章の物語の完を続けて出す。

## 作る順番の提案

1. M10とM14（編の始まりと終わり）。島・神殿跡・再建した神殿・船をここでそろえる。
2. M11（第6章の結び）。M10の島とM14の神殿を使い回す。④の影はヴァルガとガーゴイルの輪郭だけなので、ヴァルガの作画の前でも作れる。
3. M12とM13（ヴァルガが登場する2本）。Studioでヴァルガの作画ができてから作る。

## 共通の準備（Studio）

- **人物**: 2026-11-14確認時点でスズハ・アサギ・ガンゾウの3人とも、Studioに8方向の作画コード・頭胴画像・リグ設定・比較画面がある。必要な最終調整を行い、ムービーへ取り込む。そのほかの人物（シオン・ミナ・ゴンタ・ワタリ・ピノ・イナホ・ジンベエ・ベルク・ロク・カヤ・ナギ・ヨモギ）もStudioにある。[制作一覧](../../../Storybook_Character_Studio/prototypes/README.md#ch6-7)を参照する。
- **敵**: 三頭魔竜ヴァルガ（M11の影・M12・M13）は未制作。グロム（`prototypes/grom-8dir/`）の構造を基に、三頭の外見・リグと飛行・地上表示を用意する。ガーゴイルはM11の影（輪郭だけ）で使い、Studioの飛行姿を基にする。防衛3波そのものはゲーム側の敵構成であり、今回の5本に専用ムービーは追加しない。
- **新しく描く背景・小道具**:
  - ダーマの島（海から山へ続く島影、桟橋、坂道）。
  - 崩れた神殿跡（プロローグ第3場面・M7の神殿の影と同じ形）。
  - 再建した神殿（石造りの本堂、木組みの大屋根、要石を据えた祭壇、選択の柱、共同台所）。
  - 大型対空ボウガンの射台（M13）。
- **使い回すもの**: M4・M5・M7の船、プロローグの神殿、M5の思い出の額、M2で決めた書の意匠（職業の書は深緑・金）。
- **確認**: 第1～5章と同じテスト（静止画・通し再生・スマートフォン・モーション軽減）を各ムービーに付ける。

## ゲームへの組み込み（第6～7章の実装時）

- 第1～5章と同じく、Studioで生成したムービーを第6～7章のゲームの `assets/movies/` へ写す。Studioの書き出し先（`story-movies/game-targets.mjs`）に第6～7章を加える。
- 再生は両編と共通の `game-shared/story-movies.mjs` を使う。
- タイトル画面からもう一度見る機能と「見た」記録は、第1～5章と同じく未対応の扱い。両編で対応するときに合わせて決める。
