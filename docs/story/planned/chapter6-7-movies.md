2026-11-14作成の制作計画です。第6～7章（ダーマ再興編）はゲームが未実装です。ムービーは、5本（M10～M14）すべてをStudioで試作しました（2026-11-14）。同日、ユーザーが**作る5本を決めました**（[採用した5本](#adopted)）。

作り方・長さの3段階・操作・今ある演出との関係は、[第1～5章の計画の「方針」](story-movies.md)を引き継ぎます。

## 制作の順序

第6～7章は、次の順に作ります。

1. **キャラクター**: Studioで登場人物と敵の作画を仕上げる（スズハ・アサギ・ガンゾウ、敵の各種、ヴァルガなど）。
2. **ストーリー資料**: シナリオ・章資料・このムービー計画を仕上げる。
3. **ショートムービー**: Studioで5本を作る。
4. **ゲーム**: 第6～7章のゲームを作り、ムービーを組み込む。

ムービーがゲームより先にできるので、ムービーとゲームのどちらに合わせるかを分けます（[共通設計の分担表](chapter6-7-scenario.md#movie-game-alignment)）。

- **神殿の形はムービーに合わせる**: 崩れた神殿跡（三段の基壇、柱の並び、二本だけ残る柱）と、ムービーで描く再建後の神殿の外観は、ゲームの設計図の手本になります。
- **島の地形と配置はゲームで決めてよい**: 島の向き・寸法・坂道の通り方・桟橋・麓の集落などは、ゲームの設計で決めます。決まった後、M10などの島・坂道・集落をゲームに合わせて描き直します。

## 第1～5章との違い

- **字幕を新しく書く**: 第1～5章では、実装済みの台詞・結末文から字幕を取りました。第6～7章はゲームより先に作るので、字幕を新しく書きます。書いた字幕は、ゲームの会話を書くときの基準になります。
- **会話との重なり**: 字幕と同じ文を、前後の会話で続けて流さないようにします。ムービーを飛ばしたとき・流せないときにも話が通じるよう、要点（ヴァルガの名乗りなど）は会話にも用意し、最後まで見たときだけ省きます（[STORY-008](../inconsistencies.md#story-008)と同じ方式）。
- **書の復活（M2）はない**: 第6～7章では新しい書が復活しません。アサギとスズハの授職・継承は、ゲームの会話と場面で描きます。
- **音はない**: 第1～5章と同じく、ムービーに音はありません。第6章末の「遠い咆哮」は、灯の揺れ・山の震え・飛び立つ鳥・文字の効果などで見せます。
- **Studioの一覧への登録**: 2026-11-14、M10の試作と合わせて5本をStudioの一覧（`story-movies/catalog.mjs`、区分「ダーマ再興編」）に登録しました。Studioのテストは、このページの「採用した5本」の表と「作る順番の提案」も照合します（一覧の作る順では、ここの1～3番を5～7番として並べます）。表や順番を変えたら `catalog.mjs` も直します。

## 各ムービーの内容

### M10 ダーマ再興編の始まり「始まりの場所」（大・25～30秒）

- **目的**: 第6～7章は別のゲームとして単独で始まります。初めて遊ぶ人にもこれまでの旅が分かるようにし、旧ダーマ神殿の島への到着を見せます。火山島編のM5と同じ役割です。
- **場面**:
  1. これまでの旅: 神殿からの脱出（プロローグ）、ジパングの復興（M4）、清めの泉（M7）の絵を、M5と同じ思い出の額に小さく入れる。
  2. 夜明けの海: 船に乗るシオン・ミナ・ゴンタ・ワタリ。シオンは背中のホルダーに職業の書を入れている。
  3. 海から山へ続く島: 一方が海に接し、奥へずっと山が続く島影。
  4. 神殿跡: 山腹に、屋根を失った二本の柱。プロローグ第3場面の神殿と同じ基壇と柱の並びの、崩れた姿（M7の最後の場面の影も同じ形）。
  5. 着岸: 桟橋に船が着く。タイトル「職をつぐ者／ダーマ再興編／第6章　よみがえるダーマ神殿」。
- **字幕の方針**: ①はプロローグとM7の字幕（「そして 職をつぐ者は、船に乗る。」「すべてが失われた、始まりの場所へ。」など）を使える。新しく書く字幕は、帰ってきたシオンの気持ちと、神殿跡を見上げる場面に絞る。
- **見せないもの**: スズハとの出会い（導入会話に残す）、再建した神殿の姿、ヴァルガ。
- **注意**: M7は夜の海で終わるので、M10は夜明けの海で始めて続きに見えるようにする。
- **試作（2026-11-14）**: Studioの [`story-movies/ch6-arrival/`](../../../Storybook_Character_Studio/story-movies/ch6-arrival/README.md)。約30秒・5場面（これまでの旅／夜明けの海／海から山へ続く島／神殿跡／着岸）。①はプロローグ・M4・M7の絵を三枚の思い出の額にし、字幕はプロローグと第3章・第5章の結末文の行。②の字幕はM7と同じ「そして 職をつぐ者は、船に乗る。」「すべてが失われた、始まりの場所へ。」。③④は新しく書いた字幕で、③「あの夜、炎の中から逃れた島。」「シオンは、帰ってきた。」、④「屋根を失った神殿に、二本の柱だけが残っていた。」「職を授ける場所を、もう一度 ここに。」。第6章の導入会話では、これらと同じ文を続けて流さない。⑤は字幕なしでタイトル「職をつぐ者／ダーマ再興編／第6章　よみがえるダーマ神殿」。神殿跡は、プロローグ・M7と同じ三段の基壇と柱の並びで、屋根はなく中央の左右の二本だけが立つ。
- **M7との合わせ（2026-11-14）**: M7の最後の場面の遠景の影は、屋根の一部が残ったプロローグと同じ形だった。続けて見ると一晩で屋根が消えたように見えるため、ユーザーの判断でM7の影を、M10と同じ「屋根を失い二本の柱だけが立つ」形に描き直した。神殿跡の形はStudioの共通部品（`story-movies/shared/temple.py`）にまとめ、M7とM10が同じものを使う。

### M11 第6章の結び「大屋根の灯」（中・15～20秒）

- **目的**: 第6章を神殿の完成と最初の授職の喜びで締めくくり、最後に第7章の脅威を短く見せて、章と章の間をつなぎます。
- **場面**:
  1. 灯のともる祭壇: 要石を据えた祭壇に授職の灯がともる。そばの選択の柱に、アサギの大工の印。
  2. 祝いの夜: 共同台所の前で、ミナの料理を囲む人々（シオン・ミナ・ゴンタ・ワタリ・ピノ・スズハ・アサギ・ガンゾウ）。
  3. 海岸から望む神殿: 灯のともった大屋根が山腹に浮かぶ。
  4. 遠い咆哮: 海の向こうから咆哮が届き、灯が揺れ、鳥が飛び立つ。月の光る沖を、ガーゴイルの群れを従えた三つ首の影が横切る。
  5. タイトル「第6章・完／よみがえるダーマ神殿」。
- **字幕の方針**: 祝いの言葉と、職業の書の短い言葉。④は字幕を置かないか、ごく短くする。
- **見せないもの**: ヴァルガの名前・全身・色、ガーゴイルの姿（どちらも影の輪郭だけ）。授職の場面そのもの（シオンがアサギの話を聞くところはゲームの会話で描く）。
- **ねらい**: ④でヴァルガが軍勢を率いて海の向こうから来ることを示し、第7章でガーゴイル軍が先に攻めてくることの予告にする。
- **注意**: スキップしても進行は変わらない。①の祭壇と柱、③の大屋根は、ゲームの神殿の設計図と同じ形にする。
- **試作（2026-11-14）**: Studioの [`story-movies/ch6-roof-light/`](../../../Storybook_Character_Studio/story-movies/ch6-roof-light/README.md)。約21秒（場面の合計は19.8秒）・5場面（灯のともる祭壇／祝いの夜／海岸から望む神殿／遠い咆哮／結び）。新しく書いた字幕は、①「要石の祭壇に、授職の灯がともった。」「職は、ここから また受け継がれていくのじゃ。」（2行目は職業の書）、②「神殿の完成と、はじめての授職に――乾杯！」、③「大屋根の灯が、海まで照らしておる。」（職業の書）、④「――海の向こうから、遠い咆哮。」。⑤は字幕なしでタイトル「職をつぐ者　ダーマ再興編／第6章・完／よみがえるダーマ神殿」。②は左からガンゾウ・スズハ・ワタリ・シオン・アサギ・ゴンタ・ピノが膳を囲み、ミナが鍋を運ぶ。④の三つ首の影とガーゴイルの群れは、Studioの造形の輪郭だけを影にした。
- **再建した神殿の外観（M11で描いた。ゲームの設計図の手本）**: 崩れた神殿跡と同じ三段の基壇と柱の並びに、段積みの石の本堂。9本の柱の並びの中央（左から5本目の柱の位置）を大きなアーチの入口にし、両脇に、崩れずに残った二本の古い柱を生かす。壁の上に木の梁と組物、四隅の反った木の板葺きの大屋根、正面の入口の上の破風に職業の書の紋章。軒に提灯。祭壇は本堂の中の二段の石の台で、前の面の中央に青みの要石（職業の書の紋章）、上に授職の灯の石皿。選択の柱は祭壇の右に立つ四角い石の柱で、仕事の印を刻む枠が縦に並ぶ（第6章ではアサギの大工の印だけ）。共同台所は神殿の右手前（石の腰壁・木の壁・わら屋根・かまど）。Studioの共通部品 `story-movies/shared/temple.py` の `temple_rebuilt()` で描き、M14でも同じものを使う。

### M12 三頭魔竜の襲来「三つ首の影」（小・6～8秒）

- **目的**: 先兵のガーゴイル軍の3波を退けた後、軍勢を率いる竜が自ら海を越えて現れる瞬間を印象づけ、ここで名前を明かします。旧神殿を壊した竜が、初めて姿を見せる場面です。
- **場面**:
  1. 海の向こうの空が暗くなり、水平線から三つ首の竜が飛んでくる。
  2. 三つの頭が大屋根を見下ろし、火を噴く構えをとる。
  3. 名乗り: 竜が自ら名を告げる字幕。
- **字幕の方針**: ヴァルガの言葉は短くする。記録から削られた名を自ら告げ、自分がダーマを焼いたことも告げる。職を受け継ぐ人々への恐れと、職と技術が再び広まるのを許さない意思がにじむ言葉にする（例:「我が名は ヴァルガ。ダーマを焼いた者だ。」）。最終的な台詞は制作時に決める。
- **見せないもの**: 戦いの結果（シオンの反撃とゴンタの一撃による退却はゲームで描く）。ガーゴイル（ボス戦にガーゴイルが加わるかはゲームの設計に任せるため、M12にはヴァルガだけを描く）。ゾーマや大穴との関係（物語では語らない）。
- **注意**: シオンは、プロローグでは三つ首の竜を見ていない。この竜が神殿を壊したと知るのは、ヴァルガ自身の言葉による。シオンの反応は直後の会話で描く。名乗りは直後の会話にも用意し、最後まで見たときだけ省く。第1～5章で見送ったM3（強敵の出現）と同じ型だが、第7章では名を明かす場面なので採用した。
- **試作（2026-11-14）**: Studioの [`story-movies/ch7-three-heads/`](../../../Storybook_Character_Studio/story-movies/ch7-three-heads/README.md)。約9秒・3場面（暗くなる空／見下ろす三つの頭／名乗り）。ヴァルガの頭・胴はStudioの作画コード（試作色）から書き出し、首・翼・尾は `rig-profile.mjs` の色で描いた。新しく書いた字幕は、②「職をつぐ灯など、二度と ともさせぬ。」、③「我が名は ヴァルガ。ダーマを焼いた者だ。」（計画の例のとおり）。①は字幕なし。③では字幕のほか、タイトルの位置に名前「三頭魔竜　ヴァルガ」を表示する。②は火を噴く直前で切り、大屋根の壊れ方は描かない。ガーゴイルは描かない。

### M13 最終決戦の決着「灯は消えず」（中・10～20秒）

- **目的**: 三つの頭を倒した決着を見せ、祭壇の灯が守られたことを伝えます。
- **場面**:
  1. 三つ目の頭が倒れ、竜の巨体が崩れ落ちる。
  2. 煙が晴れる。傷ついた屋根と壁の奥で、祭壇の灯がともり続けている。屋根の穴から朝の光が差し、祭壇のそばの選択の柱の印を照らす。
  3. 朝の光: 大型対空ボウガンの射台、傷の残る神殿、集まってくる仲間と住民。
- **字幕の方針**: ヴァルガの最後の短い言葉と、職業の書かシオンの言葉。
- **見せないもの**: 戦後の修復と、スズハ・アサギへの継承（ゲームで描き、M14へつなぐ）。
- **注意**: 戦いでできた損傷は、ムービーの後も修理段階へ引き継ぐ。ムービーで直った神殿を見せない。崩れ方を第5章のグロム（黒い霧へ崩れ、爪痕の印の黒鱗が残る）と呼応させるかは、制作時に決める。M13の試作では、黒い霧へ崩れる形で呼応させ、黒鱗は残さないことにした（下の「試作」）。
- **試作（2026-11-14）**: Studioの [`story-movies/ch7-flame-holds/`](../../../Storybook_Character_Studio/story-movies/ch7-flame-holds/README.md)。約18秒（場面の合計は16.4秒）・3場面（最後の頭／消えない灯／朝の光）。新しく書いた字幕は、①ヴァルガの最後の言葉「おのれ……職をつぐ者ども……。」、②職業の書「灯は、消えておらぬ。」、③職業の書「皆の仕事が、この灯を守ったのじゃ。」。③の終わりにタイトル「最終決戦の決着／灯は消えず」。①は夜明け前の神殿の前で、大型対空ボウガンの矢が刺さって地上へ落ちたヴァルガ（頭・胴はM12と同じStudioの作画コードから）。左右の二つの頭はすでに倒れ、三つ目の頭が倒れると、巨体は第5章のグロムと同じく黒い霧へ崩れる。爪痕の印の黒鱗は残さない（印の主であるヴァルガ自身が倒れたため）。②はM11の第1場面と同じ本堂の中で、屋根の穴・すす・ひび・床に落ちた板と石を加えた。選択の柱は本堂の中の祭壇の右に立つので、②の終わりに、屋根の穴から差す朝の光で照らした（当初の計画では③に挙げていた）。四つの枠の印は下から、アサギの大工の印・建築（積んだ石と金槌）・食料（湯気の立つ椀）・防衛（盾）。印の種類と数はゲームの設計で決めてよい。③は大屋根の穴と焦げ、すすけた壁、割れた窓、欠けた軒が残る神殿（直った神殿は見せない）と、ピノの木組みの台にベルクの鉄の弓と巻き上げ車を据えた射台。ベルク・ピノ・ガンゾウ・アサギ・シオンの前へ、ミナ・ゴンタ・ワタリ・スズハが歩いてくる。射台の形・位置と傷の細部はゲームで決めてよい。戦後の修復とスズハ・アサギへの継承は描かない。

### M14 ダーマ再興編・完「まだ見ぬ書へ」（大・30～35秒）

- **目的**: ダーマ再興編とこれまでの旅を締めくくり、世界中の職業の書を探す新しい旅へつなぎます。最後の航海で、ピノとベルクをそれぞれの島へ送り届けます。
- **場面**:
  1. 再開した神殿: スズハが訪れた人を迎える。アサギが屋根に上り、ガンゾウが石を運ぶ。
  2. ダーマの船出: スズハ・アサギ・ガンゾウが桟橋から見送る中、旅の4人とピノ・ベルクを乗せた船が出る。
  3. ジパング: 船が寄り、ピノが降りる。イナホ・ジンベエが迎える。田・食堂・社。
