## 開始状態と物語

シオン・ミナ・ゴンタ・ワタリが火山島へ到着します。前の島の出来事は会話で振り返り、長い航海で物資を使い切った状態から町の復興を始めます。

第1～3章のセーブ読込はありません。初期装備・所持品は `newgame.js` の固定設定で、石のハンマー、銅の剣、薬草・おにぎり・たいまつなどを持ちます。持ち出した職業の書と、農民・料理人・船乗りの書の計四冊が、システム上は復活済みの状態です。

ベルクは自分の武器が魔物に使われたことを悔い、鍛冶をやめています。鉱山・炭焼き・鍛冶場を復旧し、暮らしを動かす道具を作ることで、鍛冶屋の書が復活します。

## 進行と成立条件

| ステージ | 主な操作・結果 |
|---|---|
| `CH4_ARRIVAL` | カヤと出会い、海岸拠点を作る |
| `CH4_COLD_FORGE` | ベルク・ロクと出会い、町の状況を知る |
| `CH4_GATHER_PEOPLE` | スミとテルを救出し、カヤへ報告。火山灰畑を整える |
| `CH4_MINE` | 鉱山入口を復旧し、鉄鉱石を集める。進行条件は所持鉄鉱石6個以上 |
| `CH4_FORGE` | 炭焼き窯と鍛冶場を完成 |
| `CH4_WORK_TOGETHER` | 鉄のハンマー・鉄の金具・鉄鍋の制作と各共同作業の会話、食堂の完成・食事の場面 |
| `CH4_BOOK` | 鍛冶屋の書が復活、拠点レベル3。ベルクと話して防衛開始を選ぶ |
| `CH4_DEFENSE` | 炉を守り、炉喰らいの大鬼火を倒す |
| `CH4_DONE` | 峠で倒れているナギを発見。拠点レベル4となり、オートセーブ |

鍛冶屋の書の復活判定 `maybeReviveBlacksmith()` は、三つの共同作業会話の完了フラグと食堂の設計図完成を条件にします。道具を一つ作るだけでは復活しません。

## 次章へ残すこと
