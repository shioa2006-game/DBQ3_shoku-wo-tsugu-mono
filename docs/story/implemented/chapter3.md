## 物語

浜に漂着した船乗りワタリのため、桟橋・灯台・船を再建します。島で育てたものや作ったものが船となり、船乗りの書が復活します。シオンたちは島が自立できるように役割を託し、クラーケンの襲撃から船を守った後、外洋へ旅立ちます。

## 進行と成立条件

| ステージ | 主な操作・結果 |
|---|---|
| `CH3_INTRO` | 第2章完了の翌日の日中に開始。浜のワタリと話す |
| `CH3_DOCK` → `CH3_LIGHTHOUSE` | 桟橋、灯台を順に完成 |
| `CH3_HULL` → `CH3_MAST` → `CH3_SAIL` | 船体、帆柱、帆を順に完成 |
| `CH3_SAIL` → `CH3_RITE` | 船乗りの書が復活。拠点レベル5 |
| `CH3_RITE` | 板材5・米5・ごちそう膳1をジンベエに奉納し、授職の儀。`riteDone` が立つがステージは変わらない |
| `CH3_RITE` → `CH3_DEFENSE` | 儀式後、ワタリとの会話で出航を選ぶと襲撃 |
| `CH3_DEFENSE` → `CH3_FAREWELL` | イカの群れとクラーケンから停泊中の船を守る。勝利後、乗船・別れの配置へ移りオートセーブ |
| `CH3_FAREWELL` → `CH3_DONE` | ワタリに旅立ちを告げ、出航演出の後に完了状態を保存 |

クラーケン戦は触手を落として本体を攻撃する構成です。航海中の別マップ戦へ切り替わるのではなく、現在の島の岸・桟橋周辺で船を守ります。

## 授職と結末

シオンがジンベエへ神官の役割を託し、ジンベエがピノへ大工、イナホへ農民を授けます。イナホは料理人と農民を兼ねます。大工の書・神官の書が新しく復活するシステム処理はありません。

物語上はピノ・イナホ・ジンベエが島に残り、シオン・ミナ・ゴンタ・ワタリの四人が旅立ちます。ミナの別れ台詞の曖昧さは [STORY-004](../inconsistencies.md#story-004) に記録しています。

## クリア後とゲームの境界

画面上の表記は「本島編・完」。2026-11-03に正式副題を「ジパング復興編」へ統一すると決定しましたが、ゲーム内への反映は未実施です（[STORY-001](../inconsistencies.md#story-001)）。

実装は `CH3_DONE` の同じワールドで自由行動を続けます。以前のセーブを読み直したり、時計を出航前夜へ巻き戻したりはしません。ワタリとの会話から旅立ち演出を再び見られます。物語上の出航と、クリア後に全員のいる島で遊べることは分けて理解してください。

第4章は別ゲームを起動し、固定初期状態で始めます。第3章の完了で別ゲームへ自動遷移したり、所持品や建築を転送したりする処理はありません。
