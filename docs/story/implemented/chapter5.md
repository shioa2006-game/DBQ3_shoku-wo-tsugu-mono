## 物語

ヨモギが合流し、ナギが目覚めます。町には病人がおり、宿坊・薬草園・外社を整えて看病します。ナギは病人に寄り添い、僧侶の道を選びます。清めの泉を汚す原因へ進み、穢れ石を清め、瘴泉竜グロムを倒して泉を修復します。

## 進行と成立条件

| ステージ | 主な操作・結果 |
|---|---|
| `CH5_INTRO` | 第4章完了の翌日の日中に開始。ヨモギとの会話を経てナギが目覚める |
| `CH5_BAMBOO_GATE` | ベルクから鉄の山刀を受け取り、竹林の門を完成して南へ進む |
| `CH5_LODGE` | 病人のための宿坊を完成 |
| `CH5_HERB_GARDEN` | 薬草園を完成し、薬草の煎じ湯を2回制作。メニューを閉じた後の処理で次へ |
| `CH5_OUTER_SHRINE` | 外社を完成 |
| `CH5_VIGIL` | 煎じ湯1・火山穀物の粥1を渡す。看病と祈りの場面を経て僧侶の書が復活。拠点レベル5 |
| `CH5_PURIFY_PATH` | 穢れ石3か所で、敵を倒す→柱を建て直す→ナギが浄化する流れを完了 |
| `CH5_INNER_SHRINE` | 泉へ進み、ナギとの会話で戦闘開始を選ぶ |
| `CH5_DRAGON` | グロムと戦う。撃破後もこのステージのまま、泉の祭壇・水門・導水路を建築 |
| `CH5_DONE` | 泉の建築完成後に浄化・住民回復、拠点レベル6。結末演出の後、完了状態を保存 |

グロム撃破だけでは章完了になりません。`gromDefeated` の後に `spring_works` を完成させ、`finishChapter()` で結末へ進みます。

## グロムの現在の姿

[GROM_CONFIG](../../../dqb3-tsugumono-ch4-5/src/entities/dragon-configs.js)は、二つの頭、左右の翼、`hover: 1.5` を定義しています。低空を漂う双頭の翼竜であり、旧資料の「翼なし・地上型」とは異なります。

[戦闘処理](../../../dqb3-tsugumono-ch4-5/src/game/dragon-battle.js)では左右の頭を独立に破壊して討伐します。第7章計画のヴァルガの空中戦・複数段階の演出を、この戦闘へ実装済みと読み替えないでください。

## 結末とクリア後

清い水が戻り、住民の暮らしを島へ託します。旧神殿へつながる航路と手がかりを得たシオンは、自分が逃れた旧ダーマ神殿へ戻ることを決めます。四人の旅は続き、画面には「火山島編・完」と表示されます。

第1章の「島の山頂へ新神殿」との食い違いは [STORY-002](../inconsistencies.md#story-002) に記録。ここでは第5章が実際に語る帰還先をそのまま記載しています。

クリア後は `CH5_DONE` の同じワールドで自由建築を続けます。出航前へセーブを巻き戻しません。戦闘中のセーブを復元する場合、グロム未撃破の `CH5_DRAGON` は安全な戦闘前の `CH5_INNER_SHRINE` に戻す処理があります。これはクリア後の巻き戻しとは別です。

第6章への自動遷移やセーブ移送は未実装です。
