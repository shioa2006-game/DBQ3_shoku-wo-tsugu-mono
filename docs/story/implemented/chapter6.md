## 物語

火山島を発った四人（シオン・ミナ・ゴンタ・ワタリ）と話す職業の書は、シオンが逃げ延びた旧ダーマ神殿の島へ戻ります。山腹の神殿は屋根を失い、二本の柱だけが立っています。麓の集落で元水運びのスズハに出会い、大工見習いのアサギ、石切り職人のガンゾウと力を合わせて神殿を建て直します。

シオンは祭壇を急ごうとしますが、書に促されて、まず皆が食べて眠れる共同小屋を建てます。基壇と石段を直し、採石洞の奥で大岩ガニを倒して祭壇の要石を切り出します。ワタリがジパングから迎えた大工のピノとアサギが柱と大屋根を組み、要石を据えた祭壇に授職の灯がともります。坂道を本堂の横の入口へつなぎ、水場・休める部屋・書庫・共同台所を整えたあと、アサギが「自分で屋根を直せる大工になりたい」と申し出て、シオンが最初の授職を務めます。祝いの夜、海の向こうから遠い咆哮が届き、ガーゴイルの群れを従えた三つ首の影が沖を横切ります。

## 進行と成立条件

「はじめから」で、六冊の書が復活済み・鉄の装備の固定状態から始まります（[newgame.js](../../../dqb3-tsugumono-ch6-7/src/game/newgame.js)）。編の始まりのムービー（M10）の後、桟橋のそばの浜に立ちます。

| ステージ | 主な操作・結果 |
|---|---|
| `CH6_ARRIVAL` | 麓の集落のスズハと話す。谷に水運びの橋を架ける |
| `CH6_RUINS` | 坂道を登り、神殿跡のスズハと話す。前庭の東に共同小屋を建てる。拠点レベル1 |
| `CH6_FOUNDATION` | アサギとガンゾウが坂を登って合流。瓦礫をどけ、基壇と石段を直す。拠点レベル2 |
| `CH6_VOYAGE` | 採石洞の入口でガンゾウと話す。この会話の間に、ワタリがピノを迎えに出航する（船とワタリが不在になる） |
| `CH6_QUARRY` | ゴンタが同行。崩れた足場を直して下へ降り、地の裂け目に橋を渡す。奥の採石場へ近づくと、積み石に見えた大岩ガニが動き出す |
| `CH6_CRAB` | 大岩ガニ戦。正面の甲羅は硬く、爪を振り下ろした後の隙に横腹を狙う。倒れると、ボスは積み石へ戻り、下の坑道から再挑戦 |
| `CH6_KEYSTONE` | ガンゾウの付けた三つの印へくさびを打ち、要石の岩盤へ最後の一打を入れる |
| `CH6_HAULING` | 橋を広げ、足場を丸太の道にする（搬出路）。完成すると暗転して要石を運び出し、その間に船が帰港してピノが到着する |
| `CH6_ROOF` | 神殿でピノと話し、資材を受け取る。柱と壁を組み、梁と大屋根を架ける。拠点レベル3 |
| `CH6_ALTAR` | 要石を祭壇へ据え、授職の灯をともす。そばに選択の柱を立てる。拠点レベル4 |
| `CH6_LIVING` | 横の入口への渡り廊下・水場・休める部屋を作る。続けて書庫と共同台所を整える |
| `CH6_ORDINATION` | 本堂のアサギと話す。シオンが最初の授職を務め、選択の柱に大工の印を刻む |
| `CH6_DONE` | 第6章の結びのムービー（M11）の後、拠点レベル5。翌日の日中に第7章が始まる |

神殿の設計図（基壇・柱と壁・大屋根）は、前庭の資材置き場の収納箱へ資材を入れると、大工たち（アサギ・ガンゾウ・ピノ）が数秒に1マスずつ組みます（[crew.js](../../../dqb3-tsugumono-ch6-7/src/systems/crew.js)）。節目で住民がまとまった資材を渡し、足りない分は採集とクラフトで補えます。

## 島と神殿

南が海で、桟橋と麓の集落があります。谷（水運びの橋）を越えて山道を登り、踊り場と道の口を経て、北の神殿の台地へ上がります。神殿の西の崖に採石洞の入口、東に肩の高台があります。奥は岩山で、越えられません。神殿の形（三段の基壇、正面の九本の柱と中央のアーチ、板葺きの大屋根と書の紋章）は、Studioのムービーの部品（`story-movies/shared/temple.py`）と同じです。

祭壇（要石と授職の灯）と選択の柱は、本堂の中の近い場所に別々に立ちます。選択の柱は、刻んだ印の数で見た目が変わります。

## 敵

山道と森に岩角ヤギ（踏み鳴らしてから突進）と山ねずみ（3匹の群れ）、採石洞に小岩ガニ（構えている間は正面が硬い）と洞窟こうもりが出ます。章のボスは大岩ガニです。糸吐きグモ・石兵は登場しません。

## ムービーと会話

- M10（編の始まり）: 「はじめから」の後に流れます。最後まで見たときは、導入の地の文2行を省きます。
- M11（第6章の結び）: 最初の授職の会話の後に流れます。最後まで見なかったときだけ、祝い・遠い咆哮・三つ首の影の地の文を会話で流します。

授職の場面そのもの（シオンがアサギの話を聞くところ）は、ゲームの会話で描いています。ヴァルガの名前は、この章では出ません。

## 計画との差

- 計画の「職業の間」は、独立した部屋としては作っていません。祭壇と選択の柱のある本堂の広間が兼ねます。
- 農業の必須工程はありません（計画どおり）。渡り廊下と水場ができたときにミナから山麦の種を受け取り、畑は任意です。
- 設計図の分割・寸法・資材数・敵の数値は、[設計資料](../../../dqb3-tsugumono-ch6-7/docs/DESIGN.md)に書いたとおりに決めました。
