### STORY-001: 第1～3章の名称

- 根拠A: [UIの `showTitle()`](../../dqb3-tsugumono-ch1-3/src/ui/ui.js)は「ジパング復興編」。ゲームREADME・HTMLのタイトルもこの呼称。
- 根拠B: [第3章の目標と結末](../../dqb3-tsugumono-ch1-3/src/content/chapter3.js)は「本島編・完」。親READMEや旧全体企画も「本島編」を使用。
- 影響: 共通トップページのカード名と起動後のタイトル・結末が違い、同じ編か判断しづらい。作品全体の副題と誤認されやすい。
- 今回の扱い: 全体名は「職をつぐ者」。第1～3章の資料では二つの呼称を併記し、既存画面は維持。
- 決定（2026-11-03）: 第1～3章の正式副題は「ジパング復興編」。結末も同名へ統一する。「本島」は地理的な呼称として残せるが、編名には使用しない。上の根拠・今回の扱いは整理時点の実装記録。変更箇所と文案は[決定記録](decisions-2026-11-03.md)にまとめた。

<a id="story-002"></a>
### STORY-002: 神殿の所在地と旅の目的

- 根拠A: [第1章 `quests.js`](../../dqb3-tsugumono-ch1-3/src/game/quests.js)の防衛後・祭壇会話は、北の山の社を新ダーマ神殿の礎とし、「山頂に、まことの 新ダーマ神殿」を建てる旅を予告。
- 根拠B: [第5章 `springDone` と結末](../../dqb3-tsugumono-ch4-5/src/content/chapter5.js)では、シオンが逃れた旧ダーマ神殿へ戻る決意が語られる。[第6章計画](planned/chapter6.md)もダーマ地方の旧神殿を同じ場所に再建する。
- 影響: ジパング内に新設するのか、別の土地の旧神殿を再建するのか、作品を通じた目的地が食い違う。
- 今回の扱い: 第1章の実在する台詞を記録し、第5章の帰還先もそのまま記録。二つの神殿を新設定で説明したり、同じ場所だと断定したりしない。
- 決定（2026-11-03）: 旧ダーマ神殿を元の場所へ再建する。所在地はジパング・火山島とは別の島。第1章の社は島で職を受け継ぐ場所として説明し、山頂への本神殿建立の予告を修正する。第6章計画の「島ではなく」という記述は修正済み。上の根拠・今回の扱いは整理時点の実装記録であり、ゲームの台詞修正は未実施。

<a id="story-003"></a>
### STORY-003: 商人の書と「六冊」

- 根拠A: [第1章の祭壇会話](../../dqb3-tsugumono-ch1-3/src/game/quests.js)には「鍛冶の書、商人の書、僧侶の書」とある。
- 根拠B: [第1～3章jobs.js](../../dqb3-tsugumono-ch1-3/src/game/jobs.js)と[第4～5章jobs.js](../../dqb3-tsugumono-ch4-5/src/game/jobs.js)に定義される書は合計六種類で、商人は含まれない。[旧全体企画の「職業の書と生活上の役割」](../../archive/story/2026-11-03/dqb3_game_plan.md)は「本作で実在する六冊」と表現し、第6章計画は新しい書を追加しない。
- 影響: プレイヤーが商人の書の復活を今後のイベントとして期待する可能性がある。
- 今回の扱い: 「実装された書は六種類」とだけ確定する。世界に他の書が存在する可能性まで否定しない。世界設定とゲームの収録範囲の違いで説明可能なので、矛盾とは断定しない。
- 決定（2026-11-03）: 第1章の予告から「商人の書」を外し、本作で扱う書の予告へ直す。世界の全職・全書の総数を新たに断定する変更ではない。ゲームの台詞修正は未実施。

<a id="story-004"></a>
### STORY-004: ミナの出航前の台詞

- 根拠A: [第3章 `farewellTalk`](../../dqb3-tsugumono-ch1-3/src/content/chapter3.js)でミナは「シオン、ほんとに行っちゃうんだね」と語り、シオンは「ここは、みんなに任せた」と続ける。
- 根拠B: 同ファイルの授職とエンディングでは、畑をイナホへ託し、ミナはシオン・ゴンタ・ワタリと出航する。[日常会話の別れ用台詞](../../dqb3-tsugumono-ch1-3/src/content/smalltalk.js)も次の島への同行を示す。
- 影響: 会話だけを見るとミナが島に残るようにも読める。同行者そのものの実装が違うわけではない。
- 今回の扱い: 同行者は結末に基づき四人と記載し、この一節の曖昧さを保留。
- 決定（2026-11-03）: 話者はミナのまま、一緒に旅立つことが伝わる台詞へ直す。同行者と人物配置は変更しない。ゲームの台詞修正は未実施。

<a id="story-005"></a>
### STORY-005: シオンの見習いの立場

- 根拠A: [第1章の祭壇会話](../../dqb3-tsugumono-ch1-3/src/game/quests.js)でビルダーの書が「おぬしはもう見習いではない」と評する。
- 根拠B: [第3章の授職](../../dqb3-tsugumono-ch1-3/src/content/chapter3.js)で本人は「神官見習い」「正式な神官ではない」と話す。
- 影響: 成長への評価と、神官としての正式な立場が混同される。資格が変わった実装があるとは断定しない。
- 決定（2026-11-03・第2回①A）: 神官としては見習いのまま、ビルダーとして認められる。第1章をその意味が伝わる台詞へ変更する。[文案](decisions-2026-11-03.md)を用意したが、ゲームへの反映は未実施。

<a id="story-006"></a>
### STORY-006: 唯一の生存者と第6章の地元住民

- 根拠A: [第1章の導入](../../dqb3-tsugumono-ch1-3/src/game/quests.js)でシオンは「たった一人だけ生き残ってしまった」と語る。
- 根拠B: [第6章計画](planned/chapter6.md)にはダーマ地方の避難民が登場する。従来は彼らと神殿襲撃の生存者の関係が明確ではなかった。
- 影響: 世界全体や周辺地域にも生存者がいないと誤読する可能性がある。実装上の矛盾と断定せず、対象範囲を整理する。
- 決定（2026-11-03・第2回②B）: シオンは襲撃時に神殿にいた人の中では唯一の生存者。第6章の地元住民は神官以外の、神殿周辺にいた住民。復活を望むが、ビルダーの建築・神官の務めをできず、自力では神殿を再建して授職を再開できない。
- 対応: 第6章の人物設定と人物資料へ反映。第1章の台詞は変更していない。第6章は未実装なので、将来の会話で地元住民と神殿内の人々の違いを伝える必要がある。
