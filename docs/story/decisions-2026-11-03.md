# 不整合の解消方針と修正文案（2026-11-03）

[全体像](overview.md) / [不整合一覧](inconsistencies.md)

ユーザーが質問①～④のA案を選択し、②には「ジパングや火山島とは別の島」と補足したことに基づく決定記録です。方針は確定しています。以下は決定時の修正文案を保存したものです。同日の後続作業でゲームへ反映しました。実装範囲と確認結果は[不整合一覧](inconsistencies.md#implementation-2026-11-03)を参照してください。

決定記録作成時は、Claude Codeとの並行作業のため、変更を `docs/story/` に限定しました。以下の「現在」「反映待ち」「未変更」はその時点の記録です。後続の実装反映では設置物・アイコン関連を変更せず、第1～3章の台詞・表示と関連資料を更新しています。

## 決定した設定

| 対象 | 決定 |
|---|---|
| STORY-001／① | 第1～3章の正式副題は「ジパング復興編」。全体名は「職をつぐ者」。「本島」は地理用語として残せるが編名には使わない |
| STORY-002／② | ジパング・火山島とは別の島にある、シオンが逃れた旧ダーマ神殿を元の場所へ再建する。第1章の社はジパングで職を受け継ぐ場 |
| STORY-003／③ | 第1章の「商人の書」の予告を外す。本作で復活させる書に沿った予告にする |
| STORY-004／④ | ミナ自身が、一緒に旅立つ実感を語る台詞へ変更する。同行者はシオン・ミナ・ゴンタ・ワタリのまま |

「別の島」は神殿の地理的な所在地の決定です。当初こちらで「沿岸への上陸は導入演出、プレイ範囲は内陸の山間部を維持」と整理しましたが、その後ユーザーから、一方向の海面からずっと山となるマップを考えているとの補足がありました。内陸のみをプレイするという整理は継承せず、[第6～7章の追加案](planned/chapter6-7-expansion-proposal.md)へ記録しています。大規模神殿の再建と、波状攻撃・防御建築・修理を繰り返す第7章の構想も同資料に保存しています。詳細はまだ案の段階であり、島の固有名も新設していません。

## 第2回の回答：人物設定と第7章の防衛

同日の追加質問に対し、ユーザーが①A、②B、③A、④B、⑤は暫定Bと回答した。以下を第1回の決定に追加する。第6～7章は未実装であり、決定した設計と動作済みの仕様を区別する。

| 質問 | 決定・補足 | 状態 |
|---|---|---|
| ① シオンの見習いの立場 | 神官としては見習いのまま、ビルダーとして認められる。第1章の「もう見習いではない」は神官への昇格と誤解されない台詞へ修正 | 方針確定・台詞反映待ち（STORY-005） |
| ② 神殿襲撃の生存者 | シオンは襲撃時に神殿にいた人の中では唯一の生存者。第6章で出会う地元住民は、神官ではなく神殿周辺に暮らしていた住民。神殿復活を望むが、ビルダーの建築も神官の務めもできず、自力では再建・授職を再開できない | 設定確定・第6章計画へ記載（STORY-006） |
| ③ 次の襲撃の開始 | 修理・補給後、プレイヤーの合図で開始する。時間経過だけで次の波が始まる方式にしない | 未実装の制作方針として確定 |
| ④ 神殿の破損と敗北 | 防壁・罠だけでなく、再建した神殿の壁や屋根も壊れ、神殿本体の補修が必要になる。神殿中枢の耐久が尽きると敗北。建造物の損傷と中枢耐久の関係の詳細は別途設計する | 未実装の制作方針として確定 |
| ⑤ 選択の柱と最終ボス | 柱はボス戦前に完成させる。最終ボス戦の具体像は未定で、従来の戦闘中建築を必須とはしない | **暫定方針**。ボス戦を具体化するときに再検討 |

第6章の地元住民がビルダー・神官ではないことは、暮らしの知恵や協力する力まで持たないという意味ではない。各地から来るピノ・ジンベエなどの訪問団とは区別する。地元住民も神殿復活の過程に関わり、再建後に役割を選ぶ従来案と両立させる。

神殿本体の損傷を補修することを、この編の防衛の特徴にする。柱の完成時期だけを暫定変更した段階なので、ボスの形態数、攻撃、弱点、防護解除の方法、戦闘中の神殿への攻撃は未確定とする。詳細は[追加案と追記した制作方針](planned/chapter6-7-expansion-proposal.md)を参照。

## ゲームへ反映する文案

### 第1章：社を建てる場面

対象: [quests.js](../../dqb3-tsugumono-ch1-3/src/game/quests.js) の防衛勝利後、ビルダーの書の台詞。

- 現在：「職業の社――それは新しいダーマ神殿の礎じゃ。北の山の中腹に設計図を広げたぞ！」
- 文案：「職業の社――この島で、人から人へ職を受け継ぐための場所じゃ。北の山の中腹に設計図を広げたぞ！」

社の位置と設計図は維持し、その役割を後の第3章の授職へつなげます。

### 第1章：見習いの立場を明確にする

対象: [quests.js](../../dqb3-tsugumono-ch1-3/src/game/quests.js) の `onAltarPrayed()`。

- 現在：「……うむ。うむ！　シオンよ、おぬしはもう見習いではない。職をつぐ者 じゃ！」
- 文案：「……うむ。うむ！　シオンよ、おぬしは立派なビルダーじゃ。人の暮らしをつなぐ、職をつぐ者 じゃ！」

これは第2回①の方針に沿う文案。第3章の「神官見習い」「正式な神官ではない」という台詞は維持する。正式な神官への昇格や資格授与は追加しない。

### 第1章：祭壇で祈った後

対象: 同じ `quests.js` の `onAltarPrayed()`、ビルダーの書の最後の二言。

- 現在：「じゃが、これで終わりではないぞ。鍛冶の書、商人の書、僧侶の書……失われた書は、まだ世界中に眠っておる」
- 文案：「じゃが、これで終わりではないぞ。料理人の書、船乗りの書、鍛冶屋の書、僧侶の書……取り戻すべき職は、まだ残っておる」

- 現在：「山頂に、まことの 新ダーマ神殿 を建てる旅は、ここから始まるのじゃ！」
- 文案：「この社を、島の暮らしを支える場所に育てるのじゃ。職をつぐ旅は、ここから続いていくぞ！」

第1章時点では次の島への出航も旧神殿への帰還も先の出来事です。この場面は島の復興から次の職へつなぎ、旧神殿へ戻る決意は第5章で語る現在の構成を保ちます。

対象: [ui.js](../../dqb3-tsugumono-ch1-3/src/ui/ui.js) の第1章用 `playEnding()` 末尾。

- 現在：「― 新ダーマ神殿を建てる旅が、いま始まる ―」
- 文案：「― 職をつぐ旅は、ここから続いていく ―」

### 第3章：目標と結末の編名

対象: [chapter3.js](../../dqb3-tsugumono-ch1-3/src/content/chapter3.js) の `CH3_DONE` 目標と `ending` 最終行。

- 「本島編・完」を「ジパング復興編・完」へ変更する。
- タイトル画面はすでに「ジパング復興編」のため、その名称を維持する。
- `ui.js` は結末の行に「本島編」が含まれる場合に `ending-title` を付ける処理がある。名称変更と同時に判定を新名称へ合わせ、結末の装飾を維持する。

### 第3章：船出の会話

対象: 同じ `chapter3.js` の `farewellTalk` 冒頭のミナ。

- 現在：「シオン、ほんとに行っちゃうんだね」
- 文案：「シオン、いよいよ私たち、この島を旅立つんだね」

後続のシオン、ジンベエ、ワタリの台詞と、島を託す三人・旅立つ四人の設定は維持します。
