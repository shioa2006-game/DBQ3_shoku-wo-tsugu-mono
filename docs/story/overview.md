## 作品と各編の呼び名

作品全体の名称は「職をつぐ者」。各編はそれぞれのタイトル画面から独立して起動します。

| 範囲 | 現在使われている呼び名 | 状態と扱い |
|---|---|---|
| 第1～3章 | ジパング復興編 | タイトル・第3章の完了目標・エンディングを統一済み |
| 第4～5章 | 火山島編 | 実装済みの独立ゲーム |
| 第6～7章 | ダーマ再興編 | 制作予定。ゲーム実装なし |

共通トップページの全体名は「職をつぐ者」です。「ジパング復興編」は第1～3章の副題であり、全7章共通の副題ではありません。「本島」は地理的な呼び方として残せます（[STORY-001](inconsistencies.md#story-001)）。

名称の実装出典: [第1～3章UI](../../dqb3-tsugumono-ch1-3/src/ui/ui.js)、[第3章会話・エンディング](../../dqb3-tsugumono-ch1-3/src/content/chapter3.js)、[第4～5章UI](../../dqb3-tsugumono-ch4-5/src/ui/ui.js)、[第5章会話・エンディング](../../dqb3-tsugumono-ch4-5/src/content/chapter5.js)。

## 第1～5章で起きていること

ダーマ神殿の崩壊を逃れた神官見習いシオンが、ジパングへ漂着し、話すビルダーの書と出会います。住まい、田、食堂、船、鍛冶場、癒やしの場を作り、住民と働くことで失われた職を取り戻していきます。

| 章 | 主な出来事 | 次へ残すもの |
|---|---|---|
| [1](implemented/chapter1.md) | 小屋と畑を作り、収穫で農民の書を復活。旗を守り、職業の社を建てる | ミナたちの暮らしと社。翌日の第2章へ |
| [2](implemented/chapter2.md) | 南への橋、田、食堂を復旧。料理人の書を復活させ、田を守る | イナホと食の循環。翌日の第3章へ |
| [3](implemented/chapter3.md) | 桟橋・灯台・船を建て、船乗りの書を復活。授職とクラーケン戦を経て出航 | ピノ・イナホ・ジンベエへ島を託し、シオン・ミナ・ゴンタ・ワタリが旅を続ける |
| [4](implemented/chapter4.md) | 火山島で町と鍛冶を再開。暮らしに使う道具と食堂を作り、鍛冶屋の書を復活。炉を守る | ナギの救出と、竹林・清めの泉の異変 |
| [5](implemented/chapter5.md) | 宿坊・薬草園・外社を整え、ナギが僧侶となる。穢れ石を清め、グロムを倒し泉を修復 | 火山島の自立と、シオンが逃れた旧ダーマ神殿へ戻る決意 |

第3章の授職では、シオンがジンベエへ神官の役割を託し、ジンベエがピノへ大工、イナホへ農民の役割を授けます。人物の役割と、システム上の職業の書の種類は同一ではありません。

決定した設定では、ダーマ地方はジパング・火山島とは別の島にあり、そこでシオンが逃れてきた旧ダーマ神殿を同じ場所へ再建します。第1章の職業の社は、ジパングで職を受け継ぐための場所です。第1章の山頂への本神殿建立の予告と第2章の同種の予告を修正し、旧神殿へ戻る決意は第5章で語る構成を維持しました（[STORY-002](inconsistencies.md#story-002)）。

## ゲームとセーブの境界

第1～3章は同じゲーム・ワールド内で進みます。第1章の `POSTGAME` は全編終了ではなく、翌日の日中に第2章へ進む章間の状態です。第3章の出航後は `CH3_DONE` を保存し、その島で遊び続けられます。

第4～5章は別ゲームです。第4章は第3章までの出来事を前提にした固定New Gameで始まり、第1～3章の所持品・建築・セーブを読み込みません。ビルダー・農民・料理人・船乗りの四冊が復活済みです。第5章の出航後は `CH5_DONE` の同じワールドで遊び続けられます。いずれも旧資料の「出航前夜のスナップショットに巻き戻す」実装ではありません。

|---|---|
| 第1～3章 | `shoku_wo_tsugumono_save_v1` |
| 第4～5章 | `shoku_wo_tsugumono_kazan_save_v1` |
| 第6～7章 | 未実装。専用領域を使う計画 |

## 第6～7章の制作計画

現在の方針は[シナリオと共通設計](planned/chapter6-7-scenario.md)へ集約した。第6～7章は未実装。

[第6章](planned/chapter6.md)では、別の島の海岸から山へ進み、旧ダーマ神殿を元の場所に再建する。旅の4人とダーマの新キャラ3人が協力し、ワタリが大工のピノを迎える間に採石洞へ向かう。大岩ガニを倒して祭壇の要石を切り出し、大屋根を完成させる。神官見習いのシオンが、大工の道を選んだ若者への最初の授職を取り仕切る。

[第7章](planned/chapter7.md)では、職と技術の広がりを阻もうとする魔物の波状攻撃に備える。通常戦闘・罠・据え付け式ボウガンを組み合わせ、神殿の壁・屋根と設備を補修する。三頭竜の初襲来を反撃で退けた後、神殿を修復して対策を施し、同じ三頭竜との最終決戦へ進む。神殿中枢の耐久が尽きると敗北。各波と最終決戦は準備後のプレイヤーの合図で進める。

神殿を地元住民へ託し、シオンたちとビルダーの書が旅を続ける結末案。名前・地形寸法・戦闘数値・戦後の授職担当者などは[共通設計の未決事項](planned/chapter6-7-scenario.md)で管理する。従来の訪問団6人の集合、内陸だけのマップ、戦闘中の選択の柱建築は検討経緯として扱い、現行シナリオを参照する。
