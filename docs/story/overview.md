共通トップページを作る際は、全体名を「職をつぐ者」とし、「ジパング復興編」を全7章共通の副題として扱わない方針です。第1～3章は「ジパング復興編」に統一する決定です。「本島」は地理的な呼び方として残せます（[STORY-001](inconsistencies.md#story-001)）。今回トップページ自体は変更していません。

## 第1～5章で起きていること

ダーマ神殿の崩壊を逃れた神官見習いシオンが、ジパングへ漂着し、話すビルダーの書と出会います。住まい、田、食堂、船、鍛冶場、癒やしの場を作り、住民と働くことで失われた職を取り戻していきます。

| 章 | 主な出来事 | 次へ残すもの |
|---|---|---|
| [1](implemented/chapter1.md) | 小屋と畑を作り、収穫で農民の書を復活。旗を守り、職業の社を建てる | ミナたちの暮らしと社。翌日の第2章へ |
| [2](implemented/chapter2.md) | 南への橋、田、食堂を復旧。料理人の書を復活させ、田を守る | イナホと食の循環。翌日の第3章へ |
| [3](implemented/chapter3.md) | 桟橋・灯台・船を建て、船乗りの書を復活。授職とクラーケン戦を経て出航 | ピノ・イナホ・ジンベエへ島を託し、シオン・ミナ・ゴンタ・ワタリが旅を続ける |
| [4](implemented/chapter4.md) | 火山島で町と鍛冶を再開。暮らしに使う道具と食堂を作り、鍛冶屋の書を復活。炉を守る | ナギの救出と、竹林・清めの泉の異変 |
| [5](implemented/chapter5.md) | 宿坊・薬草園・外社を整え、ナギが僧侶となる。穢れ石を清め、グロムを倒し泉を修復 | 火山島の自立と、シオンが逃れた旧ダーマ神殿へ戻る決意 |

第3章の授職では、シオンがジンベエへ神官の役割を託し、ジンベエがピノへ大工、イナホへ農民の役割を授けます。人物の役割と、システム上の職業の書の種類は同一ではありません。

決定した設定では、ダーマ地方はジパング・火山島とは別の島にあり、そこでシオンが逃れてきた旧ダーマ神殿を同じ場所へ再建します。第1章の職業の社は、ジパングで職を受け継ぐための場所です。第1章に残る山頂への「新ダーマ神殿」建立の予告は、この方針に合わせて修正予定です（[STORY-002](inconsistencies.md#story-002)）。

## ゲームとセーブの境界

第1～3章は同じゲーム・ワールド内で進みます。第1章の `POSTGAME` は全編終了ではなく、翌日の日中に第2章へ進む章間の状態です。第3章の出航後は `CH3_DONE` を保存し、その島で遊び続けられます。

第4～5章は別ゲームです。第4章は第3章までの出来事を前提にした固定New Gameで始まり、第1～3章の所持品・建築・セーブを読み込みません。ビルダー・農民・料理人・船乗りの四冊が復活済みです。第5章の出航後は `CH5_DONE` の同じワールドで遊び続けられます。いずれも旧資料の「出航前夜のスナップショットに巻き戻す」実装ではありません。

|---|---|
| 第1～3章 | `shoku_wo_tsugumono_save_v1` |
| 第4～5章 | `shoku_wo_tsugumono_kazan_save_v1` |
| 第6～7章 | 未実装。専用領域を使う計画 |

## 第6～7章の制作計画

[第6章](planned/chapter6.md)は、ジパング・火山島とは別の島にあるダーマ地方へ戻り、破壊された旧神殿を同じ場所へ再建する計画です。島の沿岸へ船で上陸し、内陸の山間部をプレイする構成を維持します。これまでの島々の代表が合流し、復活した六冊と生活上の役割を生かします。新たな職業の書の追加ではなく、神殿の建築と授職、一部住民の役割選択を中心にします。

[第7章](planned/chapter7.md)は、完成した神殿を無銘の魔竜ヴァルガと軍勢から守る計画です。「職業の間」と中央の「選択の柱」、職を選ぶ・変える・兼ねる・休む・今は選ばないという理念へつながります。シオンが最高位の神官として留まるのではなく、職をつぐ旅を続ける結末を想定しています。

これらの戦闘、住民の役割選択、神殿マップ、専用セーブは未実装です。詳細な脚本・演出・完了条件は `planned/` に保存し、実装済み章の説明へ混在させません。全体企画の詳細な原文は[旧全体企画書](../../archive/story/2026-11-03/dqb3_game_plan.md)で参照できます。
