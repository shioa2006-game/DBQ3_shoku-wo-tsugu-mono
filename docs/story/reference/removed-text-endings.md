# 削除した文字の章末（2026-11-08）

[資料の入口](../README.md) / [ストーリームービーの挿入計画](../planned/story-movies.md) / [不整合一覧のSTORY-008](../inconsistencies.md#story-008)

章末に全画面で文字が流れる演出（`ui.playEnding()`）は、2026-11-08にユーザーの判断で両編から削除しました。章末は SVGストーリームービー（M1・M4・M7）だけで描きます。ムービーを流せないときは、文字を出さずにそのまま次へ進みます。

削除した3つの文の全文を、ムービーの字幕の出どころとして下に残します。各ムービーの字幕は、この文の行を語の順を変えずに使っています（Studioの `tests/node/ch1-shrine.test.mjs`・`ch3-departure.test.mjs`・`ch4-arrival.test.mjs`・`ch5-return.test.mjs` がこのページと照合します）。`&nbsp;` だった空行は省きました。ゲームの台詞として使うものではありません。

## 第1章の章末

第1～3章の `src/ui/ui.js` の `playEnding()` の既定の文。社の祭壇で祈った後に流れていた。置き換えたムービーは M1「小さな社」（第1章の行と最後の行だけを字幕にした）。

```text
勇者がゾーマを倒し、世界には平和が訪れるはずだった。
だが、上の世界には再び魔物があふれ、混乱が広がった。
ダーマ神殿は襲われ、多くの職業の書が焼かれ、散り散りになった。
職を受け継ぐ道は失われ、町は壊れたまま時を止めた。
神官見習いの少年シオンは、一冊の「職業の書」を携えて神殿から脱出した。
その書に導かれ、流れ着いたジパングで槌を取った。
家を建て、田を耕し、柵をめぐらせ、祈りの場を作った。
人々が働き始めた時、白紙の職業の書に文字が戻った。
これは、勇者のいない上の世界で、
人々がもう一度、自分の職を取り戻す物語。
職をつぐ者 〜ジパング復興編〜
― 職をつぐ旅は、ここから続いていく ―
```

## 第3章の結末

第1～3章の `src/content/chapter3.js` の `ending`。ワタリに旅立ちを告げた後（`CH3_DONE` での再演でも）流れていた。置き換えたムービーは M4「旅立ち」（最後の行はタイトルで表した）。

```text
漂着した見習い神官は、
家を建て、田を起こし、港を灯した。
白紙の書に文字が戻るたび、
島には ひとり、またひとりと 職をつぐ者が生まれた。
大工のピノ、料理と畑のイナホ、島に職を遺す神官ジンベエ。
三人は島に残り、この地の暮らしを守っていく。
そして シオンは船に乗る。
農民ミナ、狩人ゴンタ、船乗りワタリと共に――
職を待つ、まだ見ぬ島々へ。
漂着した者は、船をつくる者になった。
職をつぐ旅は、海の向こうへ続いていく。
―― ジパング復興編・完 ――
```

## 第5章の結末

第4～5章の `src/content/chapter5.js` の `ending`。泉の建築完成後に流れていた。置き換えたムービーは M7「帰るべき場所へ」（最後の行はタイトルで表した）。

```text
火を取り戻した者たちは、鉄を暮らしの形に変えた。
祈りを取り戻した者たちは、病める者のそばに立った。
鍛冶屋のベルク、僧侶のナギ、薬草のヨモギ。
ロクとカヤと島の人々は、火と水のつながった町を守っていく。
そして 職をつぐ者は、船に乗る。
農民ミナ、守り手ゴンタ、船乗りワタリと共に――
すべてが失われた、始まりの場所へ。
―― 火山島編・完 ――
```

第4～5章の `playEnding()` には、どこからも使われていない既定の文（「炉は冷え、鉄は眠っていた。」から始まる4行）もありましたが、同時に削除しました。M5の最後の字幕「炉は冷え、鉄は眠る。」「——それでも人は、火を戻すことを選んだ。」は、火山島編のタイトル画面の一文から取ったもので、この文とは別です。
