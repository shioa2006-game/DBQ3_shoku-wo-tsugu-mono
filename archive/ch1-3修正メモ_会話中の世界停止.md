# 第1〜3章リポジトリへの移植メモ: 会話・メニュー中の世界停止

> 対象: `dqb3-tsugumono-ch1-3`（本島編。別環境で開発中のため、このメモだけを残す）
> 出典: `dqb3-tsugumono-ch4-5`（火山島編）で実装・テスト済みの仕様をそのまま移植する。
> 参照実装: `dqb3-tsugumono-ch4-5/src/main.js` / `src/systems/combat.js` / `tests/e2e/pause.test.mjs`

作成日: 2026-07-13

---

## 1. 問題

会話（ストーリー会話・雑談・選択肢）やメニューを開いている間、プレイヤーの入力だけが
無効になる一方で、モンスターのAI・接触攻撃・防衛戦の進行は通常どおり動き続ける。
そのため、会話中にモンスターが近づいてくると、会話が終わるまで一方的に攻撃され続ける。

## 2. 決定した仕様（火山島編で採用済み）

1. **モーダルUIが開いている間は世界を完全停止する**
   - 対象UI: 会話・選択肢・クラフトメニュー(E)・収納箱・職業の書(B)・ポーズ（= `ui.modalOpen` 全体）
   - 停止するもの: モンスターの移動/攻撃/湧き、防衛戦の進行（波・防衛対象へのダメージ）、
     昼夜の時間、作物の成長、木の再生、住民AI、ドロップ品、満腹バフの残り時間、オートセーブのタイマー
   - 動き続けるもの（見た目のみ）: カメラ、描画、たいまつの炎・旗・設計図ゴーストなどのアニメーション
2. **モーダルUIを閉じた直後に1.5秒の被弾猶予（grace）を与える**
   - 会話中に隣まで来ていた敵からの「開幕タコ殴り」を防ぐ
   - 猶予中もプレイヤーからの攻撃は通常どおり可能（被弾だけ無効）
   - 対象はプレイヤーと住民。防衛対象（旗・船など `isBanner`）は対象外
   - 無敵の点滅表示は出さない（`invuln` とは別のフィールドで管理する）

## 3. 実装手順（ch1-3 のコードベース向け）

### 3.1 `src/main.js`

1. コンストラクタにフィールドを追加する（`this.autosaveTimer = 30;` の近く）:

   ```js
   this.wasPaused = false; // 前フレームにモーダルUIが開いていたか
   this.graceT = 0; // 会話・メニューを閉じた直後の被弾猶予（秒）
   ```

2. `frame(dt)` の `if (this.started) { ... }` 内を分割する。
   `this.handleInput(dt);` の直後に停止判定を入れ、それ以降のシミュレーション本体
   （プレイヤー移動〜オートセーブまで）を新メソッド `simulate(dt, time)` へ移す:

   ```js
   if (this.started) {
     this.handleInput(dt);
     const paused = this.ui.modalOpen;
     if (!paused && this.wasPaused) this.graceT = 1.5;
     this.wasPaused = paused;
     if (!paused) this.simulate(dt, time);
   } else {
     this.cameraYawTarget += dt * 0.05;
   }
   // applySky / props.update / blueprints.update / chunks.flushDirty /
   // updateCamera / input.endFrame / renderer.render は従来どおり毎フレーム実行
   ```

   `simulate(dt, time)` の先頭で猶予を減衰させる:

   ```js
   this.graceT = Math.max(0, this.graceT - dt);
   ```

   **`handleInput` は停止中も毎フレーム呼ぶこと**（Esc/E/B でメニューを閉じる操作が
   ここにあるため）。ゲームプレイ入力は `input.enabled = !ui.modalOpen` が既に防いでいる。

3. `simulate` へ移す範囲（ch1-3 の `frame` 内の該当ブロック）:
   - プレイヤー移動・南ゲートのクランプ・持ち物の手持ち表示
   - `updateAim` / `daynight.update` / 魚のかげの再湧き / `farming` / `trees` / `cooking` / `water`
   - モンスター（`updateAmbient` / `update`）と `defense.update`
   - 住民の `update`、ドロップ品の回収、`quests.update`、水中判定、HUD更新、オートセーブ

### 3.2 `src/systems/combat.js`

`attackEntity(e, dmg, fromPos)` の先頭付近、`isBanner` の分岐の**後**に猶予チェックを入れる:

```js
if (e.isBanner) {
  g.defense.damageBanner(dmg);
  return;
}
// 会話・メニューを閉じた直後の被弾猶予（main.graceT）。
if (g.graceT > 0) return;
```

これでプレイヤーと住民の両方が猶予の対象になり、防衛対象（旗・田・船）は対象外のまま。

## 3.3 【重要】停止中の「見た目だけの同期」（これを入れないとキャラがペラペラに見える）

世界を止めると、スプライトをカメラへ向けるビルボード処理（各キャラの update 内の
`rig.group.rotation.y = cameraYaw` など）も止まる。一方でカメラの追従・回転は
毎フレーム動き続けるため、会話中にカメラとスプライトの向きがずれて、
**キャラの板ポリゴンが斜めから見え「ペラペラ」に見える**（火山島編で実際に発生）。

対策: 停止中も「見た目だけの同期」を毎フレーム行う。AI・移動・戦闘は動かさない。

1. `Villager` に追加（`rootSync` とほぼ同じ内容）:

   ```js
   // 世界停止中（会話・メニュー）の見た目だけの同期。
   syncVisual(dt, cameraYaw, world) {
     this.root.position.copy(this.pos);
     this.rig.group.rotation.y = cameraYaw;
     this.rig.faceWorld(this.facing.x, this.facing.y, cameraYaw);
     this.rig.update(dt, false);
     const gy = world.groundYBelow(this.pos.x, this.pos.z, this.pos.y + 0.1);
     this.shadow.position.y = gy - this.pos.y + 0.02;
   }
   ```

2. `Monster` に追加:

   ```js
   syncVisual(dt, cameraYaw) {
     this.sprite.faceWorld(this.facingDir.x, this.facingDir.y, cameraYaw);
     this.sprite.mesh.rotation.y = cameraYaw;
     this.sprite.update(dt); // 2ポーズの揺らぎは見た目だけなので続けてよい
     this.hpBar.rotation.y = cameraYaw;
   }
   ```

3. `main.js` に追加し、停止中に毎フレーム呼ぶ:

   ```js
   if (!paused) this.simulate(dt, time);
   else this.syncVisualsWhilePaused(dt);

   syncVisualsWhilePaused(dt) {
     this.player.rig.group.rotation.y = this.cameraYaw;
     this.player.rig.faceWorld(this.player.facing.x, this.player.facing.y, this.cameraYaw);
     this.player.rig.update(dt, false);
     for (const v of this.villagers) v.syncVisual(dt, this.cameraYaw, this.world);
     for (const m of this.monsters.monsters) m.syncVisual(dt, this.cameraYaw);
   }
   ```

4. あわせて `startNewGame()` の先頭でカメラを既定の向きへ戻す。タイトル画面は
   カメラがゆっくり回り続けているため、これが無いと開幕の会話（第1章の漂着イントロ）
   の構図が毎回バラバラになる:

   ```js
   this.cameraYawTarget = Math.atan2(6.5, 8.0);
   this.cameraYaw = this.cameraYawTarget;
   ```

## 4. ch1-3 固有の注意点

- **防衛戦との整合**: 防衛戦の開始/終了会話は戦闘の外側で再生される設計なので、
  停止による進行不能は起きない。逆に、防衛戦中に Esc ポーズやメニューを開くと
  戦闘が止まる＝実質ポーズになる（仕様として許容。火山島編も同じ）。
- **食事シーン**: `cooking.update` が止まるため、18時の食事シーン判定・`mealTimer` も
  メニュー中は進まない。翌日に持ち越されることはない（時間ごと止まるため）。
- **クラーケン戦**: `defense.update` ごと止まるので触手・本体の攻撃周期も停止する。追加対応は不要。
- **`invuln` と混同しないこと**: 既存の `invuln`（被弾後の点滅つき無敵）はそのまま。
  `graceT` は点滅させない別枠として追加する。
- **セーブ互換**: この修正はワールド生成・セーブ形式に触れないため、
  `GEN_VERSION` の変更や既存セーブへの影響はない。
