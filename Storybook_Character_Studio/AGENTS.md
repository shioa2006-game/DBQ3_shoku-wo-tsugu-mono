# Studioでの作業

このフォルダは「職をつぐ者」用の8方向キャラクター制作原本です。現在のキャラクターは主人公・ミナ・ピノ・イナホ・ゴンタ・ジンベエ・ワタリと、モンスターのスライム・おおこうもり・おおねずみ・どろたぼう・イカです。

- 最初に [README](README.md)、[制作ガイド](docs/CHARACTER_AUTHORING.md)、対象キャラクターのREADMEを読む。
- 作画の原本は `prototypes/*-8dir/character.mjs`、共通部品は `prototypes/shared/`。生成物だけを手で修正しない。
- 主人公シオンは2026-11-07から頭・胴分離の `hero2`（以前の主人公 `adventurer` は合成シート方式で、比較用に残す）。ミナも頭・胴分離方式。新規制作ではミナの部品分離を基礎にし、襟の二重表示を再発させない。
- 元画像との比率・輪郭・重なりを比較する。切り出しやリグの問題を顔や首の位置調整だけで隠さない。
- 顔と頭全体、幅と高さ、真横と斜め前を分けて判断する。既存の縮小率を全員・全方向へ一律適用せず、顎と首の接続を基準に調整する。
- 元画像との比較倍率を揃え、左右両方と変更対象外の方向も確認する。詳細は制作ガイドの「共通ルールの早見表」「比較条件と変更範囲の確認」を参照する。
- 道具の重なり対策では振る動作の自然さを維持する。剣の刃の向きと、手の位置・腕の動き・剣先の軌道を分けて扱う。
- `npm.cmd test` を実行し、作画や出力を変えた場合は対象を再生成する。見た目はStudioの比較ページ（`compare/`、ブラウザーテストは `npm.cmd run test:compare`）でも確認する。以前の画像は `references/` に置き、ゲームのフォルダへ戻さない。
- 通常の再生成はStudio内だけ。ゲーム側の専用試作画像の更新には `--preview-game` を使う。本編への移植はユーザーが決めた段階で行う。
- ゲーム側を変更する場合は、そのフォルダの `AGENTS.md` に従う。
- 作業開始時にGit状態を確認し、他の作業の未保存変更を削除しない。過去の旧4方向エンジン・旧キャラクターは [整理記録](docs/CLEANUP.md) に記載したGit履歴を参照する。

- モンスターは人型の頭胴分離を適用しない。スライムは全身のA・Bシートを同じ接地基準で作り、ゲームの `MonsterSprite` で8方向と切り替えを確認する。

- 当面はCH1～3を優先する。残りのモンスターと共用画像のボスは `prototypes/README.md` を参照。おおこうもりの飛行用余白は専用READMEに記録し、地上キャラの下端121pxをそのまま当てはめない。

- 2026-11-02にCH1～CH3の12種を本編へ移植済み。現在は `--preview-game` の出力画像を本編も使用する。リグ設定変更時はゲーム側 `src/content/rig-profiles/` にも同期する。ゲームの `docs/CHARACTER_ART.md` を参照。
- 2026-11-03に主人公・ミナ・ゴンタ・ワタリ・おおこうもり・どろたぼうを第4～5章へも移植。両編が書き出し先のキャラクターは、書き出し後に `npm.cmd run sync:games` で `game-targets.mjs` の全ゲームへ写す。
