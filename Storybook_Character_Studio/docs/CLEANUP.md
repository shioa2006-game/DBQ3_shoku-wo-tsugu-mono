# 2026-11-01 Studio整理記録

ユーザーの依頼に基づき、主人公とミナの8方向制作をStudioの中心にしました。制作で得た判断基準は [制作ガイド](CHARACTER_AUTHORING.md) に集約しています。

> 2026-11-02追記: 以下は統合前の整理記録です。旧コミットIDは親リポジトリには含まれません。[統合記録](../../docs/REPOSITORY_MIGRATION.md)に従いStudioの履歴bundleを復元して参照してください。

## 残したもの

- 主人公とミナの `character.mjs`、最新SVG・PNG・比較画像・マニフェスト。
- ミナの頭／胴分離レイヤーと `rig-profile.mjs`。
- `prototypes/shared/` の目・鼻・SVG部品・方向順。
- ローカル静的サーバー、同じフォルダのサーバーを再利用する起動機能とそのテスト。
- 2人の制作・再生成・3D比較・移植に必要な説明。

## 削除したもの

| 対象 | 理由 |
|---|---|
| `characters/` | 旧4方向用の戦士・魔法使い・ゴブリン・スライム・王・魔王など。主人公とミナのSVG作画から参照されていない |
| `src/` | 旧Inkstoneの描画エンジン、内蔵剣士・弓兵・骸骨、ダンジョン描画。現行8方向制作の依存先ではない |
| `studio/`、`game/` | 旧カタログのギャラリー・ビューアー・ダンジョンサンプル |
| `tools/sync-catalog.mjs`、`tools/export-game.mjs`、`tools/lib/module-files.mjs` | 旧カタログ登録と旧エンジン持ち出し専用 |
| 旧 `tests/browser/`、`tests/fixtures/`、Nodeの旧ゲーム／カタログテスト | 削除した機能の検証専用。起動テストは維持し、8方向制作と参照切れの検査を追加 |
| 旧 `docs/` のAPI・部屋・4方向制作ガイド、報告・実験画像 | 現在の作業方式と異なる資料。現在の制作ガイドへ置換 |
| 主人公・ミナの旧版PNGと `refinement-v*.png` | 各試行の一時比較資料。知見は制作ガイドに整理し、現行再生成から過去版への依存を除去 |
| `exports/all-characters/` | 旧7キャラクターの生成済みキット。34コードファイルが保存済みソースと一致し、残り6件が生成された入口・登録・説明・メタデータであることを確認して削除 |

Git管理対象の削除は158ファイルです。削除前に各ファイルがコミット `cd35705c77328b2432c80aa788cbf6b3ea89fc30` と一致することをハッシュで検証しました。旧出力キットはGit管理外の40ファイルでした。必要になった場合、旧コード・資料はこのコミットから参照でき、旧キットは同版のエクスポーターから再生成できます。

フォルダ全体を無条件に削除せず、確認したファイルのみを削除しました。他のゲームフォルダや起動中のサーバーには削除操作を行っていません。

## 更新した入口と再生成

- `index.html` は主人公・ミナの最新画像、比較、ダウンロード、3D比較へのリンクに変更。
- `start-studio.bat` / `npm start` は旧カタログ生成なしで利用可能。
- `export-characters.bat` と `npm run export:all` は2人だけを再生成。
- 主人公もミナと同じく、通常出力はStudio内だけに変更。ゲームの専用比較画像へ反映する場合は `--preview-game` を指定。
- 主人公の未正規化PNGもStudioに保存し、両者とも過去版PNGなしで再生成可能にした。
- 主人公の合成シート方式とミナの分離シート方式の違いを明記。作画形状や色は今回変更していない。

## 検証方法

`npm.cmd test` で起動・再利用、現在のSVGの再現、ミナのレイヤー担当、ローカル参照切れを確認します。`npm.cmd run export:all` で旧ソースや旧比較画像なしの再生成を確認し、既存の主人公／ミナのSVG・PNGが整理前と同じであることをGit差分で確認します。

整理時の結果：7件のテストが合格し、2人とも再生成成功。作画原本・既存の最新SVG／PNG・比較画像に差分はありません。ゲーム側リポジトリにも変更はありません。
