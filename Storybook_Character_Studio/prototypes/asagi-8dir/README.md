# アサギの8方向SVG・試作04

第6〜7章の大工見習い「アサギ」。2026-11-10に承認された[元画像v2](../../references/asagi-8dir-v2.png)から制作しました。細い目、面長の輪郭、鼻筋と鼻先、黒縁の丸い眼鏡、中央で分けた波打つ黒褐色の髪を専用の曲線で描いています。浅葱色の作業着、生成りの襟と前掛け、革のベルト、本人の左腰の道具入れを合わせました。

第6〜7章のゲームは未実装のため、現在はStudio内の制作原本です。NPC IDの候補は `asagi`。元の人物写真はリポジトリへ複製していません。

## 試作04：左右の耳の後ろへ髪を追加（2026-11-14）

真横の顔の輪郭が後ろ髪に重なり、耳の後ろへ肌色が広く露出していました。左右の横向きに、耳上から耳の後ろへ落ちる毛束と、耳下で返る小さな毛束を追加しました。顔より手前に重ね、耳の外縁を残しながら後頭部の髪へつないでいます。[左右の拡大比較](output/profile-comparison.png)は、元画像v2とSVGを同じ倍率で並べています。

対象は左・右の2方向です。残り6方向、鼻の作画、胴、リグ設定は試作03を維持しています。

## 試作03：鼻をロクの表現へ調整（2026-11-14）

他のキャラクターとのテイストをそろえるため、[ロク](../roku-8dir/README.md)の鼻を基準にしました。正面・斜め前は鼻の両側を囲む輪郭と丸い小鼻の描き込みを減らし、片側の鼻筋と短い鼻先の線で表現しています。横向きは鼻先の張り出しを少し抑え、輪郭につながる形を整えました。鼻の線と小さなハイライトは肌色のパレットを使います。

作画はロクが使う `../shared/humanoid-kit.mjs` の `adultNose`・`ADULT_PROFILE` を参照し、アサギの目・眼鏡・口の位置に合わせています。[鼻の表現比較](output/nose-style-comparison.png)で正面・斜め前・横を同じ倍率で確認できます。髪、目、眼鏡、口、胴、リグ設定は試作02を維持しています。

## 試作02：頭の大きさ・髪の修正

試作01は耳横と襟足の張り出しが大きく、横向き・背面の毛束が水平な段になっていました。元画像v2と同じ倍率で8方向を比較し、髪の外周を方向別に描き直しました。分け目から縦に落ちるS字の毛束、耳前の返り、襟足の小さなカールを別の面として重ね、短いハイライトを加えています。

頭部の不透明面積は試作01から約8〜13％減りました（128pxセルの上から76pxまでを比較した概算）。顔の輪郭、目・鼻・眼鏡、頭高、首との接続を基準に髪を修正し、頭全体の一律縮小やリグ位置の変更は行っていません。胴のPNGは試作01と同一です。

比較用の元画像はセル単位で先に切り出し、隣のセルの毛先が余白へ混入する問題も修正しました。静止比較と3D比較で共通の切り出し処理を使い、倍率0.27、横中心63.232px、縦余白4pxをそろえています。

## 再生成・確認

Studioルートで実行します。PNGの生成には、既存の第4〜5章の依存関係と公式テストヘルパーが起動できるブラウザーが必要です。

```powershell
npm.cmd run export:asagi
npm.cmd test
npm.cmd run test:compare -- asagi
```

`export:all` にも含めています。`--preview-game` は移植先を設定していないため受け付けません。

Studioを `npm.cmd start` で開き、[アサギの比較ページ](../../compare/ch4-5/characters/?c=asagi)へ進みます。第4〜5章の比較ページと実際のリグを共用しますが、表示は「ダーマ再興編・制作中」です。左が共通倍率で縮小した元画像、右がSVGの頭・胴。8方向を同時に見ながら待機・歩行・ハンマー・剣を切り替えられます。

`reference-normalized.png` は比較用に元画像を128pxセルへ配置したものです。各セルを切り出した後で共通倍率に縮小します。左側は従来の合成シート方式なので、頭と襟の分離の検証は右側の2枚で行います。元画像との輪郭の比較には `comparison.png` も使います。

ブラウザーテストは空きポートで専用サーバーを起動し、そのサーバーだけを終了します。待機の8方向、歩行2位相、ハンマーと剣、元画像への切り替え、水中色、390px幅を確認します。スクリーンショットは `compare/ch4-5/characters/asagi-rig-*.png` に保存し、Git管理しません。
