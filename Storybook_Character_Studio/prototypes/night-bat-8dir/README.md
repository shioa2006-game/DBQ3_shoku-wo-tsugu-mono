# おおこうもりの8方向コード生成・試作01

CH1の `MONSTER_TYPES.bat`。元画像は以前の `references/nonhumanoids/night_bat_idle_a_8dir.png` と `night_bat_idle_b_8dir.png`。紺色の丸い体、長い耳、紫の翼膜と翼骨、黄色い目、小さな牙をコードで描きます。元画像の画素は比較用にだけ使用します。

[制作ガイド](../../docs/CHARACTER_AUTHORING.md)を参照。全身シート方式で、Aは翼を上げる、Bは翼を下げるポーズです。体と足は変形せず、翼の関節と膜を描き替えます。正面・斜め前は2眼、真横は1眼、斜め後ろ・背面は顔なし。左右反転で反対側を作ります。

## 原本と出力

- `character.mjs`: 方向別の体・耳・翼・顔、パレット。
- `export.mjs`: SVG描画、公式正規化、飛行用の固定配置、比較画像とマニフェスト。
- `output/night_bat_code_idle_a_8dir.png`・`night_bat_code_idle_b_8dir.png`: 512×256、128pxセル、4列×2行の全身画像。
- 同名の `.svg`・`.src.png`: 作画原本の出力と正規化前PNG。
- `output/comparison.png`: 元画像とコード生成画像の同倍率比較。
- `output/manifest.json`: 方向順、配置、参照画像、移植先と実際の表示条件。

元画像は飛行中の余白を持ち、下端はAで約98～108px、Bで約109pxです。人型やスライムの接地下端121pxをそのまま使うと体が低く見えます。この試作は公式 `normalize` の後、全方向・両ポーズを一律14px上へ平行移動し、下端107pxに揃えます。拡大縮小や方向別リグ補正はしません。画素欠落がないことを検査します。翼の下端が足より下へ来るポーズを追加する場合は、外接枠ではなく体の基準位置を保つ処理を先に設計してください。

## 再生成・比較

Studioルートで実行（同じ親フォルダにゲームとその依存関係が必要）:

```powershell
npm.cmd run export:bat
npm.cmd run export:bat -- --preview-game
npm.cmd test
```

`--preview-game` は専用の `night_bat_code_idle_*` 画像だけをゲーム側へ書き出します。

[おおこうもりの比較ページ](../../compare/ch1-3/night-bat/)で8方向・A/B固定・交互再生・水中色を確認できます。実際の `MonsterSprite` を本編と同じ倍率0.85、飛行用 `yOffset=0.4`、着色0xffffff、切り替え間隔0.38秒で使います。

確認のコマンド:

```powershell
# Studioで実行（サーバーは自動で起動する）
npm.cmd run test:compare -- night-bat
# ゲームのルートで実行
npm.cmd run test:ci
```

テストは全16セルの正規化と配置、各方向の羽ばたき差分、クラスのUV・倍率・飛行高さ、同期再生、水中色、狭い画面を確認します。Studioの `compare/ch1-3/night-bat/preview.png` と `rig-8dir-a.png`・`rig-8dir-b.png` に比較結果を保存します。

初回試作です。元画像の細かな毛並みやポーズごとの傾きは簡略化しています。移動・追跡・攻撃AIは比較画面の対象外です。本編の画像とモンスター定義は、全キャラクター完成後の移植時に変更します。

## 翼の接続と上下動の調整

翼の上側・下側の付け根を体の内側まで延ばし、方向別の縮小・反転後も胴体に重ねます。特に斜め前・斜め後ろの手前側の翼を確認します。テストでは全16セルの不透明領域がつながっていることも検査します。

比較画面の自動再生では、0.76秒の羽ばたき周期に合わせて上下各0.06の滑らかな上下動を加えます。翼を上げるAで沈み、押し下げるBで上がります。元画像側にも同じ変位を適用し、床の影は地面に置いたまま濃さと大きさを少し変えます。A・B固定時は基準高さで静止します。

上下動は比較画面での飛行表現です。本編の `Monster.updateBat` には巡回時の高度変化と追跡・下降処理があるため、最終移植時に二重加算しないよう統合します。シート自体は同じ体の基準位置を維持し、動作条件をマニフェストにも保存します。
