# 三頭魔竜ヴァルガ・造形試作01

第7章ボスの三頭竜。グロムの頭・胴のSVG作画を継承し、三頭と大型の翼を組み合わせたStudio内の試作です。濃い紫の鱗、古金色の腹板、象牙色の角は確認用の試作色で、確定配色ではありません。

[グロムとの8方向比較](../../compare/ch6-7/varuga/)を開くと、同じカメラと倍率で左右に表示します。初期表示は静止。浮遊の再生・停止と8方向の巡回ができます。浮遊はグロム由来の動作を確認するためのもので、ヴァルガ専用の着地・攻撃・頭別耐久は未制作です。

- `character.mjs`: グロムの描画関数とヴァルガの試作配色。頭・胴各1ポーズ、8方向。
- `rig-profile.mjs`: 三頭の配置、胴・頭の倍率、翼・首の色。中央の首を高く、左右の首を前へ張り出して真横でも頭を分けます。
- `rig.js`: 既存の `DragonRig` を継承。長い首が途切れないよう、首の分割数を18に増やします。第4～5章のグロムには変更を加えません。
- `output/`: 原本SVG・原画PNG・正規化PNG・参照比較画像・マニフェスト。1セル128px、4列×2行、透明背景。頭のシートを三頭で共有し、首・翼・尾は3Dです。

```powershell
npm.cmd run export:varuga
npm.cmd test
npm.cmd run test:compare -- varuga
```

通常の生成先はStudio内だけです。`--preview-game` は移植先未登録として拒否します。移植時は頭・胴のPNGとリグ設定・首の分割処理を一緒に扱い、戦闘数値と着地・攻撃を第6～7章で実装します。`output/comparison.png` のREFERENCEは流用元グロムの画像で、承認済みのヴァルガ原画ではありません。
