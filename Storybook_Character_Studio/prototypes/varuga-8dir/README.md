# 三頭魔竜ヴァルガ・造形・動作試作03

第7章ボスの三頭竜。グロムの頭・胴のSVG作画を継承し、三頭と大型の翼を組み合わせたStudio内の試作です。赤銅色の鱗、金色の腹板、銀色の角は確認用の試作色で、確定配色ではありません。

[グロムとの8方向比較](../../compare/ch6-7/varuga/)を開くと、同じカメラと倍率で左右に表示します。初期表示は飛行姿勢の静止。姿勢・動作から飛行／着地する／地上待機／三頭の噛みつき／三頭の火炎／飛行中の火炎を選べます。着地・攻撃は一度再生して停止し、最初から再生できます。スライダーで途中の姿勢を確認でき、停止中は火炎の形も固定されます。命中判定・ダメージ・頭別耐久はゲーム側で実装します。

- `character.mjs`: グロムの描画関数とヴァルガの試作配色。通常頭・開口頭・胴の各8方向。開閉しても頭のセルの中心と下端は同じです。
- `motion.mjs`: 着地2.6秒、三頭の噛みつき4.6秒、地上・飛行火炎4.5秒。予兆・攻撃・復帰の演出時刻を管理します。数値は試作用で、攻撃判定の仕様ではありません。
- `rig-profile.mjs`: 三頭の配置、胴・頭の倍率、翼・首の色。左右の首を正面で約45度の斜め上へ伸ばし、中央の首も胴より前へ配置します。
- `rig.js`: 既存の `DragonRig` を継承。首を32分割の曲線でつなぎ、後頭部の下に上向きに接続します。首先は球体の半径を考慮して頭の画像面の奥へ収め、横向きでも頬を覆わないようにしています。地上では足元を固定して胴を少し低くし、左右の翼を背中側へ畳みます。着地の沈み込みも足元は維持します。首・尾・翼の骨は反射を抑えた赤銅の質感です。第4～5章のグロムには変更を加えません。
- `output/`: 原本SVG・原画PNG・正規化PNG・参照比較画像・マニフェスト。1セル128px、4列×2行、透明背景。通常頭と開口頭のシートを三頭で共有し、首・翼・尾は3Dです。

```powershell
npm.cmd run export:varuga
npm.cmd test
npm.cmd run test:compare -- varuga varuga-motions
```

通常の生成先はStudio内だけです。`--preview-game` は移植先未登録として拒否します。移植時は頭・胴のPNGとリグ設定・首の曲線・材質処理を一緒に扱い、`motion.mjs`・開口頭PNGも含めて移植し、戦闘数値・AI・命中判定と動作を第6～7章で接続します。`output/comparison.png` のREFERENCEは流用元グロムの画像で、承認済みのヴァルガ原画ではありません。

リグの `update()` に渡す `origin` は従来と同じ浮遊時の胴の基準位置です。地上の床は `origin.y - config.hover` として計算します。`setMotion()` で演出を開始し、`poseState.done` で終わりを確認できます。Studioの攻撃は描画確認用です。
