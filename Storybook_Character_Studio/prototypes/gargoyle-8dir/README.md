# ガーゴイル（第7章の神殿防衛）

[飛行4方向画](../../references/gargoyle-flight-4dir-v1.png)と[着地修正版](../../references/gargoyle-landed-v2.png)を基に、[作画コード](character.mjs)で同じ石の体、角、牙と翼を描く。飛行のA/Bは翼を上げる・下ろす動き。地上のA/Bは翼を左右の肩から腰へ畳んだまま、左右の足を踏み替える動き。着地時に飛行用の2枚から地上用の2枚へ切り替える想定。

Studioで `npm.cmd run export:gargoyle` を実行すると、`output/` に飛行・地上それぞれのA/BのSVG・原画PNG・正規化PNG、比較画像、マニフェストを生成する。各シートは128pxセルを4列×2行で配置する。飛行の高さは表示時のオフセット0.4で表現する。

[比較画面](../../compare/ch4-5/monsters/?c=gargoyle)で飛行・地上、8方向、ポーズを選べる。地上の参照画は左斜め前の1枚を固定表示する。

## 岩砕きのガーゴイル：静止造形・試作01

通常型と共通の作画コードに `buildHeavyGroundSheet` を追加。顔・左右の耳・2本の角・尾を引き継ぎ、胸と肩、前腕を厚くした。両足を開いて接地し、岩の拳を低く構える。畳んだ翼は左右それぞれの肩から腰へ配置する。単純な全身拡大ではなく、同じ表示倍率でも上半身の量感が変わる造形。

[通常型との比較](../../compare/ch4-5/monsters/?c=gargoyle_heavy)では、通常型を1倍、重装型を1.3倍で表示して8方向を比べる（2026-11-14調整）。「種類」で静止・飛行・攻撃を選ぶ。静止モードでは左が通常型の地上A、右が重装型の静止姿勢で、自動切り替えを使わない。1.3倍はStudioの確認用の表示設定とし、本編での最終倍率は移植時に確認する。

`npm.cmd run export:gargoyle` で通常型と一緒に再生成する。出力は `output/gargoyle_heavy_ground_code_idle_{a,b}_8dir.{svg,src.png,png}` と `heavy-ground-manifest.json`・`heavy-ground-comparison.png`。既存の `MonsterSprite` 用にA/Bを出力するが、静止試作のため両方は同じ画像。比較ボードの参照は通常型の着地設定画であり、重装型の専用設定画ではない。ゲームへは移植しない。

確認: `npm.cmd test` と `npm.cmd run test:compare -- gargoyle gargoyle-heavy`。

頭部は通常型と同じ見かけの大きさになるよう、作画時に1/1.3へ縮小した。全身の表示倍率1.3と組み合わせ、胸・肩・前腕の量感を強める。顔・耳・角を一緒に縮小し、頭の取付位置と体の造形は維持する。

## 岩砕きのガーゴイル：飛行・攻撃

承認された静止造形と頭身を基に、以下の2ポーズを各8方向で追加した。

| 動作 | A | B | 比較画面の表示 |
|---|---|---|---|
| 飛行 | 翼を上げる | 翼を打ち下ろす | 足を後ろへ引き、高さオフセット0.4。通常型も飛行姿勢で比較。0.38秒ごとに切り替える |
| 攻撃 | 両腕を肩から振りかぶる | 腰から上を前へ倒して拳を振り下ろす | 両足を接地したまま、Aを0.75秒、Bを0.35秒表示。左は通常型の地上Aで固定 |

`buildHeavyFlightSheet` と `buildHeavyAttackSheet` が原本。腕の石の面は肩を支点に回転し、飛行では通常型と同じ翼の構造を用いる。静止姿勢と通常型の出力は維持した。「ポーズ」でA/Bそれぞれに停止して全方向を確認できる。

`npm.cmd run export:gargoyle` で `gargoyle_heavy_{flight,attack}_code_idle_{a,b}_8dir.{svg,src.png,png}` と各 `heavy-{flight,attack}-manifest.json`・比較ボードも生成する。ファイル名の `idle` は共通の書き出し命名で、攻撃シートの用途は攻撃。マニフェストの攻撃 `frameDurations` は秒単位、`interval:null` は一律間隔ではなく姿勢ごとの時間で制御することを表す。

今回はStudioの動作素材まで。地上歩行、飛来から着地への切り替え、壁への命中判定・ダメージ・攻撃後の待機への復帰はゲーム制作時に接続する。
