# アイテムアイコン・試作02（第1～3章）

ゲームのインベントリ・ホットバー・クラフト一覧・設計図・地面のドロップで使うアイテムアイコンを、16×16のドット絵としてコードで描きます。今のゲームはブロックの模様かemojiで表示していて、実物と違う絵柄が多いため、Studioで原本を作りPNGで移植します。

## 方針

- 1アイコン16×16px、透明背景。ブロックの模様（16pxタイル）と同じ画素の大きさにそろえる。本編では2倍（32px）で、整数倍のまま表示する。
- 色は全アイコン共通の `PALETTE`。ゲームの設置物・手持ち道具（`props.js`・`rig.js`・`blocks.js`）と同じ色を使う。光は左上から。
- 輪郭線は書き出し時に自動で付ける（`OUTLINE`）。外側だけに付け、柵の横木の間のような囲まれた隙間は透明のまま。絵は四辺から1画素あける。
- 手持ち道具・設置物のアイコンは、本編の3Dモデルと形・配色を合わせる（例: こん棒は鋲つきの棍棒、銅の剣は銅の刃・金の鍔・赤い柄）。

## 原本と出力

- `icons.mjs`: 作画原本。`PALETTE`と、ID→描画関数の `ICONS`。16行×16文字の文字絵（`art`）か、線・楕円などの部品で描く。
- `pixel.mjs`: 描画部品（画素・矩形・文字絵・太さの変わる線・楕円・多角形・自動輪郭線）。依存なし。
- `cubes.mjs`: 立方体ブロックのアイコン。
- `catalog.mjs`: 第1～3章の全50アイテム（ゲームの `ITEMS` と同じID・順番）と、今の表示。
- `export.mjs`: PNG書き出し。ブラウザは使わず、ゲーム側の `pngjs` で直接書き出す。
- `output/item_icons_16.png`: ゲームへ渡すアトラス（16pxセル・8列、作画済みだけ）。
- `output/manifest.json`: アイテムID→セル位置（`cells`）、未作画の一覧（`pending`）、表示条件。
- `output/preview.png`: 確認用。上段は全50件を4倍（灰色は未作画）、下段は作画済みを実寸2倍で、ホットバー色と草地の上に並べる。
- `index.html`: 今の表示（emoji・模様）と新しいアイコンを並べる比較ページ。

## 再生成

同じ親フォルダにゲーム `dqb3-tsugumono-ch1-3` とインストール済みの依存関係が必要です。Studioで実行:

```powershell
npm.cmd run export:items
npm.cmd run export:items -- --preview-game
npm.cmd test
```

`--preview-game` は、ゲーム `dqb3-tsugumono-ch1-3/assets/items/` の `item_icons_16.png` と `item_icons_16.json`（ゲームが読む位置情報）も書き換えます。完成した16px画像で正規化はないため、`art_src/` は経由しません。Studioのテストは、ゲーム側の画像と位置情報が書き出し結果と一致することも確認します。

比較ページはStudioのサーバー（`npm.cmd start`）で `prototypes/item-icons/` を開きます。

## 進み具合

試作01でずれの大きい12件、試作02で残りの38件を作画し、第1～3章の全50件が揃いました（`pending` は空）。

- 立方体ブロック11件（土・石・すな・木材・板材・白かべ・かやぶき・耕した土・用水路・帆・船の外板）は `cubes.mjs` で斜め上から見た立方体に描く。面ごとの模様と色はゲームの `blocks.js` の16pxタイルに合わせ、上面・左面・右面の明るさを変える。
- 手持ち道具はこん棒・剣を斜め、ハンマー2種を頭が横のT字にした。斜めにすると石の頭が斧に見えるため。
- スライムゼリー・こうもりのはね・こうもりのマントの紫と紺は、Studioのスライム・おおこうもりの色に合わせた。

## 本編への移植（第1～3章は移植済み）

2026-11-03に第1～3章へ移植しました。

1. ゲームの `itemIcon()`（`src/game/items.js`）が `assets/items/item_icons_16.png` を読み、36pxの画像の中に2倍（32px）で描く。画像が読めない間とセルの無いIDだけ、従来のブロックの模様・emojiを使う。読み込み後にホットバーを描き直す。
2. 地面のドロップは同じ画像を使い、拡大時もドットがぼけないようにした。
3. もちもの（30px→36px）・クラフト一覧（32px→36px）・設計図（20px→18px）の表示を整数倍にそろえた。食事のトーストはemojiを使わない。
4. ゲームの `tests/e2e/item-icons.test.mjs`（`test:ci` に含む）で、全アイテムが画像のアイコンを使うこと、ホットバーとドロップの表示を確認する。

第4～5章は未移植です。同じ原本に章ごとの一覧を足し、共通のアイコンは同じ画像を使う予定です。
