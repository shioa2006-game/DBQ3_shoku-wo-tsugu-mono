## 作り方

- 設定画は4列×2行（正面・左斜め前・左・左斜め後／背面・右斜め後・右・右斜め前）。各セル（443.5px四方）の座標で、方向ごとに髪・顔・服・本の形を `character.mjs` に書いた（設定画の画素は使わない）。
- 縮尺は全方向で同じ（設定画1px = セル0.345px）。各方向のチュニックの中心がリグの絵の中心 u=.494 に来るように置き、縦は既存の正規化で下端121pxに揃える。
- 横方向は正規化しない（書き出しの `keepDrawnX`）。横向き・斜めでは大きな後ろ髪と背中の本で外接枠の中心が胴からずれ、外接枠で中央合わせすると3Dの腕・脚が服の下から外れるため。Studioのテストは、この案だけ外接枠ではなく裾の中心を確かめる。
- 髪（2026-11-05 改訂）は設定画の線そのものを測って描く。各セルで、外形（アホ毛を含む）の座標を不透明部分の外周から、毛束の間の線の座標を髪の中の濃い線の芯から測り、点を間引いて `character.mjs` に書いた。前髪の下の縁とえり足は、測った座標を拡大図で確かめながら手で置いた。描くときは点を通る滑らかな曲線にし、毛先（指定した点と急に折れる点）だけ角を残す。毛束の線は両端を細くし、すぐ下に薄い陰を付ける。色は設定画から拾った橙寄りの金色で、明るい色は頭頂近くと、つむじを囲む光の帯だけに使う。
- 測った髪は、リグの頭の切り出し範囲（セル x 19.7〜106.8・y 5.8〜76.8）へ収めるため、アホ毛の上部（y 30より上）を全方向で高さ85%にし、左斜め前（x 300より後ろ）と真横（x 215より後ろ）の後ろ髪を浅くした。
- 右側の3方向は左側を反転。左右非対称なのは左腰の小物入れだけで、反転した向きでは描き分ける。
- 顔は共通の目の部品ではなく、この案専用の大きな目（白目・虹彩・2つの光・太い上まつげ）にした。正面と斜め前は、頬とあごを設定画の幅まで（あごは少し広めに）広げ、目の間隔も広げた（正面の目の中心 277/333 → 273/337、虹彩は白目の内側寄り）。
- 目（2026-11-07 改訂）は設定画に合わせて縦長にした。虹彩は縦長の楕円で、向きごとの幅を設定画から測った値に寄せた（正面 幅21×高さ30、左斜め前の手前 幅16・奥 幅11、真横 幅11）。横を向くほど細く、白目は外側にだけ見える（`eye()` の `iris` が虹彩の幅、`shift` が鼻側への寄り）。大きな光は虹彩の左上、小さな光は右下。

### 試作03の胴

- **斜め向き（2026-11-07 改訂）**: 左斜め前・左斜め後（と反転の右斜め前・右斜め後）は、胴を45度回した形で描く。チュニックの中心を手前の角として、斜め前は正面と脇、斜め後は背中と脇の2面に分け、各面の上のもの（ベルト・裾・ホルダー・本・肩紐）を角から奥の縁へ向けて少しずつ上げる（`turn()`、幅1につき0.1）。ゲームのカメラは見下ろしなので、奥ほど高く見える3Dの脚・腕と向きがそろう。角をチュニックの中心に置くので、裾の一番低い所はリグの絵の中心のまま。奥の肩側の縁は裾に向けて広げ（左斜め前 152→146、左斜め後 182→193）、3Dの奥の腕が胴の陰に入るようにした。脇の面は陰の色。
- **斜め向きの奥の肩（2026-11-07 改訂）**: リグは斜め向きで奥の腕を胴の板の後ろ（前後のずれ `limbDepthScale` 0.42）に置くため、見下ろしのカメラでは奥の肩が正面より約12（設定画の単位）高く映る（手前は約12低い）。肩の左右の位置（中心から0.099＝0.14×cos45°）は正しいが、絵の肩の線はそこまで上がっていなかったため、腕の上端が肩の上に飛び出して見えていた。斜め前はベストの奥の肩を角張らせて高くし、斜め後は本を設定画と同じ高さ（上端203、設定画の右斜め後ろと同じく奥の角が髪の下端に届く）まで伸ばして、腕の上端を隠した。`limbDepthScale` を小さくする案（0.25）は、歩行で奥の腕が胴の手前に出て本に重なるため採らない。
- **服**: 胴の基本は紺のベスト（`#293d75`）。正面では左右の前身頃の間から生成りの服（`#f1e3c4`）が縦に広く見え、前身頃の縁は直線（濃い線と明るい縁取り）。左斜め前では生成りが遠い側へ寄って細くなり、手前の前身頃が側面へ回り込む。真横では生成りは前の縁の細い帯だけ。斜め後ろ・背面はベストの背中だけで、生成りは襟だけ。肩から腕にかぶさる部品はなく、紺の3Dの袖（`sleeve: 0x293d75`）が紺のベストの肩に直接つながる。
- **首元**: 生成りの小さな立ち襟（正面は中央に小さな切れ込み）。リボン・スカーフ・金具は付けない。
- **肩紐**: 背中のホルダーの革の肩紐。正面は胸の左右をベルトまで下り、左斜め前は手前の肩を越えてホルダーへ、奥は胸を下りる。真横・斜め後ろ・背面は肩を越えて背中へ回る。
- **職業の書**: 表紙は深緑（`#365c47`、縁は暗い緑 `#203b31`）、金の「開いた本」の紋章（`#d6aa51`）と上の角の小さな金具。横・斜めでは生成りのページの小口（左右の表紙の縁に金の細い線）、背面・左斜め後ではページの束の上端を表紙の上に見せる。下半分は茶色の革のホルダー（`#805536`）に収まり、ホルダーの上端は暗い縁で本と分ける。正面では、設定画と同じく本の上の角が両肩の後ろから見える（影になった暗い緑の裏表紙と、上から見えるページの上端）。体より少し広くし、3Dの腕の上端（この向きで y 約200）が本の手前に来るようにした（2026-11-07。本を描かなかったときは、腕の上端が下がった肩の線より上に出て、いかり肩に見えた）。肩紐は本の上端から肩を越えて胸を下りる。
- **そのまま残したもの**: 茶色の革ベルトと金の留め金、左腰の小物入れ（反転した向きでは描き分け）、焦げ茶のズボン・茶色のブーツ（3Dリグ）。

## 設定画との対応

| 向き | 頭 | 胴・小物入れ・職業の書 |
|---|---|---|
| 正面 | 設定画どおり。中央の前髪は両目の間へ、横の毛先は外へ上向きに跳ねる。顔の左右の縁に沿って細い毛束が下りる | 生成りの服が中央に広く、両側に紺のベスト。肩紐が胸の左右をベルトまで下りる。小物入れは画面右 |
| 左斜め前 | 設定画どおり | 生成りが遠い側へ寄って細くなる。右肩の後ろに本の小口とホルダー。肩紐が手前の肩に掛かる。小物入れは手前の腰 |
| 左（真横） | 後ろ髪を少し浅くした（頭の切り出し窓に収めるため） | 紺のベストで、前の縁に生成りの細い帯。本の厚みとページの小口、ホルダー、肩紐。小物入れは腰の横（3Dの腕の陰） |
| 左斜め後 | **v2の設定画の右斜め後ろを反転して使用**（耳と頬だけ）。設定画の左斜め後ろは横顔の目・口まで見え、真横とほぼ同じで右斜め後ろとも食い違うため、回転のつながりを優先した | ベストの背中。深緑の表紙（紋章）と左側の小口、ページの上端、ホルダー、肩紐。小物入れは手前の腰に少し見える |
| 背面 | 頭頂のつむじから毛束が回る。耳が髪の下から見える | ベストの背中と、本の両脇の肩紐。深緑の表紙と金の紋章、ページの上端。ホルダーは本の下側だけを覆う |
| 右斜め後・右・右斜め前 | 左側の反転 | 左側の反転。小物入れは右・右斜め後では体の向こう側で描かず、右斜め前は腰の奥に少しだけ見せる |

3Dリグでは頭が胴の上部に重なるため、本の上端は首元より下に置き、髪で紋章が隠れないようにした。

## 原本と出力

- `character.mjs`: 方向ごとの作画。`hero2Local(view)` は比較ツール用に設定画の座標のまま描く。
- `rig-profile.mjs`: 腕の位置、頭の前後位置と方向別の高さ。腕は今の主人公と同じ付け方（リグの既定値: 付け根 `armSep:.14`・傾き `armRestTilt:.34`・肩の高さ `shoulderLift:0`・袖 `sleeveY:-.12`）で、腕の長さ・手の位置・道具を振る位置がそろう。2026-11-06 に一度、設定画に合わせて腕を短く下げたが、手が短く見えたため今の主人公と同じ付け方に戻した。
- 攻撃（2026-11-07）: 右斜め前は道具を持つ手が手前で、振り上げた道具が顔の前を横切る。平らな頭の板が3Dの道具を切ってめり込んで見えたため、`toolOverHead:['front_right']` でこの方向の攻撃中だけ道具を頭の板の上に描く（`rig.js` の任意設定。振る軌道・握り・道具の向きは今の主人公と同じ）。他の方向は、道具が頭の横か後ろを通るため指定しない。`test:compare -- hero2` が設定の効く方向・時間を検査し、`hero2-rig-swing-front-right.png`（今の主人公との振り上げの比較）を保存する。
- `export.mjs`: 書き出しと比較画像。`studioOnly` のため `--preview-game` は使えない。
- `output/hero2_code_head_layer_8dir.png`: 頭（髪・顔・耳）。首と襟は含めない。
- `output/hero2_code_torso_layer_8dir.png`: 胴（首・襟・生成りの服・紺のベスト・肩紐・ベルト・小物入れ・ホルダー・職業の書）。
- `output/hero2_code_body_8dir.png`: 比較用の合成。
- `output/comparison.png`: 設定画（0.5倍）と生成画像（1.45倍）を同じ大きさで8方向並べた比較。
- `output/layers.png`: 頭・胴・合成のシートを1.75倍で並べたもの。
- `output/v02-v03.png`: 試作02（`v02/` の保存画像）と試作03の合成を、同じ2倍で8方向並べた比較。
- `v02/`: 試作02の頭・胴・合成の画像、比較画像とリグ設定（`HERO2_V02_RIG_PROFILE`）。比較ページ `?c=hero2v02` が読む。再生成しない。

## 採用する場合

本編へ移す段階はユーザーが決めます。採用時は次をまとめて行います。

1. `game-targets.mjs` に `humanoid('hero2', 'humanoid-layers', ['ch1-3', 'ch4-5'])` を追加し、`export.mjs` から `studioOnly` を外して `--preview-game` と `npm.cmd run sync:games` で両編へ書き出す。
2. 両編の `src/entities/player.js` を `headSheetUrl` / `bodySheetUrl` の分離読込とこの案のリグ設定・手足の色へ切り替える（今の主人公は合成シート1枚）。横方向を正規化しない書き出しなので、ゲーム側のシート検査（`tests/e2e/sheets.test.mjs`）の中心判定との関係も確認する。
3. 両編の `test:ci` と `test:e2e`、Studioの比較テストを実行し、道具を振る動作・水中色も確認する。

## 残っている違い

- 髪: 外形と主な毛束の線は設定画から測ったが、細かな毛束の線は128pxセルで潰れるため省いた（各方向16本前後）。つやは設定画のまだらな明るい部分を、つむじを囲む光の帯で置き換えている。
- 3Dリグの正面では、今の主人公の袖がコートの肩に重なるのと同じく、紺の袖がベストの肩の外側に重なる（3Dの腕が胴の画像より手前にあり、腕の付け方を今の主人公にそろえたため）。同じ紺なのでつながって見える。素手の球は設定画の握りこぶしより大きい（リグ共通の大きさ）。
- 設定画の短い袖のふくらみは描いていない（袖は3Dリグの紺の腕）。真横では前の縁の生成りの帯が、設定画より少しはっきり見える。
- 斜め向きでは、奥の手が胴の奥側の縁から少し見える。リグは腕を全方向で同じ角度（`armRestTilt:.34`、今の主人公と同じ）だけ外へ開くため、奥の手の中心が胴の縁の近くに来る（今の主人公でも同じ見え方）。腕の開きを方向別に変える設定はリグにない。
- 真横と左斜め前の後ろ髪、全方向のアホ毛の上部は、頭の切り出し窓に収めるため設定画より少し短い。
- 手（素手）は3Dの陰影で設定画より明るく黄みがかって見える。
