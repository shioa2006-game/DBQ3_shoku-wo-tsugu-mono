# 主人公シオンの新デザイン案・試作02

主人公シオン（ダーマ神殿から「職業の書」を守って逃げ延びた神官見習い）の見た目の変更を検討するための案です。**正本は8方向の設定画 [`references/hero-redesign-8dir-v2.png`](../../references/hero-redesign-8dir-v2.png)** です。本編の主人公（[adventurer-8dir](../adventurer-8dir/README.md)）は変えていません。出力はStudio内だけで、`game-targets.mjs` にも載せていません。採用するかどうかはユーザーが比較結果を見て決めます。

試作01（2026-11-05）は4方向の設定画 [`hero-redesign-4dir-v1.png`](../../references/hero-redesign-4dir-v1.png) から斜め方向を推測して描いたため、作り直しました。

## 作り方

- 設定画は4列×2行（正面・左斜め前・左・左斜め後／背面・右斜め後・右・右斜め前）。各セル（443.5px四方）の座標で、方向ごとに髪・顔・服・本の形を `character.mjs` に書いた（設定画の画素は使わない）。
- 縮尺は全方向で同じ（設定画1px = セル0.345px）。各方向のチュニックの中心がリグの絵の中心 u=.494 に来るように置き、縦は既存の正規化で下端121pxに揃える。
- 横方向は正規化しない（書き出しの `keepDrawnX`）。横向き・斜めでは大きな後ろ髪と背中の本で外接枠の中心が胴からずれ、外接枠で中央合わせすると3Dの腕・脚が服の下から外れるため。Studioのテストは、この案だけ外接枠ではなく裾の中心を確かめる。
- 髪の輪郭は「毛先」と「付け根」の点で書き、付け根に近い側を凸・反対を凹にして毛先が丸く跳ねる形にした。毛束の線は付け根から頭頂へ向けて自動で引く。
- 右側の3方向は左側を反転。左右非対称なのは左腰の小物入れだけで、反転した向きでは描き分ける。
- 顔は共通の目の部品ではなく、この案専用の大きな丸い目（白目・大きな虹彩・2つの光・太い上まつげ）にした。

## 設定画との対応

| 向き | 頭 | 胴・小物入れ・職業の書 |
|---|---|---|
| 正面 | 設定画どおり。中央の前髪は両目の間へ、横の毛先は耳の高さで外へ跳ねる | 肩掛けは襟の下で左右に分かれる。本の上端が両肩の後ろから見える。小物入れは画面右 |
| 左斜め前 | 設定画どおり | 右肩の後ろに本の小口とホルダー。肩紐が手前の肩に掛かる。小物入れは手前の腰 |
| 左（真横） | 後ろ髪の跳ねを少し内側へ寄せた（頭の切り出し窓に収めるため） | 本の厚みと白いページの小口、ホルダー、肩紐。小物入れは腰の横（3Dの腕の陰） |
| 左斜め後 | **設定画の右斜め後ろを反転して使用**（耳と頬だけ）。設定画の左斜め後ろは横顔の目・口まで見え、真横とほぼ同じで右斜め後ろとも食い違うため、回転のつながりを優先した | 設定画どおり。紋章の表紙と左側の小口、ホルダー、肩紐。小物入れは手前の腰に少し見える |
| 背面 | 頭頂のつむじから毛束が回る。耳が髪の下から見える | 紺の表紙と金の「開いた本」の紋章。ホルダーは本の下側だけを覆う |
| 右斜め後・右・右斜め前 | 左側の反転 | 左側の反転。小物入れは右・右斜め後では体の向こう側で描かず、右斜め前は腰の奥に少しだけ見せる |

背中の本は、背面・斜め後ろでは紺の表紙（紋章付き）、横向き・斜め前ではページの小口が見える。3Dリグでは頭が胴の上部に重なるため、本の上端は首元より下に置き、髪で紋章が隠れないようにした。

## 原本と出力

- `character.mjs`: 方向ごとの作画。`hero2Local(view)` は比較ツール用に設定画の座標のまま描く。
- `rig-profile.mjs`: 腕の位置（袖がチュニックのすぐ外から肩掛けの下へ出る）、頭の前後位置と方向別の高さ。
- `export.mjs`: 書き出しと比較画像。`studioOnly` のため `--preview-game` は使えない。
- `output/hero2_code_head_layer_8dir.png`: 頭（髪・顔・耳）。首と襟は含めない。
- `output/hero2_code_torso_layer_8dir.png`: 胴（首・襟・肩掛け・チュニック・ベルト・小物入れ・ホルダー・職業の書）。
- `output/hero2_code_body_8dir.png`: 比較用の合成。
- `output/comparison.png`: 設定画（0.5倍）と生成画像（1.45倍）を同じ大きさで8方向並べた比較。
- `output/layers.png`: 頭・胴・合成のシートを1.75倍で並べたもの。

`test:compare -- hero2` は、比較ページ [`compare/ch4-5/characters/?c=hero2`](../../compare/ch4-5/characters/?c=hero2) を3Dリグで開いて8方向・歩行・攻撃（鉄の剣）を検査し、`compare/ch4-5/characters/hero2-rig-8dir.png`・`hero2-rig-actions.png`・`hero2-rig-old-new.png`（今の主人公との比較）を保存します（Git管理しない）。比較ページは左が今の主人公（本編の画像・手足の色・リグ設定）、右がこの案です。

## 採用する場合

本編へ移す段階はユーザーが決めます。採用時は次をまとめて行います。

1. `game-targets.mjs` に `humanoid('hero2', 'humanoid-layers', ['ch1-3', 'ch4-5'])` を追加し、`export.mjs` から `studioOnly` を外して `--preview-game` と `npm.cmd run sync:games` で両編へ書き出す。
2. 両編の `src/entities/player.js` を `headSheetUrl` / `bodySheetUrl` の分離読込とこの案のリグ設定・手足の色へ切り替える（今の主人公は合成シート1枚）。横方向を正規化しない書き出しなので、ゲーム側のシート検査（`tests/e2e/sheets.test.mjs`）の中心判定との関係も確認する。
3. 両編の `test:ci` と `test:e2e`、Studioの比較テストを実行し、道具を振る動作・水中色も確認する。

## 残っている違い

- 髪: 128pxセルで読める大きさの毛束にまとめた。設定画より毛先がやや鋭く、細かな毛束の数は少ない。
- 3Dリグでは袖の上端が肩掛けの外側の角に少し重なる（3Dの腕が胴の画像より手前にあるため）。
- 真横の後ろ髪は頭の切り出し窓に収めるため、設定画より少し短い。
- 手（素手）は3Dの陰影で設定画より明るく黄みがかって見える。
