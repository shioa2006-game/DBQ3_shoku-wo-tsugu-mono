## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch3-departure
```

1. [`../shared/cast.mjs`](../shared/cast.mjs) が、登場人物（`cast.mjs` の一覧）の頭・胴のSVGを、Studioの作画コード（`prototypes/<id>-8dir/character.mjs`）から `parts/cast.json` へ書き出します。手足の色（ゲームの3Dリグと同じ）と、胴の画像から測った肩・裾の位置も添えます。
2. `src/build.py` が、5場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

`index.html` と `parts/cast.json` は生成物です。手で直さず、`src/` を直して生成し直します。人物の作画を変えたときも、生成し直すとムービーに反映されます（`npm.cmd test` は、部品が作画コードと食い違うと失敗します）。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 完成した試作（生成物） |
| `build.mjs` | 生成の入口（部品の書き出し → Pythonの組み立て） |
| `cast.mjs` | 登場人物と向き（正面：見送りの三人・船の上の四人、背面：見送る三人の後ろ姿） |
| `src/build.py` | ストーリーデータ（表示時間・字幕・カメラ・タイトルの時刻）と、タイトル・パネルの文言 |
| `src/scenes.py` | 5場面のSVG（`scene1()`～`scene5()`）と、各場面の動き（`S1_CSS`～`S5_CSS`） |
| `src/props.py` | 小道具：船・灯台・小屋・食堂・社・田・畑・かかし・のぼり旗・木 |
| `parts/cast.json` | 書き出した人物の部品（生成物） |
| `reference/storyboard.md` | 絵コンテ |
| `screenshots/` | ブラウザーテストが保存する静止画（Git管理しない） |

人物の手足・姿勢・縁の光は共通の [`../shared/figures.py`](../shared/figures.py)、再生処理は [`../shared/engine.py`](../shared/engine.py) にあります（[共通部品の説明](../shared/README.md)）。

## 作画上の約束ごと

- 人物の頭・胴は正式デザインの作画コードのまま。ムービーで描くのは手足（色はゲームの3Dリグと同じ）と姿勢だけ。全員をゲームと同じ128pxのセル座標で描くので、背丈と頭の大きさの比がゲームと同じになる。
- 小道具の形はゲームで建てたもの（`src/game/blueprints.js`）に合わせる：板の甲板とタール塗りの舷側、一段高い船尾楼と真鍮の舵輪、6段の帆柱と帆桁、わらを織った大きな帆。石積みの灯台と板の灯室。白い壁の食堂、赤い鳥居と水色の祭壇の社。
- 昼の場面なので、船の灯りは光らせない（形だけ）。灯台の灯りは「港を灯した」に合わせて光らせる。
- 第3章で描いていないもの（船の名前、旗の紋章、航海の行き先の島の姿）は加えない。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s5-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。

## 確認する

```powershell
npm.cmd test

```

`npm.cmd test` は、人物の部品が作画コードと一致すること、字幕が第3章の結末文の行と順番どおりに一致すること、正式デザインの人物が場面2・3に出ること、id の接頭辞、Pythonでの再生成が同じ内容になることを確かめます。`test:movie` は、空いているポートでStudioのサーバーを起動し、第1～3章のテスト用ブラウザーで実際に再生します（各場面の静止画、自動再生の完走と所要時間、クリックでの送りとタイトルの停止点、スキップ・Esc・再再生、モーション軽減、スマートフォンの縦・横、ページのエラー）。

## ゲームでの扱い（2026-11-08に組み込み）

- Studioの `npm.cmd run sync:movies` で `dqb3-tsugumono-ch1-3/assets/movies/` の `ch3-departure.html` へ写し、両編共通の `game-shared/story-movies.mjs` が全画面で再生する（[組み込みの仕組み](../../../docs/story/planned/story-movies.md#integration)）。このムービーを生成し直したら、写し直す（Studioのテストが写しと生成物の一致を確かめる）。
- 入る場所は、`CH3_FAREWELL` でワタリに旅立ちを告げた後（`quests3.js`）。`CH3_DONE` でワタリと話すと見られる再演でも流す。以前の文字の結末（`CH3.ending`）を置き換え、その文字の結末は2026-11-08に削除した（全文は[削除した文字の章末](../../../docs/story/reference/removed-text-endings.md)）。ムービーを流せないときは、文字を出さずに `CH3_DONE` へ進む。
- 船出の前の会話（ミナ・シオン・ジンベエ・ワタリ）はそのまま。ムービーは会話の後、出航の場面から始まる。
