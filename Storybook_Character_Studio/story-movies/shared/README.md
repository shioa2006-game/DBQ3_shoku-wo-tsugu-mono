# SVGストーリームービーの共通部品

[ムービーの一覧](../index.html)（Studioの `/story-movies/`）の各ムービーが使う部品です。2026-11-08、2本目の「旅立ち」（[`../ch3-departure/`](../ch3-departure/README.md)）を作るときに、プロローグから取り出してまとめました。

| ファイル | 役割 |
|---|---|
| `engine.py` | 画面の骨組み（ステージ・字幕・HUD・開始/終了パネル）、CSS、再生エンジン `StoryPlayer`、1ページへの組み立て（`page()`）。プロローグの再生処理をそのまま移したもので、作品ごとに違うのはルート要素の id、ストーリーデータの定数名、確認用に `window` へ出す名前だけ |
| `helpers.py` | 作画用の汎用関数（山の稜線、すやり霞、雲、炎、渦巻き、草、星形など） |
| `cast.mjs` | 人物の頭・胴を、Studioの作画コードからゲームと同じ128pxのセル座標で書き出す（第1～3章の7人と、第4～5章の住民7人）。手足の色（ゲームの3Dリグと同じ）と、胴・頭の画像（`output/*_layer_8dir.png`）から測った肩・裾・頭の位置を添える |
| `figures.py` | ムービー用の人物：`cast.mjs` の部品に手足（袖・ズボン・手・ブーツ）を付け、姿勢（腕を下ろす・手を振る・腰に手・手を重ねる・舵輪を握る）、色調、縁の光を加える |
| `books.py` | 職業の書の5冊（農民・料理人・船乗り・鍛冶屋・僧侶）の表紙の色・紋章・道具の絵（M2・M9で使う） |
| `build-movie.mjs` | 各ムービーの `build.mjs` から呼ぶ生成処理（人物の部品の書き出し → Pythonの組み立て） |

## 新しいムービーの作り方

1. `story-movies/<フォルダ名>/` に `cast.mjs`（登場人物と向き）、`build.mjs`（`buildMovie()` を呼ぶ）、`src/build.py`（ストーリーデータとパネルの文言、`engine.page()`）、`src/scenes.py`（場面のSVG）を置く。[`../ch3-departure/`](../ch3-departure/README.md) が見本。
2. `npm.cmd run build:movie -- <フォルダ名>` で `index.html` を生成する。
3. [`../catalog.mjs`](../catalog.mjs) の状態を `prototype` にし、一覧に出す静止画（場面・ミリ秒）と、制作メモ・絵コンテへのリンクを書く。
4. `npm.cmd test` と `npm.cmd run test:movie -- <フォルダ名>`（ブラウザーでの再生確認）。

## 約束ごと

- 人物の頭・胴は作画コードのまま使い、ムービー側で描き直さない。作画を変えたら、各ムービーを生成し直す（テストが食い違いを見つける）。
- 場面のSVGは場面ごとに自己完結させ、id・クラス・アニメーション名に場面の接頭辞（`s1-` など）を付ける。絵の中のCSSアニメーションは `.is-active` の下でだけ動かす。位置が動くものには `.mv` を付け、モーション軽減時に止める。
- 生成物（`index.html`・`parts/`）は手で直さない。改行はLF。乱数は固定シード。
- プロローグ（`../prologue/`）は、シオンを設定画の座標（443.5px）で描く独自の `src/shion.py` を使う（2本目以降は `figures.py`）。
- ほかのムービーの場面を絵の中に入れるときは、その場面の関数を呼んでそのまま縮める（例：M5の思い出の額。`../ch4-arrival/src/props5.py` の `recall()`）。元の接頭辞は入れる場面の接頭辞の下に置き換え、元のムービーを変えたら入れた側も生成し直す。
