# 絵コンテ：収穫祭の夜 ― 第2章の結び

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.9秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.1秒でフェード、最後は0.9秒で暗転します。全体で約20秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 守った田（0～3.0秒）

- カメラ: 倍率1.06（下寄り）→ 1.0。
- 絵: 星と月の夜空、奥の山並みと村の小屋（窓の灯り）。水を張った田に月の光の道。畦に黒い泥の跡がいくつも残る。手前と奥に実った稲。
- 動き: 稲の揺れ（動き）、水面のきらめき、星のまたたき。
- 字幕: 0.3秒「田がよみがえり、食が戻った。」（2.8秒まで）

## ② 収穫祭（0～5.0秒）

- カメラ: 倍率1.04（右寄り）→ 1.0（左へ）。
- 絵: 夜空、宴の暖かい光。奥に食堂（白い壁・のれん）と左右の小屋、右にかまどの火と煙。上に赤と白の提灯の列。長い膳（ごはん・汁・焼き魚・おにぎり）を囲む、左からジンベエ・ゴンタ（杯を上げるように手を上げる）・シオン・ミナ（手を振る）・ピノ（手を振る）。腰から下は膳に隠れる。右端から、手を前で重ねて料理の皿を持ったイナホが歩いてくる。
- 動き: 提灯の明滅、かまどの火のゆらぎと煙（動き）、手を振る、イナホが歩み寄る（動き）。
- 字幕: 0.4秒「今夜は 収穫祭だね！」（4.6秒まで）

## ③ 二冊の書（0～3.0秒）

- カメラ: 倍率1.0 → 1.05、わずかに上へ。
- 絵: 宴の灯りのぼけ（橙・黄）。中央下にシオンの背中（金髪、紺のベスト、背中のホルダーに深緑の職業の書）。書がほのかに光る。0.3秒に左に農民の書（土色・金の稲穂）、0.9秒に右に料理人の書（朱赤・金の鍋）が、光の中に浮かび上がる。
- 動き: 書の光の明滅、二冊が浮かび上がる（動き）、灯りのぼけの明滅。
- 字幕: 0.3秒「農民、料理人……二冊の書が よみがえった。」（2.8秒まで）

## ④ 荒れる沖（0～5.0秒）

- カメラ: 倍率1.18（左の村寄り）→ 1.04（右の沖へ）。宴の村から海へ目を移す。
- 絵: 暗い空、沖の上だけに黒い雲と雨。不ぞろいな高い波と白い波頭、もまれる小さな船の影（帆だけの影。人は描かない）。手前左の島は静かで、村の灯りと小屋。
- 動き: 雲が流れる（動き）、雨（動き）、波（動き）、船が大きく揺れる（動き）、村の灯りの明滅。2.4秒に稲光（空に稲妻、沖が白く光る。少し間をおいてもう一度）。その一瞬だけ、海の中に巨大な影（胴と、何本もの太い腕の輪郭）が見えて、すぐ消える。
- 字幕: 0.4秒「潮の匂いが変わったの。今夜は 荒れるやもしれん」（4.6秒まで）

## ⑤ 結び（0～3.6秒、タイトル）

- カメラ: 倍率1.04 → 1.0。
- 絵: 暗い空と星、暗い海。右の水平線の雲の中で、1.1秒ごろ遠い稲光がまたたく。
- 動き: 遠い稲光、星、波（動き）。
- 字幕: 0.3秒「職をつぐ旅は、まだ続く。」（1.9秒まで）
- タイトル: 2.1秒に「職をつぐ者　ジパング復興編」（小）・「第2章・完」（大）・「荒れた田の村」。手動で送るときはタイトルで一度止まる。
