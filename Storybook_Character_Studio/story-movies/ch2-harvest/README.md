# 収穫祭の夜 ― 第2章の結び（SVGストーリームービー試作・M9）

『職をつぐ者』第2章の章末に新しく足す、約20秒・全5場面のストーリームービーの試作です。今の第2章には章末の演出がありません。**2026-11-08にゲーム本編（第1～3章）へ組み込みました。** ゲームでの扱いは[下の節](#game)を参照。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch2-harvest/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [SVGストーリームービーの挿入計画](../../../docs/story/planned/story-movies.md) の M9（優先度B）。物語は [第2章の記録](../../../docs/story/implemented/chapter2.md)。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

プロローグ・M4と同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第5場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=4`・`?still=4&t=2450`（稲光の瞬間）・`?reduced=1`。

|---|---|---|---|
| ① 守った田 | 3.0秒 | 月夜の田。水面に月、実った稲が揺れる。畦に泥田の主たちとの戦いの泥の跡。奥に村の小屋の灯り | 田がよみがえり、食が戻った。 |

## 字幕の出どころ

田んぼ防衛戦の勝利会話（[`chapter2.js`](../../../dqb3-tsugumono-ch1-3/src/content/chapter2.js) の `paddyDefenseWin`）の台詞から、語の順を変えずに一部を抜き出しています（新しい台詞は作っていません）。

| 場面 | 台詞（話す人） |
|---|---|
| ① | 「……田がよみがえり、食が戻った。大したものじゃ」（ジンベエ） |
| ② | 「じゃあ、今夜は 収穫祭だね！ ごちそう、いーっぱい作るから！」（イナホ） |
| ③・④ | 「農民、料理人……二冊の書が よみがえった。次は 海 じゃ。……む、潮の匂いが変わったの。今夜は 荒れるやもしれん——職をつぐ旅は、まだ続くのじゃ！」（職業の書） |
| ⑤ | 上の最後の「職をつぐ旅は、まだ続くのじゃ！」を「職をつぐ旅は、まだ続く。」にしました。M1の結び（「職をつぐ旅は、ここから続いていく」）と続けて見たときに、同じに聞こえないようにするため |

タイトルの「荒れた田の村」は第2章の章名（[第2章の記録](../../../docs/story/implemented/chapter2.md)）。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch2-harvest
```

食堂・小屋は第3章の結末（`../ch3-departure/src/props.py`）の小道具、書の表紙は [`../shared/books.py`](../shared/books.py) を使います。それらを変えたら、このムービーも生成し直します。`index.html` と `parts/cast.json` は生成物です。

## 見せないもの・作画上の約束ごと

- ワタリの顔・名前と、浜に打ち上がる場面は描かない（発見の驚きは第3章の導入に残す）。船は影だけ。
- クラーケンの全身は描かない。稲光の一瞬だけ、海の中の影の輪郭（胴と腕の太い線）を見せる。
- 嵐の原因や魔物の正体など、新しい設定は字幕にも絵にも足さない。
- ゲームの島には嵐の表現がないので、嵐（雲・雨・稲光・高波）は沖だけ。手前の島と村の灯りは静かなまま。
- 第2章までに建てたものだけを描く（食堂・田・小屋・橋の先の村）。灯台・船（自分たちの）は第3章なので描かない。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s5-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める（稲の揺れ・雨・波・船の揺れ・イナホの歩みは止まり、稲光と影の明滅は残る）。

## ゲームでの扱い（2026-11-08に組み込み）

- Studioの `npm.cmd run sync:movies` で `dqb3-tsugumono-ch1-3/assets/movies/` の `ch2-harvest.html` へ写し、両編共通の `game-shared/story-movies.mjs` が全画面で再生する（[組み込みの仕組み](../../../docs/story/planned/story-movies.md#integration)）。このムービーを生成し直したら、写し直す（Studioのテストが写しと生成物の一致を確かめる）。
- 入る場所は、田んぼ防衛戦の勝利会話の後、`CH2_DONE` へ移る前（`quests2.js` の `playVictory()`）。
- 勝利会話の最後の書の台詞は、字幕③～⑤がその抜粋なので、ムービーを流すときは会話から外す。最後まで見なかったとき（スキップ・読み込めない）はムービーの後に流す。ジンベエ・イナホの台詞を抜いた字幕①②は重なったまま（[STORY-008](../../../docs/story/inconsistencies.md#story-008)）。
- スキップしても進行（`CH2_DONE` への移行と、翌日の第3章の開始）は変わらない。
