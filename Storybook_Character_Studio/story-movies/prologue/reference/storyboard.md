# プロローグの絵コンテ

[試作のREADME](../README.md) / [冒頭ショートムービーの計画](../../../../docs/story/planned/opening-movie.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `PROLOGUE_STORY`）。場面の切り替えは0.95秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.2秒でフェード、最後は0.9秒で暗転します。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 平和の終わり（4.8秒）

- ねらい: 勇者の勝利で明るくなった世界。その中央に、不穏な兆しが小さく見える。
- 絵: 闇の名残りの雲（上の左右）が割れ、切れ間から光の筋が大地へ差す。光を受けた山並み、田畑と川、二つの村（炊事の煙）、右の丘に城。左に崖と松、右の岩の上で剣を掲げる勇者の小さな影（剣先がきらめく）。
- 動き: 雲が左右へ開く（動き）、光の筋が現れる、霞と白い鳥が流れる（動き）、草が揺れる（動き）。1.4秒から地平の中央に紫の光・細い煙・地割れがにじみ、2.8秒から画面全体が少し陰る。
- カメラ: 全景（1.0）から地平の中央へ寄る（1.14、下へ6%）。
- 字幕: 0.5秒「勇者がゾーマを倒した。」 1.9秒「世界には、平和が訪れるはずだった。」（4.3秒まで）
- 次へのつながり: 紫の兆しの位置は、②の裂け目と同じ。

## ② 異変（5.0秒）

- ねらい: 平和が終わり、上の世界に再び魔物があふれる。
- 絵: 暗い紫の空、大地の裂け目から渦を巻いて立ち上る影の柱（中に光る目）、翼をもつ魔物の群れ、稲光、瘴気。以前の試作の絵を使う。
- 動き: 始めに地響きで少し揺れる（動き）、影の柱が噴き上がる（動き）、魔物が裂け目から空へ散る（動き）、稲光。
- カメラ: ①の寄りの位置（1.14）から引く（1.03）。
- 字幕: 0.6秒「しかし、平和は長く続かなかった。」 2.1秒「上の世界に、再び魔物があふれ出した。」（4.45秒まで）。原因（穴の名前など）は字幕にしない。

## ③ ダーマ神殿の崩壊（5.8秒）

- ねらい: 職を授ける神殿が襲われ、多くの書が焼かれる。すべてが失われたようには見せない。
- 絵: 山上の石造りの神殿が炎に包まれ、塔と大屋根・柱が崩れる。手前の瓦礫の上で一冊の書（赤い表紙）が燃え、ページが風に舞う。空に魔物の影、火の粉。
- カメラ: 1.1 → 1.17、左下から右上へ。
- 字幕: 0.6秒「職を授けるダーマ神殿も、襲われた。」 2.3秒「多くの職業の書が焼かれ、人々は職を受け継ぐ道を失った。」（5.25秒まで）

## ④ シオンの脱出（7.0秒）

- ねらい: 主人公の紹介。神官見習いの少年が、一冊の職業の書を背負って逃げ延びる。
- 前半（0～4.0秒）: 夜の山道。右奥の峰で神殿が燃え、煙が空を流れる。シオン（左斜め前）が息を切らして駆け下りる。金髪・青い瞳・紺のベスト・生成りの服、右肩の後ろに書のページの小口とホルダー。右から炎の橙、左上から月明かりの青の縁の光。背中の書が金色に光り、光の粒が後ろへ流れる。
- 後半（4.05秒から0.6秒で移る）: 走る背中の近い画（左斜め後ろ）。深緑の表紙と金の紋章の職業の書が、茶色の革のホルダーの中で光る。画面の右の外で燃える神殿の明かり、奥の暗い尾根。
- 動き: 体が上下に弾む（動き）、背景が奥ほど遅く流れる（動き）、蹴り上げた土ぼこり（動き）、火の粉・光の粒（動き）、書の光の明滅。
- カメラ: 1.0 → 1.14（左へ1.5%、下へ3%）。
- 字幕: 0.5秒「ただ一人、神殿から逃れた見習いがいた。」 2.0秒「少年の名は、シオン。」（4.0秒まで） 4.25秒「その背には、守り抜いた一冊の職業の書があった。」（6.5秒まで。前の2行と同じ場所に入れ替えて出す）

## ⑤ ジパングへの漂着（7.4秒）

- ねらい: 暗い世界から明るい世界へ。新しい旅の始まり。
- 絵: 夜明けの海。右に朝日とジパングの島（雪をいただく山・五重塔・鳥居の岩）、左に岬と松（①の松と呼応）。浜にシオンが立ち、右斜め後ろから見る。背中に深緑の表紙と金の紋章の職業の書。波打ち際から続く足あと、流木、左手前へ伸びる影。
- 動き: 夜の名残り（青紫）と星が4.8秒かけて消える、朝日が昇る（動き）、光の筋が回る（動き）、雲・かもめが流れる（動き）、波が寄せる（動き）、海のきらめき、シオンの朝日側の縁の光が現れる、背中の書の淡い光。
- カメラ: シオンに寄った位置（1.12）から全景（1.02）へ引く。
- 字幕: 0.6秒「そして、遠い島ジパングへ。」 2.1秒「ここから、失われた職を取り戻す旅が始まる。」（4.3秒まで）
- タイトル: 4.5秒から『職をつぐ者』（字間が締まりながら現れる）。手動で送ったときも、ここで一度止まる。
- 終わり: 0.9秒で暗転し、終了画面（もう一度見る）。本編では、ここから第1章の浜辺の導入へつなぐ。
