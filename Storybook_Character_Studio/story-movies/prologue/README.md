『職をつぐ者』の冒頭に挿入する、約31秒・全5場面のストーリームービーの試作です。**Studio内の試作で、ゲーム本編には組み込んでいません。** 採用と移植はユーザーが確認してから決めます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/prologue/ 。Studioのトップページの「プロローグ・SVGストーリームービー（試作）」からも開けます。
- 物語の基準: [冒頭ショートムービーの計画](../../../docs/story/planned/opening-movie.md)、[世界観と物語の始まり](../../../docs/story/overview.md)、[人物と職業の書](../../../docs/story/characters-and-jobs.md)、[第1章](../../../docs/story/implemented/chapter1.md)
- 主人公の正式デザイン: [hero2（試作03）](../../prototypes/hero2-8dir/README.md)、設定画 [`references/hero-redesign-8dir-v3.png`](../../references/hero-redesign-8dir-v3.png)
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

| 操作 | 内容 |
|---|---|
| 「プロローグを見る」 | 黒からフェードして再生を始め、5場面を自動で進める |
| クリック・タップ・Space・Enter | 次の場面へ。第5場面では、1回目でタイトルまで進み（タイトルは飛ばさない）、次で終了 |
| 「スキップ」・Esc | すぐに終了画面へ |
| 「もう一度見る」 | 最初から再生 |

確認用のURLパラメータ: `?autoplay=1`（ボタンなしで再生）、`?from=4`（第4場面から再生）、`?still=4&t=6000`（第4場面の6.0秒の状態で止める）、`?reduced=1`（モーション軽減を強制）。

スマートフォンの縦画面では絵（16:9）の下に字幕を出します。横画面・PCでは絵の下部に字幕を重ね、下を暗くして読みやすくします。スキップボタンはタッチ端末で 46px 以上の高さにしています。OSの「視差効果を減らす」（モーション軽減）では、カメラと位置の動きを止め、フェード・字幕・光の明滅・夜明けの変化は残します。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:prologue
```

1. `src/shion_parts.mjs` が、正式デザインのシオンの作画コード（[`prototypes/hero2-8dir/character.mjs`](../../prototypes/hero2-8dir/character.mjs)）から、8方向の頭・胴のSVGを `parts/shion-parts.json` へ書き出します。
2. `src/build.py` が、5場面のSVG・字幕・再生処理を組み立てて `index.html`（自己完結、外部ファイルなし）を書き出します。乱数は固定シードなので、何度実行しても同じ内容になります。

`index.html` と `parts/shion-parts.json` は生成物です。手で直さず、`src/` を直して生成し直します。主人公の作画（hero2）を変えたときも、生成し直すとムービーのシオンに反映されます（`npm.cmd test` は、ムービーの部品が作画コードと食い違うと失敗します）。

## シオンの描き方

正式デザインのシオンと同じ人物に見えることを最優先にし、髪・顔・服・職業の書の形はゲームの8方向シートと同じ作画コードから取り出します。ゲームのスプライト画像を拡大しているのではなく、ゲーム用に縮小する前のSVG（設定画のセル座標、443.5px四方）をそのまま大きく描いています。

- **頭・胴（正式デザインのまま）**: ふわふわの金髪・大きな毛束・アホ毛、大きな青い瞳と丸い顔、生成りの服・紺のベスト、肩紐・茶色のベルトと小物入れ、背中の茶色の革のホルダーと深緑の職業の書（金の「開いた本」の紋章、生成りの厚いページ）。
- **手足（ムービーで追加）**: ゲームでは3Dリグが描く部分です。3Dリグと同じ色（紺の袖 `#293d75`・素手・焦げ茶のズボン `#3b2a22`・茶色のブーツ `#8a5428`）の太い線で、肘・膝を曲げた姿勢を描きます。輪郭の太さは頭・胴と同じです。
- **姿勢**: 第4場面の前半は左斜め前を向いて走る（`run_left`）、後半は左斜め後ろ姿で走る（`run_away`、背中の書の表紙を見せる）、第5場面は右斜め後ろ姿で立つ（`stand_dawn`）。
- **表情**: 第4場面の前半だけ、原本の笑顔の口を、口角の下がった小さな開いた口（息を切らして逃げる）に差し替え、耳の上のこめかみ（髪の上）に汗を一粒足します（頬の端では顔の輪郭に紛れて見えにくかったため、2026-11-08に移動）。眉は前髪に隠れるので変えません。原本の口の線が見つからないと生成が止まります。
- **走る腕**: 第4場面の前半の手前の左腕は、肘を後ろへ大きく引き、握りこぶしを腰の横に置きます（2026-11-08。手首を外へ跳ね上げる形は女の子走りに見えたため）。
- **夜と夜明け**: 第4場面は人物の全色を夜の紺へ30%寄せ（金髪・紺・深緑が分かる程度に留める）、右奥の炎の橙と月明かりの青の縁の光を付けます。背中の書は金色の光を放ち、光の粒が後ろへ流れます。第5場面は朝日の色へ7%寄せ、朝日側の縁の光を夜明けとともに出します。
- **縁の光**: 人物の形を一色で塗った写しを少しずらして後ろに敷きます（フィルター・マスクを使わず、再生負荷を抑えるため）。
- **使わないもの**: 以前の試作のフード・長いマント・肩の白いケープ・ゴーグル・帽子・赤いリボンやスカーフ・胸に本を抱える姿は使いません（テストでも確認）。

## 作画上の約束ごと

- すべての場面が `viewBox="0 0 1600 900"`（16:9）。
- id・class は場面番号の接頭辞（`s1-`～`s5-`。シオンの部品は `s4-sh-`・`s4-sb-`・`s5-sh-`）を付ける。クロスフェード中は2つの場面が同時にあるため。
- 絵の中のCSSアニメーションは、プレイヤーが場面に付ける `.is-active` の下でだけ動く。
- 位置が動くアニメーションには `class="mv"` を付ける。モーション軽減時はこれが止まるので、止まった状態でも絵が成り立つように描く。舞い散る粒子は変数 `--p`（0～1）で飛行途中の位置を止まった状態として持つ。
- 各場面のSVGは `<style>` と `<defs>` を内部に持ち、他の場面に依存しない。

## 第1章へつなぐときの注意

ムービーは、第1章の浜辺の導入の直前（漂着して朝を迎えたところ）までを描きます。本が初めて話す驚き、ビルダーの技の説明、木材集めは第1章の導入で見せます。ムービーの中で別の本を拾う場面は加えていません。シオンが神殿から持ち出し、背中に背負っている一冊が、第1章で話しかける職業の書です。

現在の第1章の導入（[`quests.js`](../../../dqb3-tsugumono-ch1-3/src/game/quests.js) の `startIntro()`）は、ムービーと次の説明が重なります。移植するときに調整します（今回はゲームの会話を変えていません）。

| 導入の台詞 | ムービー | 移植時の扱いの案 |
|---|---|---|
| 「勇者がゾーマを倒した。世界には平和が訪れるはずだった。」 | 第1場面の字幕と同じ | ムービーを見た後は省く |
| 「しかし、上の世界には再び魔物があふれ、混乱が広がった。」 | 第2場面 | 同上 |
| 「職業を司るダーマ神殿も襲われ、多くの職業の書が焼かれ、散り散りになった。」 | 第3場面 | 同上 |
| 「……波の音が聞こえる。」以降（シオンの回想・唯一の生存者・書が話す） | 描かない（第4場面は脱出の事実だけ） | 残す。回想の「職業の書を抱えて」は、ムービーでは背負っているため「職業の書を持って」などへの調整を検討 |

ムービーをスキップした人、または見なかった人には、今の導入の3行がそのまま必要です。移植時は「ムービーを最後まで見たか」で冒頭3行を出し分ける案と、常に省いて初回だけムービーを強制する案があります。

## 将来ゲームへ移植する場合の構成案

- `StoryPlayer` クラス → 両編で共用できるので `game-shared/`（例: `game-shared/story-player.js`）。
- `PROLOGUE_STORY`（字幕・時間・カメラ）→ 第1～3章の `src/content/prologue.js` など。
- 各場面のSVG → `.svg` ファイルとして書き出し、`import scene1 from './scene1.svg?raw'` のように文字列で読み込んで `markup` に渡す（`StoryPlayer` は `<template>` の id と SVG文字列の両方を受け付ける）。生成はこのStudioで行い、書き出し先を `game-targets.mjs` と同じ考え方で管理する。
- 再生の場所: タイトル画面の「はじめから」の後、`INTRO` の導入会話の前。`storyend` イベント（または `onComplete`）で `startIntro()` を呼ぶ。スキップでも同じ。
- セーブとの関係: 既存セーブの読み込みでは再生しない。「もう一度見る」はタイトル画面のメニューから。
- 大きさ: 現在の `index.html` は約0.53MB（第4場面が約0.2MB）。ゲームに入れる場合は、使う方向だけの部品にする、縁の光の写しを省く、などで減らせる。

## 残っている課題

- 音声（音楽・効果音）は未制作。
- 描画の負荷: ヘッドレスのソフトウェア描画で 19～34fps（第5場面が最も重く、次いで第3・第4場面）。実機のGPU描画、iPhoneのSafari、低性能端末では未確認。重い場合は第5場面の海のきらめきの数、第4場面の縁の光の写しを減らす。
- 手足はムービー用の線で描いた単純な形で、走る姿勢は1枚（上下に弾むだけ）。脚を交互に動かす走りの動きは付けていない。
- 第4場面の前半は正式デザインの左斜め前の向きなので、背中の書はページの小口と緑の縁だけが見える。表紙と紋章は後半の近い画で見せる。
- 勇者の影は小さな影絵で、特定の人物に見えないようにしている。勇者の姿を詳しく描く場合は別途デザインが必要。
