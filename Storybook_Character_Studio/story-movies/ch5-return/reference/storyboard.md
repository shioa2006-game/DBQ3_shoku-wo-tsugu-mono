# 絵コンテ：帰るべき場所へ ― 火山島編・完

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.95秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.2秒でフェード、最後は0.9秒で暗転します。全体で約33秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 清めの泉（0～7.2秒）

- カメラ: 倍率1.08（右寄り・上）→ 1.0（全景）。
- 絵: 朝の空。左右に竹林、竹の間から光の筋。中央に赤い鳥居と、そのくぐり口から見える小さな社。手前に石で囲んだ泉。右へ、水門から板の導水路が鉱山町へ下る。町の家々と、煙突に火の戻った鍛冶場。奥に静かな火山（細い煙）。
- 動き: 泉の濁りが2.6秒かけて晴れる、波紋の輪（動き）、きらめき、導水路を流れる水（動き）、竹の葉の揺れ（動き）、光の筋、鍛冶場の火と煙（動き）、火山の煙（動き）。
- 字幕: 0.5秒「火を取り戻した者たちは、鉄を暮らしの形に変えた。」、2.0秒「祈りを取り戻した者たちは、病める者のそばに立った。」（6.8秒まで）

## ② 町の人々（0～9.6秒）

- カメラ: 倍率1.0 → 1.06、わずかに上へ。
- 絵: 晴れた空と奥の火山。町の家々、鍛冶場（煙突の火）、右の竹の丘から下る導水路。広場の前の列に鍛冶屋のベルク（腰に手）・僧侶のナギ（手を重ねる）・薬草のヨモギ。後ろの列にロク（両手を腰）・カヤ（手を振る）・スミ（手を重ねる）・テル（手を振る）。
- 動き: 名前の字幕に合わせて足元の光の輪が灯る（0.9秒ベルク・1.7秒ナギ・2.5秒ヨモギ、5.0秒ロク・5.7秒カヤ・6.4秒スミとテル）。手を振る、雲・煙（動き）、導水路の水（動き）。
- 字幕（1組目）: 0.5秒「鍛冶屋のベルク、僧侶のナギ、薬草のヨモギ。」（4.4秒まで）
- 字幕（2組目）: 4.7秒「ロクとカヤと島の人々は、火と水のつながった町を守っていく。」（9.2秒まで）

## ③ 船出（0～7.0秒）

- カメラ: 倍率1.06（左寄り）→ 1.0（右へ）。
- 絵: 夕日の空と海（右に沈む太陽、光の道）。左奥に火山島。右にM4と同じ船：船尾楼で舵輪を握るワタリ、手を振るミナ・シオン・ゴンタ（腰から下は舷側に隠れる）。左手前の直した桟橋に、手を振って見送るベルク・ナギ・カヤの後ろ姿。
- 動き: 船が右へ出ていく・揺れる（動き）、全員の手、吹き流し、波（動き）、きらめき、火山の煙（動き）。
- 字幕: 0.5秒「そして 職をつぐ者は、船に乗る。」、1.8秒「農民ミナ、守り手ゴンタ、船乗りワタリと共に――」（6.6秒まで）

## ④ 始まりの場所へ（0～8.2秒、タイトル）

- カメラ: 倍率1.0 → 1.08（右の神殿の方へ）。
- 絵: 月と星の夜空、暗い海と月の光の道。中央の小さな船（帆を夜の色に沈め、船尾の灯り）。行く手の水平線に、左で海に接し右の奥へ山が続く島。その山の肩に、屋根を失い二本の柱だけが立つダーマ神殿跡の影（プロローグ第3場面の神殿と同じ基壇と柱の並び。M10と同じ形）。火は消え、月明かりの縁だけ。水平線の霞。
- 動き: 神殿の影が4秒かけて浮かび上がる、船が右へ進む・揺れる（動き）、星のまたたき、灯り、霞（動き）、波（動き）。
- 字幕: 0.5秒「すべてが失われた、始まりの場所へ。」（3.9秒まで）
- タイトル: 4.1秒に「職をつぐ者」（小）と「火山島編・完」（大、ゲームのタイトルと同じ黄色・極太・茶色の影）。手動で送るときはタイトルで一度止まる。
