## 再生と操作

プロローグ・M4・M5と同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第4場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=3`・`?still=2&t=7000`・`?reduced=1`。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch5-return
```

1. [`../shared/cast.mjs`](../shared/cast.mjs) が、登場人物（`cast.mjs` の一覧：四人と町の7人）の頭・胴のSVGを `parts/cast.json` へ書き出します。第4～5章の住民の手足の色は、第4～5章の `villagers.js` と同じです。
2. `src/build.py` が、4場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

船は第3章の結末（`../ch3-departure/src/props.py`）、火山島は火山島編の始まり（`../ch4-arrival/src/props5.py`）の小道具をそのまま使います。それらを変えたら、このムービーも生成し直します（`npm.cmd test` は食い違いを見つけます）。

`index.html` と `parts/cast.json` は生成物です。手で直さず、`src/` を直して生成し直します。

## 作画上の約束ごと

- 人物の頭・胴は正式デザインの作画コードのまま（2026-11-08に腰まで描くよう直したもの）。ムービーで描くのは手足（色はゲームの3Dリグと同じ）と姿勢だけ。
- 神殿跡の影は、プロローグ第3場面の神殿（`../prologue/src/scenes_b.py` の `scene3()`）と同じ三段の基壇と柱の並びで、屋根を失い中央の左右の二本だけが柱頭まで立つ姿（共通部品 [`../shared/temple.py`](../shared/temple.py) の `remains_silhouette()`）。第6～7章のM10（`../ch6-arrival/`）の神殿跡と同じ形で、一色の影に月明かりの縁だけを付ける。島は、M10と同じく左で海に接し、右の奥へ山が続く並び。2026-11-14までは、屋根の一部と崩れた塔の残るプロローグの神殿そのままの影だった（一晩で屋根が消えたように見えるため直した）。
- 第6～7章は未実装なので、神殿は影だけ。ヴァルガや魔物、再建後の神殿は描かず、「戻る」ところで止める。
- 船はM4・M5と同じ。M4の船出（晴れた朝）と対になるよう、夕日の海に出て夜の海で終わる。
- 字幕は結末文と同じなので、ゲームでムービーを流すときは文字の結末を重ねて出さない。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s4-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。
