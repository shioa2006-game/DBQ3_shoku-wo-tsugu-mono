# 灯は消えず ― 最終決戦の決着（SVGストーリームービー試作・M13）

『職をつぐ者』ダーマ再興編の第7章で、最終決戦で三頭魔竜ヴァルガの三つ目の頭を倒した直後、戦後の修復の前に流す、約18秒・全3場面のストーリームービーの試作です。三つの頭を倒した決着を見せ、祭壇の灯が守られたことを伝えます。**第6～7章のゲームはまだないので、Studio内の試作です。** ゲームを作るときに組み込みます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch7-flame-holds/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [第6～7章のムービー計画](../../../docs/story/planned/chapter6-7-movies.md) の M13（優先度B）。物語は [第7章](../../../docs/story/planned/chapter7.md)（「最終決戦」）。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

ほかのムービーと同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第3場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=2`・`?still=2&t=4200`・`?reduced=1`。

## 字幕とタイトル

第6～7章はゲームより先にムービーを作るので、字幕は[計画](../../../docs/story/planned/chapter6-7-movies.md)の方針（ヴァルガの最後の短い言葉と、職業の書かシオンの言葉）に沿って新しく書きました。

- ①「おのれ……職をつぐ者ども……。」: ヴァルガの最後の言葉。M12の「職をつぐ灯など、二度と ともさせぬ。」を受け、恐れていた「職をつぐ者」に敗れたことを、短い呪いの言葉で示す。名前は言わない（M12で名乗った）。
- ②「灯は、消えておらぬ。」: 職業の書。M11の「要石の祭壇に、授職の灯がともった。」と、M12の「二度と ともさせぬ」を受ける。
- ③「皆の仕事が、この灯を守ったのじゃ。」: 職業の書。選択の柱に刻んだ皆の仕事の印、ピノとベルクの射台、集まる仲間と住民を受ける。
- タイトルは「最終決戦の決着」（小）と「灯は消えず」（大）。

シオンの言葉は、ゲームの会話（勝利の直後と、修復・継承の場面）に任せ、ムービーでは職業の書の言葉にしました。

## 決めたこと（制作時）

- **ヴァルガの崩れ方**: 第5章のグロム（「二つ目の頭が砕けると、巨体は黒い霧へ崩れ」）と呼応させ、黒い霧へ崩れる。グロムが残した爪痕の印の黒鱗は残さない（印の主であるヴァルガ自身が倒れたため）。
- **選択の柱の場面**: 選択の柱は本堂の中の祭壇の右に立つ（M11）ので、計画で③に挙げていた選択の柱は、②の終わりに屋根の穴から差す朝の光で照らす。③は外の射台と神殿、集まる人々にした。
- **選択の柱の印**: M11と同じ四つの枠に、下からアサギの大工の印（M11）・建築（積んだ石と金槌）・食料（湯気の立つ椀）・防衛（盾）。物語の「建築・食料・運搬・防衛など」から、正面の四つの枠に収まるものを選んだ。印の種類と数・刻む面はゲームの設計で決めてよい。
- **大型対空ボウガンの射台**: ピノの木組みの高い台（四本の柱・筋交い・はしご・手すり）に、ベルクの金属機構のボウガン（鉄の弓・巻き上げ車・帯金・回転台）を据え、空へ斜めに構える。形・位置・大きさはゲームの設計で決めてよい（島の地形と同じく、決まった後にムービーを合わせ直す）。

## ヴァルガと人物の絵

ヴァルガの頭・胴は、M12と同じくStudioの作画コード（[`../../prototypes/varuga-8dir/character.mjs`](../../prototypes/varuga-8dir/character.mjs)）の8方向シートから、正面と左右の斜め前のセルを [`../shared/varga.mjs`](../shared/varga.mjs) が `parts/varga.json` へ書き出したものをそのまま使います。読み込みはM12の [`../ch7-three-heads/src/props12.py`](../ch7-three-heads/src/props12.py) の `Varga`、地上へ落ちた姿の組み立ては [`src/props13.py`](src/props13.py) の `fallen_varga` です。

- 翼は地面へ垂れて裂け、穴があく。左の翼に大型対空ボウガンの矢。首・翼の膜・翼の骨の色はM12と同じ `rig-profile.mjs` の値。
- 倒れた左右の頭と首は色を暗く沈め、黒い霧の筋が立ちのぼる。三つ目の頭は通常の頭（口を閉じた頭）で、火炎はもう吐かない。
- 三つ目の頭は、首を縮めながら手前へ倒れる（モーション軽減時は止める）。倒れた後、巨体は黒い霧に覆われて消える（不透明度の変化なので、モーション軽減時も消える）。

人物（シオン＝hero2・ミナ・ゴンタ・ワタリ・ピノ・ベルク・スズハ・アサギ・ガンゾウ）は、[`../shared/cast.mjs`](../shared/cast.mjs) がStudioの作画コードから書き出した頭・胴（正面）に、[`../shared/figures.py`](../shared/figures.py) が手足を描き足したものです。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch7-flame-holds
```

1. `build.mjs` が、ヴァルガの頭・開口頭・胴（`cast.mjs` の `VARGA` の方向）を `parts/varga.json` へ、九人の頭・胴（`cast.mjs` の `CAST`）を `parts/cast.json` へ書き出します。
2. `src/build.py` が、3場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

再建した神殿は共通部品 [`../shared/temple.py`](../shared/temple.py)、祭壇・炎・選択の柱・共同台所はM11の [`../ch6-roof-light/src/props11.py`](../ch6-roof-light/src/props11.py)、場面の枠は第3章の結末（`../ch3-departure/src/scenes.py`）のものを使います。これらや、ヴァルガ・九人の作画（Studio）を直したら、このムービーも生成し直します。`index.html` と `parts/` は生成物です。ヴァルガの頭・胴は細かい作画なので、`index.html` は約0.8MBあります。

## 見せないもの・作画上の約束ごと

- 戦後の修復と、スズハ・アサギへの継承は描かない（ゲームで描き、M14へつなぐ）。
- 戦いの傷は直さずに残す（ムービーの後も修理の段階へ引き継ぐ）。傷の位置と壊れ方の細部はゲームで決めてよい。
- ガーゴイルは描かない。爪痕の印の黒鱗も描かない。ゾーマや大穴との関係は語らない。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s3-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。

## 確認する

```powershell
npm.cmd test
npm.cmd run test:movie -- ch7-flame-holds
```

`npm.cmd test` は、ヴァルガと九人の部品がStudioの作画コードと一致すること、字幕が計画資料に記録されていること、タイトル、三つの頭が口を閉じた頭であること、黒い霧、選択の柱の四つの印、傷の残る神殿と射台と九人、修復・継承の言葉を字幕に入れないこと、id の接頭辞、Pythonでの再生成が同じ内容になることを確かめます。

## 残っている課題

- ヴァルガの配色はStudioの試作色。確定したら生成し直す。
- 射台の形・位置、神殿の傷、選択の柱の印は、ゲームの設計が決まったら合わせ直す。
- 音楽・効果音（崩れ落ちる音・朝の鳥の声）はない。実機（スマートフォン）での滑らかさは未確認。
