# 絵コンテ：小さな社 ― 第1章の結び

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.9秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.1秒でフェード、最後は0.9秒で暗転します。全体で約15秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 祭壇の二冊（0～5.2秒）

- カメラ: 倍率1.0 → 1.08（二冊へ寄る、わずかに上）。
- 絵: 夜空と星。社の正面：板の奥壁、左右の白木の柱、梁、反った屋根の軒、しめ縄と紙垂。水色の布をかけた祭壇の上に、深緑の職業の書（金の開いた本の紋章）と、土色の農民の書（金の稲穂の紋章）が少し傾いて並ぶ。二冊の後ろに淡い光。床板と、左右手前の石灯籠。
- 動き: 二冊の後ろの光が0.4秒から灯る、祭壇の光の明滅、石灯籠の火のゆらぎ、光の粒が立ちのぼる（動き）、星のまたたき。
- 字幕: 0.4秒「その書に導かれ、流れ着いたジパングで槌を取った。」、1.8秒「家を建て、田を耕し、柵をめぐらせ、祈りの場を作った。」（4.8秒まで）

## ② 社を見上げる人々（0～4.2秒）

- カメラ: 倍率1.04（下寄り）→ 1.0。
- 絵: 星と月の夜。中央の北の山、頂上で水色に灯る社（赤い鳥居）、灯りの点る、つづら折りの参道。手前の左にジンベエ・ゴンタ、右にミナ・ピノの後ろ姿（腰から下は画面の下）。
- 動き: 社の光、参道の灯り、星のまたたき、雲（動き）。
- 字幕: 0.3秒「人々が働き始めた時、白紙の職業の書に文字が戻った。」（3.9秒まで）

## ③ 朝の村（0～5.6秒、タイトル）

- カメラ: 倍率1.08（右下寄り）→ 1.0（全景）。
- 絵: 朝の空と朝日。左の北の山と頂上の社、参道、松。ふもとに三軒の小屋、赤い旗、田（実った稲）と畑、かかし、柵。右下に浜と海、かもめ。
- 動き: 最初は朝の光で白く、4.5秒かけて晴れる。雲（動き）、旗、海のきらめき、波（動き）、かもめ（動き）。
- 字幕: 0.4秒「職をつぐ旅は、ここから続いていく」（2.6秒まで）
- タイトル: 2.8秒に「職をつぐ者　ジパング復興編」（小）・「第1章・完」（大、ゲームのタイトルと同じ黄色・極太・茶色の影）・「漂着の浜」。手動で送るときはタイトルで一度止まる。
