# 小さな社 ― 第1章の結び（SVGストーリームービー試作・M1）

『職をつぐ者』第1章の章末に入れる、約15秒・全3場面のストーリームービーの試作です。**2026-11-08にゲーム本編（第1～3章）へ組み込みました。** ゲームでの扱いは[下の節](#game)を参照。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch1-shrine/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [SVGストーリームービーの挿入計画](../../../docs/story/planned/story-movies.md) の M1（優先度B）。物語は [第1章の記録](../../../docs/story/implemented/chapter1.md)。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

プロローグ・M4と同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第3場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=2`・`?still=1&t=3500`・`?reduced=1`。

## 字幕の出どころ

今の第1章の章末の文（[`ui.js`](../../../dqb3-tsugumono-ch1-3/src/ui/ui.js) の `playEnding()` の既定の文）のうち、第1章の出来事の行だけを、順番どおりそのまま使っています。

- 使わない行: 勇者・魔物・ダーマ神殿の崩壊・シオンの脱出を語る前半と、「これは、勇者のいない上の世界で…」の2行。プロローグ（M0）と重なるため（計画の注意どおり）。
- 最後の「― 職をつぐ旅は、ここから続いていく ―」は、前後の線を外して字幕にしました。
- タイトルの「漂着の浜」は第1章の章名（[第1章の記録](../../../docs/story/implemented/chapter1.md)）。ゲームの章末に出ている「職をつぐ者 〜ジパング復興編〜」は、上の小さな行にしました。
- 祭壇での会話（「職業は、神殿が一方的に授けるものじゃない…」「職をつぐ者 じゃ！」など）は、ムービーの前の会話にそのまま残すので、字幕にしていません。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch1-shrine
```

1. [`../shared/cast.mjs`](../shared/cast.mjs) が、登場人物（`cast.mjs` の一覧：4人の背面）の頭・胴のSVGを `parts/cast.json` へ書き出します。
2. `src/build.py` が、3場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。

社・小屋・田・畑・旗・かかし・木は第3章の結末（`../ch3-departure/src/props.py`）の小道具、書の表紙は [`../shared/books.py`](../shared/books.py)（職業の書と、M2で決めた農民の書の意匠）を使います。それらを変えたら、このムービーも生成し直します。

`index.html` と `parts/cast.json` は生成物です。手で直さず、`src/` を直して生成し直します。

## 作画上の約束ごと

- 第1章で建てたものだけを描く（小屋・畑・田・柵・旗・社）。食堂・灯台・船は第2章以降なので描かない。
- 祭壇は、ゲームの社の祭壇と同じ水色。書の表紙は、職業の書（深緑・金の開いた本）と農民の書（土色・金の稲穂）。
- 人物の頭・胴は正式デザインの作画コードのまま。ムービーで描くのは手足と姿勢だけ。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s3-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。
