# 絵コンテ：書の復活（共通の型）

[試作のREADME](../README.md)

1場面・7.0秒。最初は黒から0.7秒でフェード、最後は0.9秒で暗転します。カメラは倍率1.04（わずかに下）から1.0へゆっくり引きます。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。5冊とも同じ流れで、表紙の色・紋章・道具・光の色・字幕の2行目・タイトルだけが変わります。

## 書の復活（0～7.0秒）

- 0.0秒: 暗い背景（中央がわずかに明るい）、星のようなきらめき。中央下に閉じた書が浮かぶ（表紙の色、金の縁取り、紋章）。浮き沈み（動き）。
- 0.9秒: 表紙が背を軸に閉じていくように細くなり（0.45秒）、続いて左に表紙の裏と左のページが開く（0.45秒）。本は右寄りから中央へ寄る（動き）。
- 1.7秒: 左右のページに、光の文字（金の筆の線）が上の行から一行ずつ戻る（約1.5秒）。右のページの中央は空けておく。
- 2.6秒: 右のページの中央に、金の紋章が光って現れ、明滅する。
- 3.0秒: 本から上へ光の柱が立つ。その中に道具が下から浮かび上がる（1.1秒、動き）。後ろで光の筋が現れ、ゆっくり回る（動き）。光の粒が立ちのぼる（動き）。
- 3.7秒: 白い閃光（0.9秒）。
- 4.0秒: タイトル（書の名前。ゲームのタイトルと同じ黄色・極太・茶色の影）。手動で送るときはここで一度止まる。
- 4.2秒～: 道具がゆっくり浮き沈みする（動き）。
- 字幕: 0.4秒「白紙のページに 光の文字が もどっていく……」（3.6秒まで）、4.3秒 その書の復活後の説明（6.7秒まで）。
