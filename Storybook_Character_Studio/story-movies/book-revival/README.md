## 5冊の書の意匠

計画で「先にStudioで決める」としていた5冊の見た目です。2026-11-08にこの試作で案を作り、ユーザーが承認しました。シオンの「職業の書」（深緑の表紙に金の開いた本の紋章）と見分けがつくよう、表紙をそれぞれの職の色にし、紋章をその職の道具や印にしました。定義は [`../shared/books.py`](../shared/books.py)（M9でも使う）。

| 書 | 表紙 | 紋章 | 浮かぶ道具 | 光 |
|---|---|---|---|---|
| 農民の書 | 土色（茶） | 金の稲穂 | 鍬 | 金 |
| 料理人の書 | 朱赤 | 金の、湯気の立つ鍋 | 鉄鍋とふた | 金 |
| 船乗りの書 | 紺 | 金の舵輪 | 舵輪 | 金 |
| 鍛冶屋の書 | 鉄色（灰） | 銅色の金床と槌 | 槌 | 銅 |
| 僧侶の書 | 生成り（白） | 朱の、しずくと葉 | 薬草の束（朱のひも） | 白 |

## 型の流れ（1場面・7.0秒）

| 時刻 | 絵 | 字幕・タイトル |
|---|---|---|
| 0.0秒 | 暗がりに、閉じた書が浮かぶ（表紙の色と紋章、後ろに淡い光） | 0.4秒「白紙のページに 光の文字が もどっていく……」 |
| 0.9秒 | 表紙が背を軸に開き、本が中央に寄る | |
| 1.7秒 | 白紙のページに、光の文字（筆の線）が一行ずつ戻る | |
| 2.6秒 | 右のページの中央に、紋章が光って現れる | |
| 3.0秒 | 本から光の柱が立ち、その職の道具が浮かび上がる。光の筋が回る | |
| 3.7秒 | 光がはじける（白い閃光） | 4.0秒 タイトル（書の名前）。手動で送るときはここで止まる |
| 4.3秒 | 道具がゆっくり浮かぶ | その書の復活後の説明（下の表） |

字幕は、すでにある文だけを使っています。1行目はゲームの今の復活の小窓の文（[`ui.js`](../../../dqb3-tsugumono-ch1-3/src/ui/ui.js) の `showBookRevival`）、2行目はその書の復活後の説明（`jobs.js` の `revivedDesc`）、タイトルは書の名前（`jobs.js` の `name`）です。農民・料理人・船乗りの書は第1～3章、鍛冶屋・僧侶の書は第4～5章の `jobs.js` から取りました（その書が復活するゲームの文）。

## 生成する

Studioのルートで実行します。Python 3.9以上（標準ライブラリだけ）が必要です。人物は登場しないので、人物の部品の書き出しはありません。

```powershell
npm.cmd run build:movie -- book-revival
```

`src/build.py` が、型（`src/scene_book.py`）に5冊の意匠を差し替えて、`index.html`（農民の書）と `cook/`・`sailor/`・`blacksmith/`・`priest/` の `index.html` を書き出します。どれも生成物なので、手で直さず `src/` か `../shared/books.py` を直して生成し直します。

## 作画上の約束ごと

- 5冊とも同じ型。違うのは表紙の色・紋章・道具・光の色・字幕の2行目・タイトルだけ。
- 光の文字は読める字にせず、筆の線の並びで表す（どの書でも同じ見え方にするため）。
- 職業の書（シオンの話す書）とは、表紙の色と紋章で見分ける。
- モーション軽減では、本は最初から開いた位置、道具は浮かんだ位置で止まる（現れ方の不透明度・表紙が開く動き・光の文字・閃光は残す）。
- id・クラス・アニメーション名の接頭辞は `s1-`。

## 確認する

```powershell
npm.cmd test
npm.cmd run test:movie -- book-revival
```

`npm.cmd test` は、5冊分のページがそろっていること、字幕とタイトルがゲームの文（復活の小窓の文、各書の `revivedDesc` と `name`）と一致すること、id の接頭辞、Pythonでの再生成が同じ内容になることを確かめます。`test:movie` はフォルダの `index.html`（農民の書）を実際に再生します（静止画、自動再生の完走と所要時間、クリックでの送りとタイトルの停止点、スキップ・Esc・再再生、モーション軽減、スマートフォンの縦・横、ページのエラー）。ほかの4冊は同じ型なので、ブラウザーでは確かめていません。

## ゲームでの扱い（2026-11-08に組み込み）

- Studioの `npm.cmd run sync:movies` で、5ページを `book-<書のID>.html` として各編の `assets/movies/` へ写し（`dqb3-tsugumono-ch1-3` は農民・料理人・船乗り、`dqb3-tsugumono-ch4-5` は鍛冶屋・僧侶）、両編共通の `game-shared/story-movies.mjs` が全画面で再生する（[組み込みの仕組み](../../../docs/story/planned/story-movies.md#integration)）。このムービーを生成し直したら、写し直す（Studioのテストが写しと生成物の一致を確かめる）。
- 入る場所は、`game-shared/job-books.mjs` の `JobBooks.revive()`。書のIDで `book-<ID>` を選んで流し、ムービーを流せないときだけ今までの復活の小窓（`showBookRevival()`）を出す。効果音はムービーの始まりに鳴る。
- 書の意匠を、ゲームの職業の書の画面（書の一覧）にも使うかは未検討。
