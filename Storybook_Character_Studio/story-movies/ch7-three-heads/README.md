# 三つ首の影 ― 三頭魔竜の襲来（SVGストーリームービー試作・M12）

『職をつぐ者』ダーマ再興編の第7章で、先兵のガーゴイル軍を退けた後、三頭魔竜ヴァルガが自ら海を越えて初めて姿を見せ、名乗る場面の、約9秒・全3場面のストーリームービーの試作です。**第6～7章のゲームはまだないので、Studio内の試作です。** ゲームを作るときに組み込みます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch7-three-heads/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [第6～7章のムービー計画](../../../docs/story/planned/chapter6-7-movies.md) の M12（優先度B）。物語は [第7章](../../../docs/story/planned/chapter7.md)（「ヴァルガと敵の動機」）。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

ほかのムービーと同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第3場面の1回目は名前の表示まで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=2`・`?still=2&t=2200`・`?reduced=1`。

## 字幕と名前の表示

第6～7章はゲームより先にムービーを作るので、字幕は[計画](../../../docs/story/planned/chapter6-7-movies.md)の方針（ヴァルガの言葉は短く、記録から削られた名を自ら告げ、ダーマを焼いたと告げる。職を受け継ぐ人々への恐れと、職と技術が再び広まるのを許さない意思がにじむ言葉）に沿って新しく書きました。

- ②「職をつぐ灯など、二度と ともさせぬ。」: 職と技術が再び広まるのを許さない意思。M11の「授職の灯がともった」を受ける。
- ③「我が名は ヴァルガ。ダーマを焼いた者だ。」: 計画の例のとおりの名乗り。第5章の「名を持たぬ主」「名は記録から削られておる」を回収する。
- 名前は字幕のほか、タイトルの位置に「三頭魔竜」（小）と「ヴァルガ」（大）を表示する。

シオンはプロローグで三つ首の竜を見ていないので、この竜が旧神殿を壊したと知るのは③の言葉による。シオンの反応は直後の会話で描く。名乗りは直後の会話にも用意し、ムービーを最後まで見たときだけ省く（計画のとおり。ゲームで決める）。

## ヴァルガの絵

頭・開口頭・胴は、Studioの作画コード（[`../../prototypes/varuga-8dir/character.mjs`](../../prototypes/varuga-8dir/character.mjs)）の8方向シートから、正面と左右の斜め前のセルを [`../shared/varga.mjs`](../shared/varga.mjs) が `parts/varga.json` へ書き出したものをそのまま使います。配色はStudioの試作色（赤銅の鱗・金の腹板・銀の角）で、確定配色ではありません。

ゲームの3Dでは首・翼・尾を立体で付けるので、ムービーでは [`src/props12.py`](src/props12.py) の `Varga` が描き足します。

- 三つの頭の並びと高さは、`rig-profile.mjs` の `heads`（左右の首は横へ±2・上へ5.3、中央は上へ5.6）を、胴の倍率（2.1）を胴のセルの高さとして画面の長さに直したもの。左右の頭は内側を向く（左右の斜め前のセル）。
- 首・翼の膜・翼の骨の色は `rig-profile.mjs` の `neckColor`・`wings.membraneColor`・`wings.boneColor`。
- 開口頭のときは、シートの口の位置に火の光を置く。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch7-three-heads
```

1. `build.mjs` が、ヴァルガの頭・開口頭・胴（`cast.mjs` の `VARGA` の方向）を `parts/varga.json` へ書き出します（人物は登場しないので `parts/cast.json` は空）。
2. `src/build.py` が、3場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

再建した神殿は共通部品 [`../shared/temple.py`](../shared/temple.py)、空・海の部品は第3章の結末（`../ch3-departure/src/scenes.py`）のものを使います。ヴァルガの作画（Studio）やこれらを直したら、このムービーも生成し直します。`index.html` と `parts/` は生成物です。ヴァルガの頭・胴は細かい作画なので、`index.html` は約0.8MBあります。

## 見せないもの・作画上の約束ごと

- 戦いの結果（シオンの反撃とゴンタの一撃による退却）は描かない（ゲームで描く）。
- ガーゴイルは描かない（ボス戦にガーゴイルが加わるかはゲームの設計に任せるため）。
- ゾーマや大穴との関係は語らない。
- 大屋根がどこまで傷つくかは描かない（初襲来の後に大屋根の一部が傷ついていることは物語の条件だが、壊し方はゲームで決める）。②は火を噴く直前で切る。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s3-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。
