# 絵コンテ：三つ首の影 ― 三頭魔竜の襲来

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.7秒のクロスフェード（手動で送ると0.45秒）、最初は黒から0.9秒でフェード、最後は0.9秒で暗転します。全体で約9秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 暗くなる空（0～2.4秒）

- カメラ: 倍率1.0 → 1.08（右へ寄る）。
- 絵: 神殿の軒先から見る昼の海。左上に大屋根の端と、灯っていない提灯。海の向こうの空。
- 動き: 右の水平線から暗い雲が広がり（動き）、空と海が暗くなる。雲の中から三つ首の竜が近づいて大きくなる（動き。遠いので暗く沈める。翼を打つ）。かもめが左へ逃げる（動き）。波（動き）。
- 字幕: なし。

## ② 見下ろす三つの頭（0～2.8秒）

- カメラ: 倍率1.06（下寄り）→ 1.0。
- 絵: 暗い赤みの空と雲。画面の下に再建した神殿の大屋根（破風の職業の書の紋章）。その上に翼を広げたヴァルガ（胴・三本の首・三つの頭・尾）。
- 動き: 宙に浮いて上下する（動き）、翼を打つ（動き）、頭が揺れる（動き）。三つの頭の開いた口に火の光がたまって大きくなり、1.0秒からまたたく。後ろの赤い光が強まる。火の粉（動き）。
- 字幕: 0.4秒「職をつぐ灯など、二度と ともさせぬ。」（2.6秒まで）

## ③ 名乗り（0～3.0秒、名前の表示）

- カメラ: 倍率1.0 → 1.05、わずかに上へ。
- 絵: 暗い空と下からの赤い光。画面の下に三つの頭（通常の頭）と首。
- 動き: 頭が下から迫り上がる（動き）、頭が揺れる（動き）、火の粉（動き）、赤い光の明滅。
- 字幕: 0.3秒「我が名は ヴァルガ。ダーマを焼いた者だ。」（2.8秒まで）
- 名前の表示: 1.0秒に「三頭魔竜」（小）と「ヴァルガ」（大）。手動で送るときは名前の表示で一度止まる。
