# 絵コンテ：大屋根の灯 ― 第6章の結び

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.9秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.1秒でフェード、最後は0.9秒で暗転します。全体で約21秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 灯のともる祭壇（0～3.6秒）

- カメラ: 倍率1.1（右下寄り）→ 1.0。
- 絵: 再建した本堂の中。奥に段積みの石の壁、上に木の梁。中央に二段の石の祭壇。前の面の中央に要石（ほかの石と色の違う青みの石。職業の書の紋章）、上に灯の石皿。右に四角い石の選択の柱（仕事の印を刻む枠が縦に四つ、いちばん下にアサギの大工の印）。
- 動き: 0.35秒に石皿へ灯がともり、炎が伸びる。光が広がり、要石の紋章（0.6秒）と柱の印（1.2秒）が光り、ゆっくり明滅する。光の粒が立ちのぼる（動き）。
- 字幕: 0.3秒「要石の祭壇に、授職の灯がともった。」、1.5秒「職は、ここから また受け継がれていくのじゃ。」（3.3秒まで）

## ② 祝いの夜（0～4.8秒）

- カメラ: 倍率1.05（右寄り）→ 1.0（左へ）。
- 絵: 夜空と、灯のともった神殿（窓・軒の提灯・入口の奥の祭壇の灯）。右手前に共同台所（かまどの火と煙）。手前に長い膳（ごはん・汁・焼き魚・おにぎり）を囲む、左からガンゾウ・スズハ（手を前で重ねる）・ワタリ・シオン・アサギ（手を上げる）・ゴンタ（手を上げる）・ピノ（手を振る）。腰から下は膳に隠れる。右から、湯気の立つ鍋を両手で運んでくるミナ。
- 動き: 提灯と窓の明滅、かまどの火と煙（動き）、手を振る、ミナが歩み寄る（動き）、鍋の湯気、星のまたたき。
- 字幕: 0.4秒「神殿の完成と、はじめての授職に――乾杯！」（4.5秒まで）

## ③ 海岸から望む神殿（0～3.4秒）

- カメラ: 倍率1.0 → 1.08、わずかに上へ。
- 絵: 夜空と星、右上に月。左で海に接し、平らな山の肩を経て右の奥へ上る島。肩の上に神殿（窓と軒の提灯の灯、後ろに暖かい光）。浜から神殿へ上る坂道と、道の灯。灯が海に映る。
- 動き: 提灯・窓・道の灯の明滅、映り込みのゆらぎ、月の光のきらめき、波（動き）。
- 字幕: 0.3秒「大屋根の灯が、海まで照らしておる。」（3.1秒まで）

## ④ 遠い咆哮（0～4.6秒）

- カメラ: 倍率1.06（左寄り）→ 1.0（右へ）。
- 絵: 左上に神殿の軒（大屋根の端と垂木）と、吊るした三つの提灯。夜空と大きな月、月の光の道の海。右下に林の影。
- 動き: 0.4秒、右の水平線から咆哮の波の輪が広がる。0.6秒から提灯が揺れ、0.7秒から灯がまたたく。0.7秒に林から鳥の群れが飛び立つ（動き）。ガーゴイルの群れを従えた三つ首の影が、右から左へ月の前を横切る（動き。翼を打つ）。
- 字幕: 0.3秒「――海の向こうから、遠い咆哮。」（2.3秒まで）

## ⑤ 結び（0～3.4秒、タイトル）

- カメラ: 倍率1.04 → 1.0。
- 絵: 静かになった星空と、画面の下に大きく、灯のともった大屋根（破風の職業の書の紋章、軒の提灯、窓）。
- 動き: 提灯と窓の明滅、星のまたたき。
- 字幕: なし。
- タイトル: 1.0秒に「職をつぐ者　ダーマ再興編」（小）・「第6章・完」（大）・「よみがえるダーマ神殿」。手動で送るときはタイトルで一度止まる。
