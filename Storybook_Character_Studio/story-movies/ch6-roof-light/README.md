# 大屋根の灯 ― 第6章の結び（SVGストーリームービー試作・M11）

『職をつぐ者』ダーマ再興編の第6章の章末に入れる、約21秒・全5場面のストーリームービーの試作です。**第6～7章のゲームはまだないので、Studio内の試作です。** ゲームを作るときに組み込みます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch6-roof-light/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [第6～7章のムービー計画](../../../docs/story/planned/chapter6-7-movies.md) の M11（優先度B）。物語は [第6章](../../../docs/story/planned/chapter6.md) と [シナリオと共通設計](../../../docs/story/planned/chapter6-7-scenario.md)。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

第6章を、神殿の完成と最初の授職の喜びで締めくくります。最後に、海の向こうから届く咆哮と、ガーゴイルの群れを従えて沖を横切る三つ首の影を輪郭だけで短く見せ、第7章へつなぎます。

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

ほかのムービーと同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第5場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=4`・`?still=4&t=2500`・`?reduced=1`。

## 字幕

第6～7章はゲームより先にムービーを作るので、字幕は[計画](../../../docs/story/planned/chapter6-7-movies.md)の「祝いの言葉と、職業の書の短い言葉。④は字幕を置かないか、ごく短くする」に沿って新しく書きました。①の2行目と③は職業の書の言葉、②は祝いの言葉、④はごく短い地の文です。新しく書いた字幕は計画資料に記録し、第6章の会話を書くときの手がかりにします。字幕と同じ文を、ムービーの前後の会話で続けて流さないようにします。

## 再建した神殿（ゲームの設計図の手本）

[共通設計の分担表](../../../docs/story/planned/chapter6-7-scenario.md#movie-game-alignment)のとおり、神殿の形はムービーに合わせ、ゲームの設計図の手本にします。再建した神殿は共通部品 [`../shared/temple.py`](../shared/temple.py) の `temple_rebuilt()` で描き、M14でも同じものを使います。

- 土台: 崩れた神殿跡と同じ三段の基壇と、同じ間隔で並ぶ9本の柱の位置（プロローグの神殿・M10の神殿跡と重なる）。
- 本堂: 段積みの石の壁と、壁から少し張り出す石の柱。柱の間に縦長の窓（左右に三つずつ）。
- 入口: 中央（4本目の柱の位置）を大きなアーチの入口にし、両脇に、崩れずに残った二本の古い柱を生かす（色が少し違い、すすの跡が残る）。木の扉は外へ開き、奥に祭壇の灯が見える。
- 大屋根: 壁の上に木の梁と、柱の上の組物。軒下に垂木の木口が並ぶ。木の板葺きの大屋根で、四隅が反り上がり、棟の両端に飾り。正面の入口の上に破風があり、職業の書の紋章（金の円に開いた本）を掲げる。
- 軒の提灯: 窓の上と両端に吊るす（夜は灯る）。
- 祭壇と選択の柱（①）: 祭壇は二段の石の台で、前の面の中央に要石（ほかの石と色の違う青みの石。職業の書の紋章）、上に授職の灯の石皿。選択の柱は祭壇とは別の四角い石の柱で、仕事の印を刻む枠が縦に並ぶ。祭壇の右に置き、役割が見分けられるようにした。
- 共同台所（②）: 石の腰壁と木の壁、わら屋根、かまどの焚き口と煙出し。神殿の右手前に置いた。

島の地形・坂道・桟橋・集落の位置はゲームで決めてよい対象です。③の島は、M10と同じ「左で海に接し、右の奥へ山が続く」並びで、ゲームで決まったら描き直します。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch6-roof-light
```

1. [`../shared/cast.mjs`](../shared/cast.mjs) が、登場人物（`cast.mjs` の一覧：八人の正面）の頭・胴のSVGを `parts/cast.json` へ書き出します。スズハ・アサギ・ガンゾウの手足の色は、各人の `rig-profile.mjs` の値です。
2. `src/build.py` が、5場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

膳の料理は第2章の結び（`../ch2-harvest/src/scenes9.py`）、空・海の部品は第3章の結末（`../ch3-departure/src/scenes.py`）のものを使います。再建した神殿（`../shared/temple.py`）や、これらを直したら、このムービーも生成し直します。`index.html` と `parts/cast.json` は生成物です。

## 作画上の約束ごと

- 人物の頭・胴は正式デザインの作画コードのまま。ムービーで描くのは手足（色はゲームの3Dリグ、第6～7章の住民は `rig-profile.mjs` と同じ）と姿勢だけ。
- ヴァルガとガーゴイルは、名前・色・全身を見せない。Studioの造形（`prototypes/varuga-8dir/`・`gargoyle-8dir/`）の輪郭の特徴（三つの頭と角・大きな翼・尾／角とコウモリの翼の小さな体）だけを、月の前を横切る影にする。
- 授職の場面そのもの（シオンがアサギの話を聞くところ）は描かない（ゲームの会話で描く）。①は灯がともった後の祭壇と柱だけ。
- 「遠い咆哮」は音がないので、咆哮の波の輪、揺れる提灯の灯、飛び立つ鳥で見せる。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s5-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。

## 確認する

```powershell
npm.cmd test
npm.cmd run test:movie -- ch6-roof-light
```

`npm.cmd test` は、人物の部品が作画コードと一致すること、字幕が計画資料に記録されていること、再建した神殿が崩れた神殿跡と同じ基壇の上に立ち、中央を入口にしていること、三つ首の影が三つの頭を持つこと、ヴァルガ・ガーゴイルの名前を出さないこと、id の接頭辞、Pythonでの再生成が同じ内容になることを確かめます。
