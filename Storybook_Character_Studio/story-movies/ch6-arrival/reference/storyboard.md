# 絵コンテ：始まりの場所 ― ダーマ再興編の始まり

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.95秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.2秒でフェード、最後は0.9秒で暗転します。全体で約30秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① これまでの旅（0～7.2秒）

- カメラ: 倍率1.0 → 1.04、わずかに上へ。
- 絵: 夜から明け方の色（左上の紺から右下の紫）の背景と星、中央の書の光。金縁の思い出の額が三枚、順に現れる。
  - 0.1秒: 左上の額。プロローグ第4場面の前半（燃える神殿を背に、職業の書を背負って夜の山道を駆け下りるシオン）。
  - 2.5秒: 右上の額。M4の第1場面（朝の光の中の復興したジパング）。左上の額は少し暗くなる。
  - 4.8秒: 中央下の額。M7の第1場面（澄んだ水の戻った清めの泉と、火の戻った鉱山町）。右上の額は少し暗くなる。
- 動き: 額は動かさず、現れ方と明るさだけを変える（中の場面が毎コマ描き直しになり重くなるため）。額の中は元のムービーのとおり動く。書の光の粒が立ちのぼる（動き）。
- 字幕: 0.4秒「ただ一人、神殿から逃れた見習いがいた。」（2.4秒まで）→ 2.8秒「漂着した者は、船をつくる者になった。」（4.7秒まで）→ 5.1秒「祈りを取り戻した者たちは、病める者のそばに立った。」（6.9秒まで）。三つは同じ場所に順に出る。

## ② 夜明けの海（0～5.2秒）

- カメラ: 倍率1.06（右寄り）→ 1.0（左へ）。
- 絵: M7の夜の空の名残が上から明けていき、星が消える。右の水平線から日が昇り、海に光の道。わらの帆の船（M4と同じ船）に、舵輪のワタリ、ゴンタ・ミナ・シオン（胸から上）。甲板に樽と袋。
- 動き: 空が白む・星が消える・日が昇る、船が右へ進む（動き）、船の揺れ（動き）、波（動き）、水面のきらめき、2.8秒からかもめ（動き）。
- 字幕: 0.4秒「そして 職をつぐ者は、船に乗る。」、1.8秒「すべてが失われた、始まりの場所へ。」（4.9秒まで）

## ③ 海から山へ続く島（0～5.2秒）

- カメラ: 倍率1.0 → 1.1（左上へ寄る）。
- 絵: 晴れた朝の空と海。手前に船首の手すりと甲板、四人の後ろ姿（左からワタリ・ゴンタ・ミナ・シオン。シオンの背中のホルダーに深緑の職業の書）。ワタリが手を上げて指す先に、左で海に接し、右の奥へ山が三重に重なって続く島。手前の山の肩（山腹）に、小さく神殿跡の二本の柱と基壇。その真下に浜と、手前の沖へ伸びる小さな桟橋。浜の奥に麓の集落（坂道の左に二軒、右に一軒と畑）、その奥に島を左右に横切る谷。坂道は浜から集落と谷の落ちた橋を経て、神殿跡の正面へまっすぐ上る（ゲームの地形と同じ並び）。
- 動き: 島がゆっくり近づく（動き）、霞が流れる（動き）、波（動き）、波打ち際の白い線、神殿跡に当たる光の明滅。
- 字幕: 0.4秒「あの夜、炎の中から逃れた島。」、1.9秒「シオンは、帰ってきた。」（4.9秒まで）

## ④ 神殿跡（0～5.6秒）

- カメラ: 倍率1.16（下寄り）→ 1.02（上へ）。麓から神殿跡を見上げる。
- 絵: 朝の空と、奥へ続く山。山腹から張り出した古い石積みの台の上に、三段の基壇。屋根はなく、中央の左右の二本の柱だけが柱頭まで立つ。ほかの柱は折れた根元で、右の一本は倒れて輪切りの石が三つ並ぶ。焼け焦げた梁の残りが左の根元に立てかかり、右は基壇から地面へ落ちている。柱に古いすすの跡、根元と段に苔と草、瓦礫。神殿跡の手前で、谷が島を左右に横切る（奥の岸に岩の崖）。石段の坂道は手前の麓から谷へ来て、架かっていた木の橋は中ほどが落ち、両岸に板の端と親柱が残る。谷の向こうで坂道は、石積みの台の正面の中央の石段へまっすぐ着く。斜面の両側に木。
- 動き: 右上からの朝日の筋の明滅、柱のあたりのほこり（動き）、草の揺れ（動き）、柱から鳥が飛び立つ（動き）、雲（動き）。
- 字幕: 0.4秒「屋根を失った神殿に、二本の柱だけが残っていた。」、2.3秒「職を授ける場所を、もう一度 ここに。」（5.3秒まで）

## ⑤ 着岸（0～5.8秒、タイトル）

- カメラ: 倍率1.08（右寄り）→ 1.0。
- 絵: 朝の空。海の側から、神殿跡の山の麓の浜を見る。奥へ重なる山並み、山腹の神殿跡、その正面からまっすぐ下る坂道、島を横切る谷、浜のすぐ奥に麓の集落。浜の中央から手前の沖へ伸びる古い木の桟橋（板が所々欠け、潮で白っぽい杭）。左から船が来て、桟橋の左に着く。
- 動き: 船が左から来て止まる（動き）、船の揺れ（動き）、波（動き）、波打ち際、水面のきらめき、かもめ（動き）、神殿跡に当たる光の明滅。

- タイトル: 2.6秒に「職をつぐ者」（小）・「ダーマ再興編」（大）・「第6章　よみがえるダーマ神殿」。手動で送るときはタイトルで一度止まる。
