# 始まりの場所 ― ダーマ再興編の始まり（SVGストーリームービー試作・M10）

『職をつぐ者』ダーマ再興編（第6～7章）の最初に入れる、約30秒・全5場面のストーリームービーの試作です。**第6～7章のゲームはまだないので、Studio内の試作です。** ゲームを作るときに組み込みます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch6-arrival/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [第6～7章のムービー計画](../../../docs/story/planned/chapter6-7-movies.md) の M10（優先度A）。物語は [第6章](../../../docs/story/planned/chapter6.md) と [シナリオと共通設計](../../../docs/story/planned/chapter6-7-scenario.md)。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

ダーマ再興編は、第1～3章・第4～5章とは別のゲームとして始まります。初めて遊ぶ人にもこれまでの旅が分かるよう、プロローグ・第3章の結末（M4）・火山島編の結末（M7）の絵を「思い出の額」に入れて短く振り返ります。M7の夜の海の続きとして夜明けの海から始め、旧ダーマ神殿のある島に着くところまでを見せます。

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

ほかのムービーと同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第5場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=4`・`?still=4&t=4200`・`?reduced=1`。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch6-arrival
```

1. [`../shared/cast.mjs`](../shared/cast.mjs) が、登場人物（`cast.mjs` の一覧：四人の正面と背面）の頭・胴のSVGを `parts/cast.json` へ書き出します。
2. `src/build.py` が、5場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

思い出の額（場面①）は、プロローグ（`../prologue/src/scenes_b.py` の `scene4()`）、第3章の結末（`../ch3-departure/src/scenes.py` の `scene1()`）、火山島編の結末（`../ch5-return/src/scenes7.py` の `scene1()`）の場面を、生成のたびにそのまま縮めて入れます。そのため、それらの絵を直したら、このムービーも生成し直します（`npm.cmd test` は食い違いを見つけます）。船は第3章の結末の `props.py`、額の縁と星は火山島編の始まりの `props5.py` のものを使います。

`index.html` と `parts/cast.json` は生成物です。手で直さず、`src/` を直して生成し直します。思い出の額に3本分の場面が入るので、`index.html` は約0.8MBあります。

## 作画上の約束ごと

- 人物の頭・胴は正式デザインの作画コードのまま。ムービーで描くのは手足（色はゲームの3Dリグと同じ）と姿勢だけ。
- 思い出の額の中は、元のムービーの絵を描き直さずにそのまま使う。元の接頭辞（`s4-`・`s1-`）は、この場面の接頭辞の下（`s1-pa-`・`s1-mb-`・`s1-mc-`）に置き換える。プロローグ第4場面は前半（夜の山道を駆け下りる全身）だけを額に入れ、後半へ切り替わる動きは止める。
- 船はM4・M5・M7と同じ（同じ船で旅を続ける）。
- 神殿跡は、プロローグ第3場面とM7の神殿の影と同じ三段の基壇と、同じ間隔で並ぶ9本の柱の位置で描く。屋根はなく、中央の左右の2本（0から数えて3本目と5本目）だけが柱頭まで残る。島を遠くから見る場面（③・⑤）も同じ形を縮めて置く。この形が、第6章のゲームの地形と神殿の設計図の手本になる。
- ダーマの島は「一方が海に接し、奥へずっと山が続く」（[シナリオ](../../../docs/story/planned/chapter6-7-scenario.md)の舞台）。浜・桟橋から麓、坂道、山腹の神殿跡へ上る並び。
- スズハとの出会い（導入会話に残す）、再建した神殿、ヴァルガ、ガーゴイルは描かない。島の住民の集落も、ゲームの設計が決まるまで描かない。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s5-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。現れ方（不透明度）は `.mv` の付かない外側の組に分け、止めても絵が残るようにする。

## 確認する

```powershell
npm.cmd test
npm.cmd run test:movie -- ch6-arrival
```

`npm.cmd test` は、人物の部品が作画コードと一致すること、①・②の字幕がすでにある文であり、③・④の字幕が計画資料に記録されていること、神殿跡の基壇がプロローグ・M7と同じ外形であること、描かないもの（スズハ・ヴァルガ）の名前が出ないこと、id の接頭辞、Pythonでの再生成が同じ内容になることを確かめます。

## 残っている課題

- **M7との食い違い**: M7の最後の場面では、夜の水平線の山の上に、屋根の一部が残ったプロローグと同じ形の神殿の影が見える。このムービーと[第6章の計画](../../../docs/story/planned/chapter6.md)（「山腹の屋根を失った二本の柱」）では、屋根はなく二本の柱だけが立つ。続けて見ると、一晩で屋根が消えたように見える。M7の影を二本の柱の形に描き直すか、遠景の影は記憶の中の姿として残すかを決める必要がある。
- 島の左右の向き・寸法・坂道の通り方は、第6章のゲームの地形を作るときに合わせ直す。
- 音楽・効果音はない。実機（スマートフォン）での滑らかさは未確認。
