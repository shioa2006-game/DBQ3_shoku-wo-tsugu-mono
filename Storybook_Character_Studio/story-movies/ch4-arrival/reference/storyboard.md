# 絵コンテ：海を越えて ― 火山島編の始まり

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.95秒のクロスフェード（手動で送ると0.55秒）、最初は黒から1.2秒でフェード、最後は0.9秒で暗転します。全体で約29秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 神殿からの見習い（0～5.2秒）

- カメラ: 倍率1.0 → 1.05、わずかに上へ。
- 絵: 夜の星空と、中央の書の光。金縁の思い出の額（色味を少し暖かく、四隅を暗く）。中はプロローグ第4場面の前半：夜の山道を、職業の書を背負ったシオンが駆け下り、右奥の峰で神殿が燃えている。
- 動き: 額がふわりと現れる（額そのものは動かさない。中の場面が毎コマ描き直しになり重くなるため）。額の中はプロローグのとおり（走る弾み・背景の流れ・火の粉・書の光）。書の光の粒が立ちのぼる（動き）。
- 字幕: 0.5秒「ただ一人、神殿から逃れた見習いがいた。」、1.9秒「少年の名は、シオン。」（4.8秒まで）

## ② ジパングの復興（0～6.8秒）

- カメラ: 倍率1.02 → 1.06（左へ）。
- 絵: 朝の光の色の背景と光の筋。左上の大きな額にM4の第1場面（復興した島：社・田・食堂・灯台）。3.2秒から、右下の額にM4の第2場面（桟橋に立つピノ・イナホ・ジンベエ）が重なる。
- 動き: 左上の額は動かさず、右下の額だけが3.2秒から滑り込む（動き）、光の粒（動き）。額の中はM4のとおり（煙・旗・手を振るピノ・足元の光の輪）。
- 字幕（1組目）: 0.4秒「ジパングでは 農民・料理人・船乗り、三つの書がよみがえった。」（3.1秒まで）
- 字幕（2組目）: 3.4秒「本島は 大工のピノ、料理人で農民のイナホ、神官のジンベエに任せてきた。」（6.4秒まで）

## ③ 長い航海（0～5.0秒）

- カメラ: 倍率1.06（右寄り）→ 1.0（全景）。
- 絵: 夕暮れの空（上が藍、水平線が橙）が夜に変わり、星が出て、右上に月が昇る。暗い海に月の光の道。中央にM4と同じ船：船尾楼で舵輪を握るワタリ、甲板に手を重ねたミナ、シオン、腰に手のゴンタ（腰から下は舷側に隠れる）。ワタリの横に空の樽が二つ、船首にしぼんだ袋。帆は月明かりの色、船尾の灯り。
- 動き: 夜になる（4.6秒かけて）、星のまたたき、月が昇る（動き）、船が右へ進み揺れる（動き）、波（動き）、吹き流し、灯り。
- 字幕: 0.5秒「職をつぐ旅は、海の向こうへ続いていく。」（4.6秒まで）

## ④ 灰の風（0～5.8秒）

- カメラ: 倍率1.0 → 1.1（右の島の方へ）。
- 絵: 灰色がかった橙の霞んだ空と、霞の向こうの白い太陽。くすんだ海。右の水平線に黒い火山島（火口が赤く光り、溶岩の筋、噴煙が左へ流れる）。手前は船首：右へ上がる手すりと甲板。左から、手を上げて島を指すワタリ、腰に手のゴンタ、ミナ、シオンの後ろ姿。灰の粒が右から左下へ舞う。
- 動き: 島がゆっくり大きくなる（動き）、噴煙が膨らみ流れる（動き）、火口の光の明滅、霞が流れる（動き）、灰（動き）、波（動き）。
- 字幕: 0.4秒「……潮風が、変わった。灰の匂いをふくんだ風。」、2.1秒「黒い島影が、ゆっくりと近づいてくる。」（5.4秒まで）

## ⑤ 焼けた船着き場（0～6.0秒、タイトル）

- カメラ: 倍率1.1（右下寄り）→ 1.0（全景）。
- 絵: 煙った夕方の空。中央に大きな黒い火山（赤い火口、噴煙）、手前の低い丘と焼けた枯れ木。左手前は海、右は黒い浜。浜に焼け落ちた小屋の骨組み（残り火）、浜から海へ伸びる焦げた桟橋（板の抜けた区間、折れた杭の残り火）。沖から小さな船（四人の頭）が近づく。
- 動き: 噴煙（動き）、火口と残り火の明滅、小屋と桟橋の細い煙（動き）、船が近づく（動き）、灰（動き）、波（動き）。
- 字幕: 0.4秒「炉は冷え、鉄は眠る。」、1.5秒「——それでも人は、火を戻すことを選んだ。」（3.2秒まで）
- タイトル: 3.4秒に「職をつぐ者」（小）・「火山島編」（大、ゲームのタイトルと同じ黄色・極太・茶色の影）・「第4章　鬼火の山」。手動で送るときはタイトルで一度止まる。
- 本編では、この後に第4章の導入会話（「——だれか、いるの……？」とカヤとの出会い）が続く。
