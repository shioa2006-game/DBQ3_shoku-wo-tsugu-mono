# まだ見ぬ書へ ― ダーマ再興編・完（SVGストーリームービー試作・M14）

『職をつぐ者』ダーマ再興編の第7章の結末で、スズハへの継承の後の最後の出航に流す、約37秒・全6場面のエンディングのストーリームービーの試作です。ダーマ再興編とこれまでの旅を締めくくり、ピノとベルクをそれぞれの島へ送り届けてから、世界中の職業の書を探す新しい旅へつなぎます。最後に「ダーマ再興編・完」と、作品名「職をつぐ者」「完」を出して、全7章の物語を締めます。**第6～7章のゲームはまだないので、Studio内の試作です。** ゲームを作るときに組み込みます。

- 確認URL: Studioを起動（`npm.cmd start`）して http://127.0.0.1:8081/story-movies/ch7-unseen-books/ 。[ムービーの一覧](../index.html)（`/story-movies/`）からも開けます。
- 計画: [第6～7章のムービー計画](../../../docs/story/planned/chapter6-7-movies.md) の M14（優先度A）。物語は [第7章](../../../docs/story/planned/chapter7.md)（「エンディング・世界中の職業の書を探す旅へ」）。
- 場面ごとの時間・カメラ・字幕・絵の内容: [絵コンテ](reference/storyboard.md)

イラストはすべてコードで描いたSVGで、音声はありません。非公式ファン企画用です。

## 再生と操作

ほかのムービーと同じ再生エンジン（[`../shared/engine.py`](../shared/engine.py)）です。「ムービーを見る」で再生し、クリック・タップ・Space・Enter で次の場面へ（第6場面の1回目はタイトルまで）、「スキップ」・Esc で終了画面へ、「もう一度見る」で最初から。確認用のURLパラメータは `?autoplay=1`・`?from=5`・`?still=6&t=6800`・`?reduced=1`。

## 字幕と最後の表示

字幕は[計画](../../../docs/story/planned/chapter6-7-movies.md)の方針（[第7章](../../../docs/story/planned/chapter7.md)の台詞の方向性をもとに作る）に沿っています。

- ⑤⑥: 第7章の例文のとおり。⑤の1行目は職業の書、2行目はシオン、⑥は結びの一文。
- ①～④: 新しく書いた。①はM10の「職を授ける場所を、もう一度 ここに。」を受ける。②は最後の出航で二人を送り届けること。③④は、各地に暮らしを託してきた旅の成果として、それぞれの島で仕事が続いていること（③は農民・料理人、④は鍛冶屋の仕事）。
- 最後の表示は、タイトルの位置に「ダーマ再興編・完」を出し、2.4秒後に作品名「職をつぐ者」、さらに1.2秒後に「完」を続ける（`src/build.py` の `TITLE_HTML`・`EXTRA_CSS`。再生エンジンのタイトルは1回だけ出るので、タイトルの中で時間差を付けた）。

## 決めたこと（制作時）

- **場面の分け方**: 計画の①（再開した神殿と桟橋からの船出）を、①再開した神殿と②ダーマの船出に分けた。②はM4・M7の船出と同じ構図（桟橋で見送る三人の後ろ姿と、手を振る船の上の人々）にした。
- **訪れた人**: ①で神殿を訪れる人は、名前を持たない旅人の後ろ姿（フードの外套・背負い袋・杖）にした。どこから来た誰かは描かない。
- **③④の構図**: どちらも、船が寄った桟橋に、降りた人が歩いてきて島の人々が迎える形にそろえた（M4の第2場面の桟橋）。
- **書の光**: ⑤⑥では、シオンが背に負う話す職業の書（原本）を光で示した（⑤は肩の後ろの深緑と金の光、⑥はM4の結びと同じ帆の上のきらめき）。

## 生成する

Studioのルートで実行します。Node.js 18以上と Python 3.9以上（標準ライブラリだけ）が必要です。

```powershell
npm.cmd run build:movie -- ch7-unseen-books
```

1. `build.mjs` が、十五人の頭・胴（`cast.mjs` の `CAST`）を `parts/cast.json` へ書き出します。
2. `src/build.py` が、6場面のSVGとストーリーデータを共通の再生エンジンで `index.html` にまとめます。乱数は固定シードなので、何度実行しても同じ内容になります。

上の部品や人物の作画（Studio）を直したら、このムービーも生成し直します。`index.html` と `parts/` は生成物です。十五人の頭・胴を含むので、`index.html` は約1.1MBあります。

## 見せないもの・作画上の約束ごと

- 次に探す書の種類・数と、次の行き先の土地は描かない（⑤⑥の水平線に陸を置かない）。
- 授職・継承の場面そのものは描かない（ゲームで描く）。①は継承の後の、スズハが人を迎える神殿。
- ②のダーマの島は、ゲームの地形と合っていない。ゲームでは桟橋は神殿の真下の浜から南へ伸びるので、桟橋から沖の船を見ると神殿は背後になり、同じ画面には入らない。合わせるには海の側から見た構図へ変え、見送る三人を後ろ姿から正面向きにすることになる。2026-11-14のユーザーの判断で、M4・M7の船出と同じ構図（見送る後ろ姿と神殿を一枚に入れる）を優先し、このままにする（[不整合一覧のPLAN-ISLAND-2026-11-14](../../../docs/story/inconsistencies.md#plan-island-2026-11-14)）。
- id・クラス・アニメーション名には場面の接頭辞（`s1-`～`s6-`）を付ける。位置の動きには `.mv` を付け、モーション軽減時に止める。
