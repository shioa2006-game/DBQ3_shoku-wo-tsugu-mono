# 絵コンテ：まだ見ぬ書へ ― ダーマ再興編・完

[試作のREADME](../README.md)

時刻は各場面の始まりからの秒。カメラの「倍率」は1が全景、移動は画面の幅・高さに対する割合です（`src/build.py` の `STORY`）。場面の切り替えは0.9秒のクロスフェード（手動で送ると0.5秒）、最初は黒から1.0秒でフェード、最後は1.4秒で暗転します。全体で約37秒。モーション軽減時は、カメラと「（動き）」の印の付いた位置の動きを止めます。

## ① 再開した神殿（0～5.4秒）

- カメラ: 倍率1.08（下寄り）→ 1.0。
- 絵: 朝の空と雲、かもめ。再建した神殿（直った姿）の正面を近くから。大屋根の破風に職業の書の紋章、軒の提灯、入口の奥に授職の灯。入口にスズハ（手を前で重ねる）。大屋根の左の上にアサギ（片手を上げる。足元に葺き板と道具箱）。石段を上る旅人二人の後ろ姿（フードの外套、一人は杖）。右に切り石を抱えたガンゾウ。
- 動き: 旅人が石段を上っていく（動き）、ガンゾウが右から歩いてくる（動き）、アサギの手（動き）、入口の奥の灯の明滅、雲・かもめ（動き）。
- 字幕: 0.4秒「ダーマ神殿は、ふたたび 職を授ける場所になった。」（5.1秒まで）
