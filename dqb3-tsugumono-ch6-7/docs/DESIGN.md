## 3. 神殿の形（ムービーの `temple.py` が手本）

- 基壇: 三段（外から x22～42 / 23～41 / 24～40、z24～37 / 25～36 / 26～35）。上の段の上面が本堂の床（y=19）。
- 正面（南面 z=35）: 柱9本を2マスおき（x=24,26,…,40）。中央（5本目 x=32）は柱を立てず、幅3・高さ3のアーチの入口。その両脇（x=30, 34）が、崩れずに残った二本の古い柱。
- 壁: 神殿の石。高さ4（y19～22）。柱の間に窓。東の壁（x=40, z=31）に横の入口。
- 屋根: 壁の上に木の梁（y=23）、その上に板葺きの大屋根（寄棟。y24～26の三層と棟）。軒は1マス張り出し、四隅を1段上げて反りを表す。正面の入口の上に破風と職業の書の紋章、軒に提灯8つ。
- 祭壇: 本堂の奥の中央（x31～33, z28）。下の段の中央が要石（青みの石に書の紋章）、その上に授職の灯の石皿。
- 選択の柱: 祭壇の東（x=35, z=28）。四つの枠に仕事の印を刻む（下から大工・石・食・守り）。
- 本堂の中: 西に書庫（本棚・机）、東に休める部屋（寝床3）。横の入口の外に渡り廊下と水場。
- 共同台所: 前庭の東（神殿の右手前）。最初に建てる共同小屋を広げる。

崩れた神殿跡（開始時）: 基壇は欠けと瓦礫があり、柱は x=30, 34 の二本だけが立つ。ほかは折れた根元。祭壇は中央の石が欠けている。

## 4. 建築と住民の手伝い

設計図は第1～5章と同じ仕組み（光る枠をクリックすると、その場所に要るブロックを所持品から置く）。神殿はマス数が多いので、次の二つで負担を減らす。

- **住民の手伝い**: 神殿の設計図（基壇・柱と壁・大屋根・修理）が出ている間、棟梁と大工たち（ピノ・アサギ・ガンゾウ。その時点で島にいる人）が、前庭の**資材置き場**（共同小屋の横の収納箱）に入っている資材を使って、数秒に1マスずつ自分で組む。プレイヤーは資材を集めて箱へ入れるか、自分の手で置く。
- **まとまった資材の受け渡し**: 節目で住民が資材を渡す（ガンゾウの切り石、ピノが船で運んだ板材など）。足りない分は採集とクラフトで補える（資材不足から必ず復帰できる）。
- **詰まないための決まり**: 物語で必ず要る設計図（第6章の建築、初襲来の後の神殿の修理、戦後の神殿の再開）のブロックは、木・石・わら・ねん土など、採り直せる素材だけで作れる。数に限りのある鉄を使うもの（門・ボウガン・とげ罠）は、必須の修理に含めない（初襲来の後の「神殿の修理」は神殿の本体だけ。防衛線の枠は、準備の段階で任意の修理として出す）。大矢が5本に足りないときは、ベルクに話すと6本になるまで渡してくれる。要石と大型対空ボウガンは、壊すと自分を落とす。

## 8. 第7章の防衛

- **守る対象**: 要石を据えた祭壇（授職の灯）。耐久200。0になると灯が消えて敗北。耐久は波をまたいで引き継ぎ、準備の間に祭壇を調べて神殿の石2個で+40回復できる。
- **3波**: 第1波＝ガーゴイル8。第2波＝岩砕き3・ガーゴイル4。第3波＝ガーゴイル8・岩砕き4（二手に分かれて着地）。
- **飛来と着地**: 南の海の上から飛んで来て、踊り場へ降りる（飛んでいる間は攻撃が届かず、向こうも攻撃しない）。着地後は「道の口 → 前庭 → 正面の入口 → 祭壇」の道順で進む。理由づけは「石の体は重く、海を渡りきると翼を休めねば飛べない」。
- **門と防壁**: 魔物は壊すまで通れない（門は1マスのブロックだが、魔物は上を跳び越えられない）。門は耐久90、丸太の防壁は60。ガーゴイルは1秒ごとに3、岩砕きは一撃25を与える。岩砕きは神殿の壁と柱も砕く。道の口の両脇は台地の下の土手（深さ4）で、木は生やさない（葉を足場に回り込めないように）。
- **進めなくなった敵**: 土手へ落ちた、谷へ誘い込まれた、物に引っかかったなどで7秒進めない敵は、飛び上がって踊り場へ降り直す（1体が動けないまま波が終わらなくなるのを防ぐ）。門や壁を壊している間、相手に届いている間は数えない。
- **群れの間隔**: 地上の敵どうしは少しずつ押し離し、1点に重ならないようにする。
- **とげ罠**: 踏んだ魔物に3ダメージ（同じ魔物には2秒おき）。12回作動すると壊れる。設計図では門のすぐ前ではなく、1段下の道（z53・z54）に置く。
- **ボウガン**: 置いたときにプレイヤーが向いていた方角（4方向）へ、射程7.5・前方90度の魔物を1.7秒ごとに撃つ（3ダメージ）。狙うのは攻めてきた軍勢と竜の頭だけ。矢は共用の矢倉から1本ずつ減る。ボウガンを調べると、持っている矢をすべて矢倉へ入れる。
- **合図**: 準備が済んだらゴンタに話しかけて始める。始めるときにセーブし、その状態を「開始直前の状態」として覚える。
- **ミナの炊き出し**: かまどがあれば、戦いの始めに全員を回復し、プレイヤーに満腹バフを付ける。
- **住民**: ゴンタ・ワタリ・ベルクは戦う。スズハ・アサギ・ガンゾウ・ピノは本堂の中へ避難し（戦いの始めに置き、終わると持ち場へ戻す）、ミナは門の内側で近くの仲間を回復する。軍勢が狙うのはプレイヤーと戦う住民だけで、避難した住民には構わず祭壇の灯へ向かう。
- **釣り合い（2026-11-14の計測）**: 敵の体力はガーゴイル20・岩砕き56。門の内側で戦えば3波とも祭壇は無傷で、第3波でプレイヤーの体力が半分まで減る。何もしないと、第1波は門を破られながら住民とボウガンで勝ち、第2波で負ける。
- **敗北**: 開始直前の状態へ戻す（ワールドの差分・所持品・収納箱・矢倉・祭壇の耐久・時刻）。突破済みの波はそのまま。
- **勝利**: 壊れた門・壁・屋根はそのまま残る。準備の段階で「神殿の修理」の設計図（半透明の枠）として出し、プレイヤーと大工たちが直す。直す順番は自由で、直しきらなくても次へ進める。
- **プレイヤーが倒れたとき**: 祭壇の前で立ち上がる（戦いは続く）。負けになるのは祭壇の灯が消えたときだけ。
- **戦いの最中のセーブ**: オートセーブは止まる。ポーズのセーブは「開始直前の状態」を書く。ロードすると準備の段階から始まる。

## 9. ヴァルガ戦

共通ドラゴンリグ（第4～5章の `dragon.js`）に、Studio の `varuga-8dir/rig.js`・`motion.mjs` を移植して使う。

### 初襲来（`CH7_VARUGA1`）

1. 前庭の上空（高さ8）に浮かび、空から火炎を吐く。最初の一吹きは必ず大屋根の西側を焼く（屋根板を10枚前後失う＝アサギの補修へつなぐ）。
2. 火炎の前に、狙う場所が赤く光る（1.2秒）。屋根があればその屋根板が焼け落ち、穴が開いている場所では祭壇の灯が傷つく。
3. 火炎のあと、頭の一つが低く降りてプレイヤーへ噛みつく（3秒）。この間だけ、その頭を攻撃できる。
4. 合わせて40のダメージを与えるとひるみ、ゴンタが翼を射抜いて退却する。早くひるませるほど屋根の被害が減る。
5. 祭壇の灯が消えたら敗北（開始直前へ）。

### 最終決戦（`CH7_VARUGA2`）

1. **対空**: 射台の大型対空ボウガンを調べて乗る。A・D（←→）で向きを変え、マウスで狙い、クリックで大矢を撃つ（装填1.2秒）。F・Escで降りる。翼に5本当てると地上へ落ちる。その間、ヴァルガは屋根と射台を火炎で狙う（赤い予告。射台が狙われたら降りて離れる）。
2. **地上**: 前庭に降りた竜と直接戦う。三つの頭にそれぞれ耐久がある（左80・中央100・右80）。噛みつきは左→中央→右の順。火炎は左右の頭が前庭を薙ぎ、中央の頭は入口の奥の祭壇を狙う。倒した頭の火炎と噛みつきは止まる。再び飛ぶことはない。
3. ボウガンは頭も撃つ。ゴンタたちも頭を攻撃する。
4. 三つの頭を倒すと勝利 → M13。巨体は黒い霧へ崩れて消え、何も残さない。
5. 勝ったとき、入口のアーチと祭壇のまわりが壊れていなければ、最期のあがきで入口が崩れる（戦後の「神殿の再開」の修復へつなぐ）。
