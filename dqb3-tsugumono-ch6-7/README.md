## 第4～5章を土台にするとき

制作開始時は第4～5章の `index.html`、`src/`、必要な `assets/`、`package.json` とlockfile、Vite設定、公式テストをこのフォルダの同じ位置へ引き継ぎます。各編は兄弟フォルダなので、下表のファイルから [game-shared](../game-shared/) への相対importをそのまま使えます。最初の起動前に専用の保存キー、Viteのbase、テストのURLと保存キーをそろえてください。

| 機能 | 引き継ぐ動作 | ダーマ再興編で用意するもの |
|---|---|---|
| 建築 | 照準、設計図の表示、障害物・残り資材・完成判定 | `src/game/blueprints.js` に神殿・採石洞などの設計図と色を定義し、完成後のイベントをクエストへ接続する。 |
| 物資・クラフト | 所持数、スタック上限、満杯時の判定、材料消費、収納箱の出し入れ・保存 | `src/game/items.js` に採石・修理・補給用の素材とレシピ、`src/systems/storage.js` に収納箱のブロックIDを指定する。 |
| 職業の書 | 復活状態・進捗表示・演出・保存 | `src/game/jobs.js` に開始時の六冊の状態と説明を設定する。シオンがアサギに授職するイベントは章のクエストで扱う。 |
| 地上防衛 | 湧き口付近の空き場所探索、波ごとの出現、守る対象の耐久・勝敗・後片付け | `src/game/defense.js` で新マップの拠点・敵・除去可能な自然ブロックを指定する。章のクエストから祭壇・3波の構成を渡す。`canStartWave(index)` が `false` の間は波の予告タイマーが止まる（先頭は0）。修理と補給後の合図をここにつなぐ。 |
| セーブ | v1の共通項目、地形差分、建てかけの高さ、所持品・住民・職業・収納の保存 | `src/game/save.js` のキーを第6～7章専用にしてから初めて起動する。`createSaveSlot` の第3引数で必要な固有項目を足し、`main.js` のロード側で復元する。 |

`main.js`、地形生成、入力・画面、住民AI、戦闘、画像・リグの読込は第4～5章のゲーム側を出発点にします。ニューゲーム初期値・島の座標・地域開放・台詞・クエストを新章のものへ置き換えます。ヴァルガの飛行・部位・対空射撃・再戦は、地上3波とは別のボス戦です。人型リグの既存2編の一致はStudioのテストが確認しており、制作原本と出力先は引き続きStudio側で管理します。

初回の動作確認では、既存2編のセーブがある同じブラウザー・同じオリジンで新章の開始・保存・再開を試し、既存2編も元の状態から再開できることを確かめます。第6章は建築途中と招聘の出航・帰港、第7章は補給中・敗北後・再戦前からの再開を確認します。公開時は共通トップの準備中ボタン、ポータルのビルド対象、Pagesのテスト・公開対象を更新します。
