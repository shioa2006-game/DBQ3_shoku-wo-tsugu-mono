## 遊び方

- 移動は WASD、ジャンプは Space、カメラの回転は Q（または [ ]）。攻撃・設置・種まきは左クリック、指した人・設備の操作は右クリック、正面の近い人・設備の操作は F、もちもの・クラフトは E。
- 採掘は、石／鉄のハンマーを持ち、壊したいブロックにカーソルを合わせて左ボタンを長押し。
- 設計図（半透明の枠）のとおりにブロックを置くと建物が完成する。赤い枠は、どける瓦礫。神殿の設計図は、前庭の資材置き場の収納箱へ資材を入れると、大工たち（アサギ・ガンゾウ・ピノ）も組んでくれる。
- 第7章の戦いは、準備ができたらゴンタに話しかけて始める。ボウガンは置いたときに向いていた方角へ自動で撃ち、調べると持っている矢を矢倉へ入れる。祭壇を調べると、神殿の石2個で灯の守りを回復できる。
- 負けても、合図の直前の状態（建物・資材・矢倉）へ戻ってやり直せる。
- 最終決戦は、射台の大型対空ボウガンを調べて乗り、A・D（←→）で向きを変え、マウスで狙い、クリックで大矢を撃つ。F・Esc で降りる。
- ポーズの「そうさ方法」からいつでも確認できる。


## 人と設備の選び方

右クリックはカーソルで指した人や収納箱などを操作します。地面をクリックしても、近くの人との会話には切り替わりません。Fキーは、マウスの位置に関係なく主人公の正面の近い人・設備を選びます。操作できる対象には枠と「収納箱を開く」「ミナと話す」などの案内が出ます（右クリックは金色、Fは水色。同じ対象なら1つにまとめます）。壁の向こうや手が届かない対象は選びません。

## ビルドとテスト

```sh
npm run build    # dist/ へビルド（base: /dqb3-tsugumono-ch6-7/）
npm run test:ci  # 高速サブセット（sheets + smoke + HUDハート + 水中描画 + 水からの脱出 + アイテムアイコン + 設置物の3D + ムービー）
npm run test:e2e # 全テスト（全編の通し、第6章・第7章の細かな確認、敗北後の再挑戦、資材不足からの復帰、セーブの共存を含む。10分ほど）
```

[親リポジトリ](../README.md)内の配置で開発してください。建築・所持品・職業の書・防衛・保存の共通処理は [game-shared](../game-shared/) を参照し、ビルド時にこの編の `dist/` に含まれます。

テストは playwright-core + ヘッドレス Chromium を使う。ブラウザは `PW_CHROMIUM_PATH` で明示指定できる（`tests/helpers.mjs` 参照）。プレビューは既定でポート4176（既存2編は4174）なので、既存2編のテストと同時に走らせても重ならない。`TEST_ONLY=chapter7` のように名前の一部で絞れる。

- 人物9人: シオン（`hero2`）・ミナ・ゴンタ・ワタリ・ピノ・ベルク・スズハ・アサギ・ガンゾウ
- 敵8種: 岩角ヤギ、山ねずみ（おおねずみの色替え）、小岩ガニ、洞窟こうもり（おおこうもりの色替え）、大岩ガニ（小岩ガニの拡大）、ガーゴイル（飛行・地上）、岩砕きのガーゴイル（飛行・地上・攻撃）、三頭魔竜ヴァルガ（頭・開口頭・胴＋3Dの首と翼と尾）
- ムービー5本: 編の始まり（M10）、第6章の結び（M11）、ヴァルガの初襲来（M12）、最終決戦の決着（M13）、エンディング（M14）。クリック・Space・Enter で次の場面、Esc・「スキップ」で終わる。字幕と同じ行は、最後まで見たときだけ前後の会話から省く。
